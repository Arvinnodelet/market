### 九号公司与未岚大陆的关系

九号公司（Segway-Ninebot）以平衡车和电动滑板车起家，2015 年收购美国 Segway 品牌，此后逐步构建"智能短交通 + 服务机器人"双赛道布局。割草机器人是服务机器人赛道的核心业务。

2021 年，九号公司将割草机器人团队独立为**未岚大陆（北京）科技有限公司**，作为控股子公司运营。未岚大陆聚焦于"无边界"智能割草机器人，拥有独立的研发、产品和全球化团队，但共享九号公司的供应链、渠道和品牌资源（以 Segway Navimow 品牌面向全球市场）。

### 从短交通到庭院机器人的战略延伸

九号公司的核心能力是**电动底盘 + 自平衡控制 + 电池/BMS + 物联网**。这套技术栈天然适合延伸到割草机器人：
- 电动底盘 → 割草机器人驱动系统
- 自平衡/姿态控制 → 坡度适应与防倾覆
- 电池/BMS 技术 → 锂电续航管理（九号每年出货数百万块电池包）
- IoT/APP 生态 → 割草机器人联网与远程控制（九号全球联网设备超 3400 万）

这一技术复用逻辑与从消费电子/无人机跨界进入机器人领域的公司（如 DJI 进入扫地机、Bambu Lab 出身大疆供应链）有结构相似性。

## 四、各系列产品详解

### i2 AWD 系列 — 入门级全驱（2026 年 CES 首发）

i2 AWD 是 Navimow 将全轮驱动技术下放至千元价位的战略产品，以"入门即 AWD"为核心卖点，面向首次购买无边界割草机器人的主流家庭。

| **越障高度** | 4 cm | 同 |
| **切割宽度** | 18 cm | 同 |

**产品简评**：i2 LiDAR 系列的核心价值在于将激光雷达导航从 $1,800+ 价位下拉至 $999。TechRadar 对 i210E LiDAR Pro 的评测称其导航精度"英寸级"（inch-perfect），障碍物识别能力强（可检测网球大小物体），59 dB 噪音极低。主要批评为 22 cm 切割盘偏窄、三轮驱动在湿滑草地上偶有打滑。

### H2 系列 — 复杂庭院专家（2026 年 CES 首发）

H2 系列是 2026 年产品线中**定位最独特**的系列——它是 Navimow 唯一搭载"完整版"**EFLS LiDAR+ 三重融合**（LiDAR + NRTK + Vision 三者硬件完整且算法协同最优）的系列，专为树荫密集、窄通道、多变光照的复杂庭院设计。

| 参数 | H210 | H220 |
|---|---|---|
| **最大覆盖面积** | 1,000 m²（0.25 acre） | 2,000 m²（0.5 acre） |
| **导航方案** | **EFLS LiDAR+ 三重融合**：固态 LiDAR + NRTK + 140° Vision（毫秒级动态切换） | 同 |
| **核心差异化** | 三种定位模式在 20ms 内切换，树荫下自动切 LiDAR、开阔区切 NRTK、夜间切 LiDAR+Vision | 同 |
| **AI 避障** | VisionFence（LiDAR + 140° RGB），200+ 物体，最小检测 1 cm | 同 |
| **驱动系统** | 后轮驱动（非 AWD） | 同 |

#### 1.3 VIO（视觉惯性里程计）— 填补 GPS 盲区的最后防线

EFLS 3.0（X3/X4/Terranox）引入的 VIO 模块是仅次于 RTK 的最重要的导航子模块。其工作原理为：

```
VIO 工作流程

摄像头帧 (30fps)  ──→  FAST 角点检测  ──→  KLT 光流追踪  ──→  位姿估计
                              │
IMU 数据 (200Hz)  ──→  预积分  ──→  重力对齐  ──→  速度/姿态
                              │
                    ┌─────────▼─────────┐
                    │  紧耦合 EKF 融合    │
                    │  (误差状态卡尔曼)   │
                    └─────────┬─────────┘
                              │
                    相对位姿 (drift <0.5% 路程)
                    当 GPS 恢复时自动全局校正
```

**关键性能指标**：
- GPS 失效后的位姿保持时间：~30 秒内漂移 <5 cm（可穿行绝大多数树冠覆盖区域）
- 消耗算力：~15% 的 NPU 资源（与 VisionFence 共享 AI 加速器）
- 在极端场景（连续 >60 秒无 GPS + 低光 + 特征稀疏的纯草坪）下，漂移累积可能导致 ~20-30 cm 位置偏差，表现为边缘切割不齐

**VIO 的实际价值**：传统纯 RTK 割草机器人在经过一棵大树下方时会立即"失明"，只能依赖随机碰撞转向（早期 H 系列的行为）。VIO 让机器人在失锁后仍能沿原定方向继续割草，直到 RTK 恢复——这对用户体验的影响远比纸面精度提升显著。

### 2. Xero-turn AWD 全驱转向系统 — 草坪零损伤的工程实现

Xero-turn 是 Navimow X4 和 Terranox 系列的核心差异化技术，于 2026 年 CES 首次亮相，已通过 **TUV Rheinland 草坪安全认证**。它解决了一个看似矛盾的问题：如何在实现零半径转向的同时不损伤草坪？

#### 2.1 传统方案为什么伤草坪？

传统四轮割草机器人在原地转向时，内侧轮静止作为旋转轴心、外侧轮绕其旋转——这会导致静止轮像钻头一样在原地碾磨草坪，在松软或湿润土壤上尤其明显（数周后出现明显的圆形秃斑）。

```
传统差速转向（伤草坪）                  Xero-turn（零损伤）
     ┌───┐                                    ┌───┐
     │ ▲ │  外侧轮                            │ ↺ │  四轮协同
     │   │  绕静止轮旋转                       │   │  Ackermann 转向
     └───┘       ↓                            └───┘  几何轨迹
     ┌───┐   外侧轮                            ┌───┐
     │ ■ │   绕行                      ←──     │   │  四轮各有
     │ ■ │   大弧                              │   │  独立轨迹
     └───┘                                    └───┘
     ┌───┐  静止轮                             ┌───┐
     │ ■ │  ← 碾磨草坪                         │   │  四轮均
     │ ■ │  原地旋转                           │   │  纯滚动
     └───┘                                    └───┘

结果: 圆形秃斑（2-4 周后出现）               结果: 无损伤
```

#### 2.2 Xero-turn 的工程实现

| 组件 | 规格/原理 | 作用 |
|---|---|---|
| **前轮 Ackermann 转向机构** | 几何梯形连杆，转向时内外轮转角差自动匹配（内轮角度 > 外轮），保证所有车轮绕同一瞬时转向中心做纯滚动 | 正常割草时的方向控制 + 大半径转向 |
| **后轮独立轮毂电机** | 双后轮各有一个独立控制的无刷轮毂电机，可正反转 | 差速辅助 + 零半径转向时的动力分配 |
| **Xero-turn 控制器** | 检测到需要 180° 掉头时（到达地图边界），前轮切至 Ackermann 最大转角 + 后轮反向差速，车辆绕自身几何中心旋转 | 零半径转向的协调执行 |
| **轮胎设计** | 宽截面（~8-10 cm）、低胎压（~15 PSI）、浅胎纹——最大化接地面积、最小化单位面积压强 | 减少任何工况下的草坪压实 |

**关键参数**：

| 参数 | X4 系列 | Terranox | Mammotion LUBA 2 | Husqvarna AWD 系列 |
|---|---|---|---|---|
| **转向方式** | Xero-turn（Ackermann + 后轮差速） | 同 | 滑移转向（skid-steer） | 铰接转向（articulated） |
| **零半径转向** | 支持（不伤草） | 支持（不伤草） | 支持（**伤草**——静止侧轮碾磨） | 最小半径 ~1.2m |
| **四轮独立驱动** | 是 | 是（双独立转向电机） | 是（四轮毂电机） | 否（仅后轮驱动） |
| **草坪安全认证** | TUV Rheinland | TUV Rheinland | 无 | 无 |
| **最大工作坡度** | 40°（84%） | 40°（84%） | 38.6°（80%） | 35°（70%） |

> 💡 **Xero-turn vs Mammotion 滑移转向的本质区别**：两者都能零半径转向，但 Mammotion LUBA 的四轮毂电机滑移转向在转向时必然有一侧轮胎横向刮擦草坪（这是差速滑移的物理必然——没有 Ackermann 几何约束，车轮的横向滑动无法消除）。Xero-turn 通过前 Ackermann + 后差速的组合，使四个车轮在任何时刻都沿纯滚动轨迹运动。TUV Rheinland 的认证正是对这种差异的独立验证。

#### 2.3 TCS 牵引力控制系统

X4 系列从汽车领域引入了 TCS（Traction Control System），在湿滑和斜坡场景下防止车轮打滑：

- 每 10ms 检测四轮转速差异
- 检测到单轮打滑 → 降低该轮扭矩 → 将动力重新分配给有附着力的车轮
- 可检测到 1 cm 以上的悬空（越过凹坑时）
- 与 ESC（电子稳定控制）和 Auto-ESC（坡道自动速度调节）共享 IMU 和轮速传感器数据

#### 3.3 AI 人体检测与分级响应

X4 系列的 VisionFence 集成了专用的人体检测 AI 模型（与物体检测模型并行运行），实现了分级安全响应：

```
检测距离        响应                         设计理由
──────────────────────────────────────────────────────────
> 3m           正常割草，无动作                 超出安全范围
2-3m           减速至 0.3 m/s                  预警区
1-2m           进一步减速至 0.2 m/s             警戒区
< 1m           立即停机 + 刀片制动 (<0.5s)      危险区
```

**技术约束**：人体检测依赖 RGB 摄像头（ToF 仅用于测距验证，不参与分类），在夜间需依赖 LED 补光。实际有效识别距离在完全黑暗环境下降至 ~1.5m（仅靠 2 颗 LED 补光）。这低于白天 3m 的标称值——对于夜间使用的安全性是一个值得关注的限制。

#### 3.4 超声波传感器的"消失"

对比 2023 年 H 系列可选配超声波、2025 年 X3 系列未搭载超声波，到 2026 年全系产品**完全弃用超声波传感器**。这是一个值得分析的技术路线选择：

| | 超声波 | 视觉+ToF（当前方案） | LiDAR（当前方案） |
|---|---|---|---|
| **探测距离** | 0.02–4m | 0.1–2m（ToF）/ 视觉远距离 | 0.05–20m |
| **物体分类能力** | 无（仅回波强度） | 有（AI 分类 200+ 种） | 有（点云分类） |
| **透明/黑色物体** | 不可靠 | 视觉可识别 + ToF 辅助 | 不可靠（吸收/穿透红外） |
| **成本** | ~$2-5/个 | ~$5-8（ToF 模组）+ ~$3-5（RGB 模组） | ~$40-60（固态 LiDAR） |
| **草地环境适配** | 草叶导致杂波 | 无影响 | 草叶产生噪点（需滤波） |
| **雨雾衰减** | 轻微 | ToF 严重衰减 | 中等衰减 |

**弃用超声波的逻辑**：超声波传感器在草地场景中的最大问题是**草叶杂波**——高草会产生大量的超声波反射，导致难以区分"高草"和"固体障碍物"。视觉+ToF 的方案不受此影响，且能提供物体分类能力（知道前方是"玩具"还是"宠物粪便"并做出不同响应）。唯一弱势场景是透明障碍物（玻璃围栏），但草坪场景中极罕见。整体来看，这一选择的工程合理性充分。

**关键设计决策**：

| 参数 | X4 方案 | 传统单盘方案（X3/i2/H2） | 设计理由 |
|---|---|---|---|
| **切割盘数量** | 2 | 1 | 更宽切割面（43 vs 22-24 cm）→ 少跑圈数 → 省电 |
| **单盘马达功率** | 180W × 2 | ~100-150W × 1 | 双马达可独立控制转速，遇厚草区域可局部加速 |
| **刀片数量** | 12 片（加厚） | 6 片 | 更多切割点 = 更细碎屑 = 更好的 mulching 效果 |
| **浮动悬挂** | 50mm 被动行程 | 刚性固定 | 地形自适应——过凹坑时刀盘下降、过凸起时上升 |
| **防堵塞设计** | 刀盘间隙加大 + 排水槽 | 仅刀盘间隙加大 | 湿草工况下减少缠绕（仍建议干草时工作） |

#### 4.2 EdgeSense 边缘切割

EdgeSense 是 X4/H2 系列通过软件实现的功能——割草机在完成内部区域割草后，沿地图边界执行一圈"边缘模式"：

- 割草机偏置行驶，使右侧切割盘尽量贴近地图边界
- 声称可切割至墙壁/围栏 **2 inch（5 cm）** 以内
- 实测（How-To Geek 评测）：在平整边缘（如水泥路面边缘）表现良好；在凸起的石质/砖质花坛边缘，刀片偶尔刮擦硬质表面造成磨损

**竞品对比**：

| | Navimow（EdgeSense） | Mammotion LUBA | Husqvarna EPOS | Worx Landroid |
|---|---|---|---|---|
| **边缘策略** | 软件偏置行驶 + 右侧切割盘 | 无专用边缘模式 | 物理弹出式边刷（部分型号） | 无专用边缘模式 |
| **残留在边缘的距离** | 2–5 inch（标称 2） | 4–8 inch | 3–6 inch | 4–10 inch |
| **局限性** | 不规则边缘仍需人工修剪 | 需人工修剪 | 边刷寿命短（6–12 月需更换） | 需人工修剪 |

> ⚠️ 需要明确的是：**所有割草机器人的边缘切割都不完美**。EdgeSense 在该领域中表现领先，但用户仍需要一台 string trimmer（打边机）来修剪围墙底部、花坛边缘等机器人无法触及的区域。这是割草机器人类别的结构性限制，而非 Navimow 独有缺陷。

#### 4.3 Mulching 效果

全系列 Navimow 均采用 **mulching（碎草覆盖）** 模式——无集草袋，细碎草屑直接落回草坪作为天然肥料。mulching 效果取决于：
- 刀片锋利度（官方建议 1-2 月更换）
- 切割频率（建议每天/隔天少量多次，而非一周一次大量切割）
- 草湿度（湿草 mulching 效果显著变差，碎屑成团而非分散）

X4 系列的 12 片刀片 + 双盘系统提供了优于单盘机型的碎化效果，但任何 mulching 系统在雨后高湿草工况下都会打折扣。

### 竞争策略分析

Navimow 采取的是**全价位覆盖 + 技术代际碾压**策略：

1. **$999–$5,499 全覆盖**：从 i2 AWD 入门 ($999) 到 Terranox 商用 ($5,499)，每个 $500 价位段至少一款产品，不给竞品留价格空隙
2. **无边界先发优势**：作为全球首款大规模落地的无边界割草机器人（2021），4 年窗口期转化为 100 万台累计出货和规模效应
3. **"Navimow 标准"**：2026 年 CES 首次系统化定义行业标准——"无需埋线、无需天线、厘米级定位、AI 避障、App 多区域管理"——此举意在将竞争从"参数军备竞赛"拉入"谁先提出标准谁就是标准"的叙事框架
4. **九号生态的协同效应**：割草机器人复用九号公司的电池/BMS 供应链（年采购数百万颗电芯）、IoT 平台（3,400 万联网设备）、全球经销商网络（共享 Segway 品牌的分销商和线下门店），这是纯割草机器人创业公司无法复制的结构性优势
5. **技术代际节奏**：从"无线化"（2021 H 系列）→"AI 视觉"（2024 i 系列）→"360° 感知"（2025 X3 系列）→"LiDAR 三模融合"（2026 H2/i2 LiDAR），平均每 12-18 个月一次重大技术平台升级，迫使竞品处于持续追赶状态

### 行业风险

1. **欧盟反倾销调查**：欧盟已对中国割草机器人发起反倾销调查。Navimow 定位中高端、强调技术竞争非价格竞争，受影响可能相对有限。但若关税上调至 20%+，欧洲市场（Navimow 最大的海外市场）的价格竞争力将受到实质冲击
2. **RTK 技术路线的天花板**：在极高树冠覆盖率场景下，纯 RTK 方案存在物理上限（GPS L1/L2 信号无法穿透密集树冠）。这是所有 RTK 割草机器人的共同约束，Navimow 的 LiDAR 融合方案是目前最好的应对，但增加了 BOM 成本
3. **新进入者压力**：追觅（Dreame）、科沃斯（Ecovacs）等扫地机器人巨头正以每年出货百万台级别的供应链能力和低价策略涌入割草机器人市场，可能导致行业利润率承压
4. **渠道依赖**：北美市场高度依赖 Lowe's 等大型零售商，如果竞品获得更好的货架位置或促销支持，Navimow 的北美份额爬升可能慢于预期

### 选购注意事项

> ⚠️ **"无边界" ≠ "无限制"**：所有 RTK 割草机器人对天空视野有天然依赖。购房前请务必用手机在庭院各处实测 GPS 卫星可见数量。树冠覆盖率超过 40% 的庭院应优先选择 LiDAR 型号（i2 LiDAR / H2）或纯视觉方案（Worx）。

> ⚠️ **割草机器人 ≠ 完全替代人工**：所有割草机器人都会在围墙边缘、花坛边角留下 2-8 inch 未割区域。你仍需要一台 string trimmer（打边机）进行边缘修饰。这不是 Navimow 的问题，而是整个品类的结构性限制。

> ⚠️ **重量与搬运**：X4/Terranox 系列干重接近 30 kg，即使有自走功能，搬运过台阶或装载到车上仍需体力或两人配合。体弱用户建议选择 12-16 kg 的 i2/H2 系列。

> ⚠️ **Connect+ 长期持有成本**：H2/X4/Terranox 的 4G 连接和 GPS 追踪在首年免费后需支付 $29.90–$39.99/年订阅费。不开通则丢失远程追踪和地理围栏警报功能，但本地 Wi-Fi + Bluetooth 控制仍可用。

> ⚠️ **欧盟反倾销税风险**：欧洲用户在 2026-2027 年购买中国品牌割草机器人可能面临额外关税。建议关注官方渠道的最终到手价，并比较 Husqvarna、Stihl 等欧洲本土品牌的本地定价。

> 💡 **Mulching = 更频繁的割草**：Mulching（无集草）模式效果好且免费给草坪施肥，但前提是**少量多次**——建议每天或隔天运行，而不是等到草长高了一次性割掉。如果你习惯一周割一次，mulching 效果会很差（草屑成团、阻塞刀盘），需要额外购买集草配件（如有）。

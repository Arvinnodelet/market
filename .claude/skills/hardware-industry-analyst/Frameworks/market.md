# Market Analysis Framework

## Objective

分析一个硬件细分市场的规模、结构、需求、竞争、技术、渠道和未来变化。重点是建立可验证的市场模型，而不是堆砌市场规模数字。

## 1. Market Definition

明确：
- Product boundary
- Included / excluded categories
- Consumer / Prosumer / Professional boundary
- Geographic scope
- Time period

## 2. Market Size

| Revenue | | | | | |

| ASP | | | | | |

TAM/SAM/SOM 只有在边界和数据足够可靠时使用。

## 3. Demand Structure

分析：
- User segments
- Main use cases
- Purchase drivers
- Replacement cycle
- Price sensitivity
- Adoption barriers

## 4. Channel Structure

分析 DTC、零售、电商、经销商、专业渠道以及区域差异。

## 5. Competitive Structure

| Player | Position | Main Products | Price Band | Technology | Channel | Ecosystem |
|---|---|---|---|---|---|---|
| | | | | | | |

## 6. Technology Structure

分析关键技术路线、性能瓶颈、成本瓶颈、供应链约束以及技术替代风险。

## 7. Regional Structure

比较主要区域的用户需求、价格、渠道、法规和竞争格局。

## 8. Forecast

避免单一 CAGR 外推。优先建立 Base / Upside / Downside 三种情景，并写明假设。

## 9. Market Conclusions

回答：
1. 市场是否真实增长？
2. 增长来自新增用户、升级还是价格变化？
3. 哪些玩家获得最大价值？
4. 哪些技术变化可能改变竞争结构？
5. 未来 2–5 年最重要的不确定因素是什么？

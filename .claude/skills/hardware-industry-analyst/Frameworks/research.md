# Research Framework

## Objective

建立可复用的硬件产品研究流程，在形成评价前先建立完整、可追溯的事实基础。

## 1. Research Scope

明确：
- 对象：Company / Product / Technology / Ecosystem / Market
- 时间范围
- 地理范围
- 产品范围
- 竞品范围
- 用户范围
- 输出目标

## 2. Research Questions

将问题拆成：

```text
Definition
→ Positioning
→ Users / Use Cases
→ Architecture
→ Technology
→ Product Experience
→ Manufacturing
→ Economics
→ Competition
→ Strategy
```

## 3. Evidence Collection

每个重要事实记录：

| Claim | Source | Evidence Status | Confidence | Notes |
|---|---|---|---|---|
| | | | | |

## 4. Evidence Status

- Confirmed
- Verified
- Reported
- Inferred
- Estimated
- Unknown

## 5. Fact → Inference → Assessment

禁止直接从一个来源跳到最终结论。优先形成：

```text
Source
  ↓
Fact
  ↓
Inference
  ↓
Engineering / Business Assessment
```

## 6. Research Gaps

输出仍未解决的问题：

| Question | Why Important | Current Evidence | Next Research Action |
|---|---|---|---|
| | | | |

## 7. Research Stop Rule

当新增资料主要重复已有事实，而不再显著改变产品模型、技术判断或竞争判断时，可以停止扩展搜索。

## 8. Deliverable

研究结束至少形成：
- 产品/公司事实表
- 关键技术模型
- 竞品矩阵
- 证据与置信度记录
- 未知项与研究缺口
- 最终分析报告

# Technology Report Template

## 1. Technology Definition
What the technology is, what problem it solves, and where it is used.

## 2. Working Principle
Explain the physical / computational mechanism step by step.

## 3. System Architecture
```text
Input → Processing / Control → Core Mechanism → Output
                 ↑
              Sensors
```

## 4. Hardware Implementation
Key components, interfaces, materials, packaging, installation and engineering constraints.

## 5. Software & Algorithms
Control loops, calibration, compensation, planning, perception, signal processing or other relevant algorithms.

## 6. Key Performance Metrics
| Metric | Definition | Main drivers | Measurement method |
|---|---|---|---|

## 7. Engineering Challenges
Thermal, mechanical, electrical, optical, fluidic, software, manufacturing and reliability constraints as applicable.

## 8. Competitive Implementations
Compare materially different implementation routes, not just brands.

## 9. Trade-offs
| Design choice | Advantage | Cost / drawback | Typical use |
|---|---|---|---|

## 10. Cost & Manufacturability
Discuss component cost, assembly, calibration, yield and service implications.

## 11. Technology Evolution
Current state, previous generations, emerging approaches and likely direction.

## 12. Assessment
Technical maturity, differentiation, scalability, reliability and strategic importance.

## 7. Core Technology System
Identify 2–4 Technology Clusters rather than isolated features.

For each cluster:
1. Problem
2. Architecture
3. Mechanism
4. Hardware / Sensors / Actuators
5. Software / Algorithms
6. Closed loop, if applicable
7. Performance effect
8. Failure modes
9. Trade-offs
10. Competitive difference
11. Strategic value
12. Next constraint

## 8. Software / Algorithms
Firmware, control, calibration, perception, planning, optimization, slicing/RIP or domain-specific algorithms.

## 9. Materials / Consumables / Ecosystem

Setup, calibration, operation, maintenance, workflow, automation and service.

# Competitor Comparison Playbook

## Objective
Build a like-for-like comparison that explains differences rather than merely listing specifications.

## Workflow
1. Define comparison scope and target customer.
2. Select comparable products by price, generation and use case.
3. Build normalized specification matrix.
4. Map architecture and key subsystem differences.
5. Compare software, algorithms, ecosystem and service.
6. Identify manufacturing and cost implications.
7. Explain which differences are meaningful to users and which are marketing-level.
8. Conclude with competitive position and likely response paths.

## Comparison Dimensions
Product / performance / architecture / sensors / actuators / software / algorithms / materials / reliability / service / manufacturing / price / ecosystem / strategic role.

## Rules
- Normalize units and test conditions.
- Mark Unknown rather than filling gaps with guesses.
- Compare equivalent configurations.
- Separate specification advantage from real-world advantage.

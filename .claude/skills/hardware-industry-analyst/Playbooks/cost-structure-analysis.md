# Cost Structure Analysis Playbook

## Objective
Explain how product design translates into unit economics.

## Workflow
1. Separate BOM, manufacturing, logistics, warranty/service, channel and operating costs.
2. Identify major cost drivers.
3. Map each cost driver to product architecture and volume.
4. Estimate only where assumptions are defensible.
5. Compare cost structure across competitors where data permits.
6. Test sensitivity to volume, component price, yield and channel mix.
7. Connect cost structure to pricing and gross-margin logic.

## Model
```text
Revenue
 ├─ Channel / distribution
 ├─ Product COGS
 │   ├─ Electronics
 │   ├─ Mechanical
 │   ├─ Sensors / actuators
 │   ├─ Core process components
 │   ├─ Assembly / calibration
 │   └─ Packaging / logistics
 └─ Service / warranty
```

## Rules
Every estimated number must include its basis, range and confidence.

# Future Analysis Model

## Objective
Future Outlook 必须由证据、瓶颈、技术能力和竞争压力推导，而不是泛泛预测趋势。

## Core Chain
```text
Current State
 ↓
Unresolved Problems / Bottlenecks
 ↓
Evolution Drivers
 ↓
Technology Enablers
 ↓
Existing Company Capabilities
 ↓
Competitive / Economic Pressure
 ↓
Likely Evolution
 ↓
Strategic Consequence
```

## Required Questions
- 当前能力边界在哪里？
- 当前最重要的瓶颈是什么？
- 为什么该瓶颈必须被解决？
- 哪些技术可能成为 Enabler？
- 公司已经拥有哪些相关能力？
- 哪些能力需要补齐？
- 近端 1–2 年最可能发生什么？
- 中期 2–4 年可能发生什么？
- 长期有哪些条件性 Scenario？
- 哪些证据会支持或否定该判断？

## Forecast Classification
- **Fact:** 已发生、已发布或已验证。
- **Trend:** 多个独立事实共同指向的方向。
- **Inference:** 根据现有能力和约束推导。
- **Scenario:** 条件成立时可能出现的未来状态。
- **Estimate:** 有明确假设的量化预测。

## Scenario Format
```text
Scenario
├─ Trigger / Enabler
├─ Required Capability
├─ Likely Product Change
├─ User / Economic Impact
├─ Competitive Impact
├─ Strategic Impact
└─ Invalidation Risks
```

## Roadmap Principle
不要写：
> AI 会越来越重要。

应写：
> 当前已经形成 X 能力 → Y 是主要瓶颈 → Z 技术能够缓解该瓶颈 → 因此下一代产品更可能向 A 能力演进；该判断属于 Inference / Scenario，而非官方 roadmap。

## Chapter Handoff
Future Outlook 必须引用前文已经建立的：
- Technology Clusters
- Product Capabilities
- Competitive Position
- Manufacturing / Economic constraints
- Ecosystem capabilities

未来判断若无法连接这些输入，应降低结论强度或标记 Unknown。

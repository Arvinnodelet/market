### 业务背景

大疆进入扫地机器人赛道是基于核心技术能力的横向延展。公司在无人机领域积累的**空间感知、实时 SLAM、毫米级避障、多传感器融合、电机伺服控制**等能力，恰好是高端扫地机器人面临的核心技术瓶颈。ROMO 系列的感知系统直接沿用了旗舰无人机 Mavic 4 Pro 的同源算法。

## 七、技术特色与核心优势

### 1. 无人机基因的感知能力

大疆将旗舰无人机 Mavic 4 Pro 同源的**空间感知、多传感器融合、实时 SLAM、AI 语义推理**算法下放至地面清洁机器人。ROMO 2 搭载的散斑 LiDAR + 双目鱼眼 + ToF 融合架构，本质上是将无人机"看世界"的方式平移到了扫地机上。

##### 面阵散斑投影 LiDAR — 破解透明物体识别的关键

**工作原理**

传统 ToF 和结构光方案在透明物体（玻璃/镜子）面前失效的根本原因是光学特性异常：红外光大部分穿透玻璃、可见光在镜面产生单向反射，传感器收不到有效回波。DJI 的解决方案是用**散斑图案的畸变来间接探测透明表面**。

```
传统方案（失效）                        DJI 散斑 LiDAR（有效）

发射红外光脉冲            发射数万个红外散斑光点
      │                          │
      ▼                          ▼
┌─────────┐              ┌─────────┐
│ 玻璃    │              │ 玻璃    │
│ (4mm)   │              │ (4mm)   │
└─────────┘              └─────────┘
      │                          │
      ▼                          ▼
光直接穿透 → 无回波       散斑图案在玻璃表面
→ "看不到" → 撞上去 🔴     产生微弱畸变和反射
                           → 红外 CMOS 拍到畸变散斑
                           → 三角测量计算深度
                           → 深度图中出现"悬空平面"
                           → AI 推理："这是透明障碍"
                           → 绕行 ✅
```

**硬件实现**

| 参数 | 说明 |
|---|---|
| 光源 | 红外激光二极管（~850nm 不可见光） |
| 散斑生成 | 衍射光学元件（DOE），将单束激光扩束为随机散斑图案 |
| 接收器 | 红外 CMOS 图像传感器（分辨率未公开，估计 ~640×480） |
| 深度图类型 | **稠密深度图**（每个散斑点一个深度值，共数万个测点） |
| 测距原理 | 三角测量——散斑图案在物体表面的位置偏移与距离成正比 |
| 帧率 | 估计 15-30 fps（与无人机避障系统同源） |
| 安全等级 | Class 1（<0.39 mW，人眼安全） |

**为什么散斑方案能识别透明物体**

| 物理现象 | 传统 ToF / 结构光 | DJI 散斑 LiDAR |
|---|---|---|
| 红外光穿透玻璃 | 光脉冲直接穿过，无反射回波 → 测距失败 | 部分散斑点在玻璃表面发生微弱的**漫反射**和**干涉**，形成可探测的畸变图案 |
| 镜面反射 | 单束光以入射角=反射角射出 → 传感器收不到 | 数万个散斑点从多角度投射，总有部分能进入 CMOS 视场 |
| 纹理依赖 | 严重依赖物体表面纹理进行特征匹配 | **不依赖纹理**——散斑本身就是人造纹理，透明表面也产生响应 |
| 环境光 | 强环境光（阳光）可能淹没红外信号 | 窄带红外滤光片 + 主动调制光源，抗环境光干扰更强 |

##### 双目鱼眼视觉 — 语义理解与概念迁移

**工作原理**

左右两颗鱼眼摄像头（FOV 前视 170°、环绕感知 285°）形成双目立体视觉。利用左右视图的视差计算深度信息，同时通过 AI 模型对物体进行分类和语义理解。

**概念迁移（Concept Transfer）详解**

传统避障方案依赖预先训练的障碍物数据库——"数据库里有数据线 → 认识数据线 → 避开"。但家庭环境中的障碍物千变万化，不可能全部录入。

DJI 的概念迁移能力使 ROMO 能对**从未见过的物体**进行推理：

```
看到陌生物体
      │
      ▼
提取几何特征：形状、尺寸、表面材质（光滑/粗糙）、边缘特征
      │
      ▼
与已知类别进行类比推理：
  "这个东西 2mm 粗、柔软、弯曲 → 可能是线缆 → 绕行"
  "这个东西坚硬、尖锐、直立 → 可能是家具腿 → 保持距离"
  "这个东西透明、平面状 → 可能是玻璃门 → 绕行"
      │
      ▼
生成避障策略 → 执行
```

**与传统方案的对比**

| | 传统模板匹配 | DJI 概念迁移 |
|---|---|---|
| 数据库覆盖 | 依赖于预先标注的障碍物类型 | 基于几何和物理特征的推理 |
| 未知物体 | 无法识别 → 撞上去 | **推理 → 避让** |
| 适应性 | 每种新型障碍物需重新训练 | 无需更新模型即可处理新物体 |
| 误判风险 | 低（仅匹配已知类型） | 中（可能过度保守，绕过安全物体） |

##### 核心优势

1. **主动光源方案**不受环境光影响——白天/黑夜/窗帘拉上的表现一致
2. **散斑投影是透明物体探测的最优方案**——不像 ToF 依赖回波强度、不像 RGB 依赖纹理
3. **概念迁移**是真正的 AI 能力壁垒——竞争对手可以复制传感器硬件，但难以复制无人机数年积累的感知算法

##### 已知局限

1. **极端镜面反射角度（<15° 入射角）**仍可能漏检——散斑的大部分光被反射到其他方向
2. **对大型家具（如沙发、餐桌）过度保守**——保持 10-15cm 安全距离绕行，留下大片清洁盲区
3. 透明亚克力**外壳易产生划痕**——可能影响视觉传感器（双目鱼眼）的长期成像质量
4. 液体识别的**可靠性受地面颜色影响**——深色地板 + 暗光环境可能漏检水渍

#### 2.2 无滤网基站自清洁系统深度拆解 🔧

无滤网基站自清洁是 ROMO 在基站维护体验上的根本性创新。传统方案依赖"清洗 + 过滤"循环，滤网是必然的故障点——DJI 的方案是**直接取消滤网，让脏污没有机会沉积**。

##### 传统基站为何必然发臭：滤网悖论

```
传统基站清洗流程：
  洗拖布 → 脏水经滤网过滤 → 污水进污水箱
           │
           ▼
      ┌─────────┐
      │  滤网    │  ← 泥沙/毛发/碎屑堆积
      │  1-4 周后 │     （滤网孔径通常 0.5-1mm）
      │  堵塞     │
      │  细菌滋生 │
      │  发臭     │  ← 这是用户的核心投诉
      └─────────┘

  解决方式：
    方案 A: 用户定期手洗滤网 + 刷洗托盘 → "说好的解放双手呢？"
    方案 B: 100°C 高温煮洗抑菌 → 治标，滤网堵塞问题依然存在
    方案 C: 取消滤网 → DJI 的选择 ✅
```

##### DJI 方案：物理结构规避，而非化学方式缓解

**核心思路**：如果吸污口足够大、水流足够强，脏污会直接被冲进污水箱，不需要滤网。

| 组件 | 参数 | 作用 |
|---|---|---|
| **吸污口** | **16 mm** 直径（竞品 10-12mm） | 泥沙/毛发/碎屑直接通过，不被拦截 |
| **四路高压水柱** | 覆盖拖布表面 + 边缘 + 底盘各角度 | 同时冲洗拖布和基站底盘，全方位清洁 |
| **清洗下压力** | 12 N | 模拟人手按压拖布，提升摩擦清洗效果 |
| **纳米微晶盾基座** | 纳米级微晶结构材质 | 微观表面致密光滑，污渍不浸润、不渗透、不附着 |
| **热水温度** | 80°C | 提升油脂溶解效率，辅助抑菌 |

**清洗流程**：

```
① 机器人返回基站 → 拖布对准清洗区
② 基站注入 80°C 热水 + 清洁液（P 系列双舱：去污 + 除菌）
③ 四路高压水柱从不同角度同时冲洗拖布和底盘
   （拖布旋转 + 12N 下压 → 模拟手搓）
④ 16mm 吸污口同步抽吸污水 → 脏污直接入污水箱
⑤ 无滤网 → 无沉积 → 无需清洗底盘
⑥ 热风烘干 → 基站和拖布均保持干燥
```

##### 8.5cm 动态自适应越障系统

**工作原理**

动态自适应机械足的越障过程分为三个连续阶段——感知、决策、执行：

```
阶段 1：感知              阶段 2：决策             阶段 3：执行
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ LiDAR 扫描    │     │ AI 分类      │     │ 跨障动作      │
│              │     │              │     │              │
│ 测量门槛高度  │────▶│ <4cm → 直接过 │────▶│ 前轮动态抬升   │
│ 评估门槛宽度  │     │ 4-6cm → 抬升  │     │ 后轮扭矩增大   │
│ 判断门槛材质  │     │ >6cm → 绕行   │     │ 拖布同步抬升   │
│              │     │              │     │ 吸力降低减载   │
└──────────────┘     └──────────────┘     └──────────────┘

双层连续越障（8.5cm 的由来）：
  ┌──── 第一层 ────┐         ┌── 第二层 ────┐
  │  ≤ 4 cm       │         │  ≤ 4.5 cm    │
  │  (如压边条)    │         │  (如门槛)     │
══╧════════════════╧═════════╧══════════════╧══

  ① 检测第一层 → 前轮抬升 → 跨越 → 后轮跟进
  ② 检测第二层 → 重复流程 → 跨越
  ③ 两轮悬挂独立控制，互不干扰
  ④ 跨越时拖布抬升（避免卡住）+ 吸力降低（减少电机负载）
```

**硬件实现**

| 组件 | 说明 |
|---|---|
| **前轮悬挂** | 独立舵机控制，可主动抬升 0-45mm |
| **后轮悬挂** | 独立悬挂 + 扭矩分配，前轮抬升时后轮动力增大 |
| **底盘高度传感器** | 实时监测离地间隙，避免底盘托底 |
| **姿态传感器** | IMU（惯性测量单元），监测爬升角度，防止翻覆 |
| **控制策略** | 先检测 → 分类 → 选择策略 → 执行 → 确认通过 → 恢复姿态 |

##### 核心优势

1. **双层连续越障策略**是 ROMO 独有——其他品牌标注的是单层最高高度，ROMO 标注的是双层组合高度，实际场景（门槛+压边条组合）通过性更强
2. **预判式抬升**——LiDAR 提前感知门槛，在到达前即开始抬升前轮，而非被动撞上后硬爬
3. **跨越时自动降吸力**——减少电机负载，留出功率裕量给行走电机

##### 已知局限

1. 活动部件（摆臂电机 + 机械足舵机）的**长期可靠性待验证**——ROMO 2 上市仅一个月
2. 机械足抬升机构增加了机身高度（98mm），在**低矮家具场景（<10cm）**不如石头 G30（79.5mm）
3. 跨越厚地毯边缘时可能**判断失误**（地毯被识别为可跨越障碍），导致拖布沾污地毯
4. S V2 **不具备机械足**——这是 ROMO 2 系列明显的产品线割裂

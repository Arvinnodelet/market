## 2. 产品技术架构

### 2.1 子系统评估

| 子系统 | ROMO P2 指标 | 段位均值（高端） | 自研？ | 评估 |

| **吸力** | 36,000 Pa | 22,000–30,000 Pa | ✅ 自研 9 叶金属风机 | **Leading** |
| **避障** | 散斑 LiDAR + 双目鱼眼 + ToF + AI 语义 | 3D 结构光 / RGB 单目 | ✅ 无人机同源算法 | **Leading** |
| **边角清洁** | 123° 外摆机械臂 + 独立 LiDAR 定位 | 伸缩机械臂 / 外扩拖布 | ✅ 自研 | **Leading** |
| **越障** | 8.5cm 双层连续 + 动态机械足 | 2-8cm | ✅ 自研 | **Competitive** |

**技术评估**：4 项 Leading、3 项 Competitive、1 项 Behind。整体技术实力强劲，但**拖地和机身厚度是明显短板**。

### 2.2 核心差异化技术

#### ① 智能避障 2.0 — 行业唯一系统解决透明物体

```
传统方案痛点：
  结构光遇到玻璃 → 反射异常 → "看不到" → 撞上去
  单目 RGB 遇到透明水杯 → 没有纹理 → "认不出" → 撞上去

DJI 方案：
  散斑 LiDAR 主动投射红外散斑图案
  → 图案在透明表面仍产生可探测的形变
  → 双目鱼眼从不同角度交叉验证
  → AI 推理："这里有个透明障碍物"
  → 绕行
```

**实测数据**（什么值得买 2026 横评）：
- 透明玻璃门识别率：DJI **95%+** / 石头 ~30% / 科沃斯 ~20%
- 2mm 数据线识别率：DJI **~100%** / 石头 ~83%（暗光仅 ~60%）/ 追觅 ~100%
- 暗光综合表现：DJI **稳定**（主动光源）/ 石头识别率下降 30% / 科沃斯下降 30%

#### ② 无滤网基站自清洁 — 重新定义基站维护标准

```
传统基站：                          DJI 基站：
┌─────────────────┐          ┌─────────────────┐
│ 拖布在托盘上清洗  │          │ 四路高压水柱直冲   │
│ 脏水经滤网过滤   │          │ 16mm 大口径吸污    │
│ 滤网需手动清洗   │          │ 脏污直接进污水箱   │
│ （每 1-4 周一次）│          │ 无滤网 无需清洗    │
│ 托盘发臭 → 差评  │          │ 365 天免维护      │
└─────────────────┘          └─────────────────┘
```

> 💡 这是解决扫地机用户**最大日常痛点**（基站发臭需要手动清洗）的工程创新。竞品如追觅用 100°C 高温煮洗来缓解，但本质仍是"洗得更干净"而非"不需要洗"。

### 3.3 一代退货潮事件

> ⚠️ **2025 年 9 月（上市仅 35 天）**：凤凰科技报道 ROMO 遭遇首批用户集中退货：
> - 核心原因：清洁性能与宣传差距大 + 售后体验差
> - 首批用户期待值极高（大疆品牌光环 + ¥5,000+ 定价），但实际清洁体验不如 ¥3,000 的石头
> - 同期安全事件：有人"意外"入侵了 7,000 台 ROMO 系统
> - 大疆通过固件更新逐步改善，但硬件问题（漏扫、划痕）无法 OTA 修复

**对 ROMO 2 的影响**：
- ROMO 2 通过机械臂 + 越障机械足解决了部分一代的清洁覆盖问题
- 但圆盘拖布方案未变，"以脏拖脏"问题依然存在
- 售后和品控能否改善是二代口碑的关键变量

## 4. 制造与供应链视角

| 维度 | 评估 |
|---|---|
| **代工** | 初期由福日电子旗下广东以诺通讯代工，大疆自建产线可能在规划中 |
| **BOM 估算** | 约 ¥2,200–2,800（基于同价位竞品 BOM 反推 + DJI 传感器溢价） |
| **其中传感器模组** | 散斑 LiDAR + 双目鱼眼 + 面阵 ToF + 机械臂 LiDAR ≈ ¥400–600 |
| **组装复杂度** | 高 — 4 个 LiDAR/ToF 模组需要出厂精密标定，机械臂/机械足增加装配工序 |
| **DFM 质量** | 良 — 无滤网基站减少零件数，但透明外壳对注塑和装配精度要求高 |
| **可维修性** | 中 — 透明外壳更换需返厂（¥168），用户不可自行更换 |
| **毛利率估算** | ~55-63%（(MSRP ¥5,999 − BOM ~¥2,500) ÷ ¥5,999） |

> 💡 DJI 的毛利率在行业中处于较高水平（石头 ~50%，科沃斯 ~45%），但传感器标定产能可能成为起量瓶颈。每台 ROMO P2 搭载 4+ 个光学传感器，标定工序时间长于传统单 LiDAR 机型。

### 7.1 行业大环境

| 指标 | 数据 | 趋势 |

| 高端市场（¥4k+） | 20.7%（-8.1pp） | ↘ 份额收缩 |

### 7.2 DJI 的机会窗口

1. **iRobot 衰退留下的海外空白**：iRobot 2025 年陷入破产重组，欧美市场出现真空，中国品牌集体出海。DJI 凭借已有海外渠道占据有利位置
2. **AI 大模型赋能**：大疆无人机 + 扫地机数据可以协同训练感知模型，形成跨品类数据飞轮（目前无竞品有此能力）
3. **行业从价格战转向技术战**：消费者越来越愿意为真正解决痛点的创新买单（2024 年 ¥4,000+ 价格段显著增长），DJI 的技术差异化策略可能在下半场受益
4. **三线以下城市渗透**：国内扫地机渗透率仅 6-12%，下沉市场是巨大增量 — 但需要 DJI 推出中端产品

### 7.3 DJI 面临的结构性挑战

1. **高端市场规模收缩**：¥4,000+ 份额 2025 年同比下降 8.1pp，DJI 固守的阵地正在缩小
2. **"技术普惠"不可逆**：AI 避障、热风烘干等高端功能正快速下沉至 ¥2,000-3,000 区间，DJI 的技术差异化窗口期在缩短
3. **品牌溢价有限**：扫地机是实用型家电而非潮流消费品，消费者对"为品牌多付 ¥1,000"的意愿低于无人机
4. **一代口碑遗留问题**：退货潮和售后差评可能影响 ROMO 2 的潜在买家决策

### 8.3 战略建议

**短期（12 个月）**：
1. **解决 ROMO 2 的品控和售后问题** — 这是口碑扭转的关键窗口，再来一次退货潮将严重损害品牌
2. **固件更新提升拖地策略** — 增加回洗频率、优化"先干后湿"逻辑，部分弥补圆盘拖布的先天不足
3. **加速海外上市** — 利用 iRobot 衰退窗口，优先攻占欧美 ¥5,000+ 高端市场

**中期（1-2 年）**：
4. **推出 ¥3,000-4,000 中端机型** — 必须进入 62.6% 的核心市场。可以用"简配传感器（去掉散斑 LiDAR，保留双目鱼眼）+ 保留基站自清洁"的方式降本
5. **开放智能家居生态** — 接入 HomeKit / 米家 / HA，降低生态壁垒导致的用户流失
6. **探索滚筒活水拖地方案** — 如果下一代仍用圆盘拖布，拖地能力将长期落后科沃斯

**长期（3 年+）**：
7. **建立扫地机品类的用户信任** — 无人机靠性能说话，扫地机靠可靠性说话。需要积累 3-5 年的可靠性口碑
8. **全屋机器人平台** — 扫地机器人只是"地面无人机"，未来可扩展到空气净化、安防巡逻、老人看护等多模态家庭机器人

## 9. 购买建议（Buy / Consider / Skip）

### 🟢 Buy — 适合以下用户

- **透明隔断/玻璃家具多的家庭**：DJI 是唯一系统解决透明物体识别的品牌
- **养宠 + 地面杂物多**：2mm 线缆、宠物粪便、玩具等避障需求最强的场景
- **极度厌恶基站维护**：365 天免维护是真实存在的差异化，不是营销噱头
- **大疆品牌粉丝**：如果你已有无人机，对 DJI 的工程能力有信任，ROMO 不会让你失望

### 🟡 Consider — 可以观望

- **大户型（150m²+）**：避障和免维护优势有吸引力，但清洁效率低的问题需要考虑
- **预算 ¥5,000 左右**：如果避障和颜值是你最看重的因素，值得考虑；否则石头 G30 更划算
- **想买但担心品控**：建议等 ROMO 2 上市 3 个月后看真实用户口碑再决定

### 🔴 Skip — 不建议

- **预算 <¥3,500**：完全不在 DJI 覆盖范围内，选石头 P20 或米家
- **对拖地效果要求高**：滚筒活水方案（科沃斯 X11 Pro）或追觅 100°C 煮洗更适合
- **低矮家具多（<10cm 缝隙）**：ROMO 98mm 进不去，选石头 G30（79.5mm）
- **需要全屋智能联动**：DJI 生态封闭，选石头（米家生态）或科沃斯

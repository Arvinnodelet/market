## 4. 技术能力深度分析

> 💡 大疆扫地机的核心战术是 **"无人机技术降维"**——将 Mavic 4 Pro 同源的感知、避障和路径规划算法应用于地面清洁场景。

### 4.1 子系统评估

| **清洁系统** | **Competitive** | 36,000 Pa 吸力行业最高，但圆盘拖布方案不如滚筒活水方案深度去污 |

### 4.2 核心技术创新深度拆解

#### 4.2.1 智能避障 2.0 — "降维打击"的技术逻辑

**工作原理**：

```
┌─────────────────────────────────────────────────────────┐
│                    DJI ROMO 2 感知架构                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   ┌──────────────────┐    ┌──────────────────┐          │
│   │  双目鱼眼摄像头    │    │  面阵散斑投影LiDAR  │          │
│   │  (170° 前视)      │    │  (主动红外测距)     │          │
│   │  (285° 环绕)      │    │  (透明/反光物体)    │          │
│   └──────┬───────────┘    └──────┬───────────┘          │
│          │                       │                       │
│          └───────────┬───────────┘                       │
│                      ▼                                   │
│          ┌──────────────────┐                            │
│          │  多模态融合感知    │  ← 无人机同源算法           │
│          │  (视觉 + 深度 +   │                            │
│          │   ToF + 语义)     │                            │
│          └──────┬───────────┘                            │
│                 ▼                                        │
│   ┌─────────────────────────────┐                        │
│   │     AI 语义推理引擎           │                        │
│   │  • 290+ 类障碍物识别          │                        │
│   │  • 未见过物体 → 概念迁移推理   │  ← 核心差异化           │
│   │  • 场景决策（绕/跨/清洁）      │                        │
│   └─────────────────────────────┘                        │
│                                                         │
│   侧面补充：面阵 ToF（沿边）+ 底部显尘灯（2000cm²）         │
└─────────────────────────────────────────────────────────┘
```

**硬件实现**：
- 面阵散斑投影激光雷达：主动投射红外散斑图案，通过图案形变计算深度。不依赖物体纹理或环境光——这是识别透明玻璃的关键（传统方案依赖纹理匹配，面对透明物体失效）
- 双目鱼眼：广角感知场景语义，分类物体类型（线缆/宠物粪便/液体/家具）
- 面阵 ToF：侧面补盲，确保沿边清洁时不出盲区

**与竞品方案对比**：

| 方案 | DJI ROMO 2 | 石头 P20 Max | 科沃斯 X11 Pro | 追觅 X60 Pro |
|---|---|---|---|---|
| **传感器** | 散斑 LiDAR + 双目鱼眼 + ToF | 3D 结构光 + RGB | 单目 RGB + 结构光 | 双目 RGB + 侧结构光 |
| **透明物体** | ✅ 95%+ | ❌ 易误判 | ❌ 易漏检 | 部分支持 |
| **细线识别** | 2mm | ~5mm | 弱 | 3mm |
| **暗光表现** | 稳定（主动光源） | 识别率下降 30% | 下降 ~30% | 良好 |
| **AI 推理** | 概念迁移（未见过物体也能推理） | 规则匹配为主 | 规则匹配为主 | 规则匹配为主 |

**优势**：
- 主动光源方案不受环境光影响，夜间清扫表现一致
- 散斑投影解决透明物体死角（传统 ToF/结构光在玻璃表面反射率异常）
- 概念迁移推理：传统方案"没见过 = 不认识"，DJI 方案可基于物体几何特征推理

**局限**：
- 散斑 LiDAR 增加 BOM 成本（估算 +80-120 元 vs 单结构光方案）
- 多传感器融合对 ISP/NPU 算力要求高，增加 SoC 选型约束
- 镜面反射极端角度（<15° 入射角）仍可能漏检

#### 4.2.2 123° 超幅外摆机械臂 — 边角覆盖的机械创新

**工作原理**：

         └──────────────────────────────────┘

   静止状态：                      外摆状态（123°）：
   ┌──────────┐                   ┌──────────┐
   │  ●●●●●●  │                   │  ●●●●●●  │
   │  ● ROMO● │                   │  ● ROMO● │
   │  ●      ●│                   │  ●    ◄──┼─── 机械臂外摆 123°
   │  ●●●●●●  │                   │  ●●●●●●  │
   └──────────┘                   └──────────┘

   桌腿环绕清洁：
      ┌─┐
      │█│ ← 桌腿          ROMO 靠激光雷达探测腿位

**硬件实现**：
- 独立激光雷达专用于机械臂定位（区别于主避障雷达）
- 主动摆臂电机 + 位置编码器，实现 123° 精密角度控制
- 机械臂末端搭载拖布模块，12N 恒定下压力

**与竞品方案对比**：

| 方案 | DJI ROMO 2 | 石头 G30 | 追觅 X60 Pro |
|---|---|---|---|
| **边角策略** | 主动外摆机械臂（123°） | 伸缩机械臂（线性） | 旋转拖布外扩 |
| **覆盖增量** | +4.5 cm/摆幅 | +2-3 cm | +1-2 cm |
| **桌腿环绕** | ✅ 独立雷达定位 + 画圈 | ❌ 仅沿边贴合 | ❌ 仅沿边贴合 |
| **机械复杂度** | 高（独立雷达 + 摆臂电机） | 中 | 低 |

**优势**：边角覆盖率行业最高，桌腿环绕清洁独有功能

**局限**：活动部件增加长期可靠性风险；摆臂机构占用机身内部空间，推高整机高度（98mm）

#### 4.2.3 8.5cm 动态自适应越障 — 从"扫地机"到"越野车"

**工作原理**：

```
    ┌──── 门槛（4cm）────┐         ┌── 第二门槛（4.5cm）──┐
    │                    │         │                      │
  ══╧════════════════════╧═════════╧══════════════════════╧══
  
  ① LiDAR 预判门槛高度 → ② 前轮机械足抬升 → ③ 跨越第一层
  → ④ 后轮跟进 → ⑤ 重复流程跨越第二层
  
  动态自适应逻辑：
  - 识别障碍物类型（门槛/滑轨/压边条/地毯边缘）
  - 根据高度选择策略：<4cm 直接跨越 / 4-6cm 抬升跨越 / >6cm 绕行
  - 跨越时调整吸力（降低电机负载）+ 抬升拖布（避免拖布卡住）
```

**硬件实现**：
- 前轮 + 后轮独立悬挂，每个轮组可主动抬升
- 底盘高度传感器实时监测离地间隙
- 跨越时动力分配：前轮抬升时后轮扭矩增大

**行业对比**：

| 机型 | 越障能力 | 实现方式 |
|---|---|---|
| **DJI ROMO P2** | **8.5 cm**（双层连续） | 主动抬升机械足 + 预判 |
| 石头 P20 Max | 8.8 cm | AI 轮足 |
| 追觅 X60 Pro | 8 cm | 仿生机械足 |
| 科沃斯 X11 Pro | 2.4 cm | 被动悬挂 |
| iRobot Roomba j9 | 2.0 cm | 被动悬挂 |

**优势**：8.5cm 覆盖绝大多数中国家庭门槛（常见的阳台滑门轨道 4-6cm、过门石 2-4cm）

**局限**：机械足长期可靠性待验证；抬升机构增加机身高度

## 5. 生态系统

| 组件 | 成熟度 | 锁定强度 | 评估 |
|---|---|---|---|
| **DJI Home App** | 中等 | 中 | 像素风 UI 好评度高，脏污热力图创新，但功能积累少于石头/科沃斯 |

> ⚠️ 大疆目前的生态策略是"封闭但高质量"——App 自研、配件自营、不上第三方平台。这与无人机业务模式一致，但在扫地机领域，消费者对 HomeKit/米家联动有真实需求。

| **自动化水平** | 高 | 无人机产线自动化经验丰富，传感器校准设备自研 |
| **质量一致性** | 待验证 | 一代 ROMO 上市仅 10 个月，长期可靠性数据不足 |
| **供应链韧性** | 中 | 受中美贸易摩擦影响（已在实体清单）。扫地机主要面向国内，影响可控 |
| **DFM 质量** | 强 | 无滤网基站设计减少装配工序；透明外壳对注塑精度要求高，倒逼工艺提升 |

**评估**：强 — 无人机业务积累的精密制造 + 供应链管理能力可直接复用。唯一隐忧是扫地机业务若起量，传感器校准产能可能成为瓶颈（每台机器需要激光雷达 + 双目相机联合标定）。

## 10. 战略评估

### 维度评估

```
产品组合：         Adequate — 6 款产品覆盖中高端，缺入门档，9 个月迭代快
技术：             Leading — 避障 + 基站自清洁行业领先，拖地/厚度待加强
生态：             Weak — App 精致但封闭，智能家居集成严重不足
制造：             Strong — 无人机制造经验复用，垂直整合能力强
商业模式：         Adequate — 传统硬件模型，耗材贡献低，无订阅
竞争地位：         ↗ Rising — 8 个月进入前 6，技术溢价支撑定价
```

### SWOT

**优势**：
1. 无人机同源感知技术 — 竞品难以短期复制（算法 + 传感器融合需要多年积累）
2. 无滤网基站设计 — 解决了基站发臭的核心用户痛点，365 天免维护为行业树立新标准
3. 品牌溢价能力 — DJI 品牌在消费电子领域号召力强，支撑高 ASP 定价

**劣势**：
1. 扫地机行业经验短 — 一代→二代仅 10 个月，长期可靠性和售后体系待验证
2. 机身厚度 98mm — 高于石头 G30（79.5mm），限制低矮家具场景
3. 生态封闭 — 不支持 HomeKit/米家/HA，对智能家居用户不友好

**机会**：
1. 海外市场 — 韩国已进入，欧美扫地机市场 iRobot 衰退留下空白
2. AI 大模型 — 无人机 + 扫地机数据协同训练感知模型（跨品类数据飞轮）
3. 大盘萎缩中洗牌 — 行业下滑淘汰弱玩家，DJI 资金和技术储备充足

**威胁**：
1. 石头科技 — 行业龙头，越障 8.8cm 已反超，下代可能全力补避障
2. 价格战 — 中国扫地机市场品牌集中度下滑（CR5 跌 4pp），新玩家涌入可能触发价格战
3. 消费者信任 — 一代用户面临快速迭代，可能产生"被割韭菜"的负面口碑

### 综合判断

```
12 个月轨迹：    ↗ Accelerating — 市场份额继续上升，预计进入前 5
3 年展望：       Bullish — 若海外拓展顺利，有望进入行业前三
关键理由：       大疆的核心壁垒不是某一代产品，而是无人机积累的感知算法 +
                快速工程迭代能力。只要这个优势不衰减，每一代 ROMO 都会
                比上一代显著更强。真正的风险是生态锁入不足导致用户流失。
```

## 11. 关键工程权衡

1. **主动光源避障 vs 机身厚度** → DJI 选择了散斑 LiDAR + 双目鱼眼的主动光源方案（98mm 厚），牺牲了石头（79.5mm）的超薄优势。主动光源在暗光和透明物体场景下表现一致，但增加了机身高度
2. **机械臂覆盖率 vs 可靠性** → 123° 摆臂提供了行业最高的边角覆盖，但活动部件 + 独立雷达增加了故障点
3. **无滤网基站 vs 极端脏污** → 16mm 大口径 + 四路水柱在常规场景出色，但面对粘性脏污（如宠物呕吐物）可能需要人工干预
4. **快速迭代 vs 用户忠诚度** → 9 个月迭代快于行业（12-14 月），技术领先但也让一代用户感到快速过时
5. **封闭生态 vs 体验完整性** → 自研 App 体验精致，但拒绝接入 HomeKit/米家限制了全屋智能场景

## 1. 各组件粘接需求总述

本项目激光位移传感器有三个关键粘接部位，需求完全不同：

| 粘接部位 | 涉及器件 | 核心要求 | 关键挑战 |
|---------|---------|---------|---------|
| **激光器 TO-Can** | 华光光电 HGLD-650TO5.6-JP-5mW (Φ5.6mm) | 低释气、耐高温、阴影区固化 | TO 管座法兰遮挡 UV 光，存在阴影区；挥发物污染激光器端面 |
| **接收镜片** | 接收成像透镜组 | 低收缩(<1%)、光学透明 @650nm、对准稳定性 | 固化收缩导致镜片偏转 → 光斑在 CMOS 上移位 → 测量误差放大 |
| **CMOS Sensor 板** | Hamamatsu S13131-1536 (9.1×2.4×0.8mm) | 低应力、CTE 匹配、低释气 | 硅(3ppm/°C) vs PCB(14-17ppm/°C) 热膨胀失配 → 芯片翘曲 → 像素面倾斜 |

## 2. 胶水选型推荐

### 2.1 激光器 TO-Can 粘接

TO-56 封装激光器与安装座之间的粘接面临**阴影区固化**问题——TO 管座的法兰盘背面和管座侧壁无法被 UV 光照射到。

**首选方案：双固化体系（UV 预固定 + 热固化）**

| 推荐产品 | 类型 | 关键参数 | 理由 |
|---------|------|---------|------|
| **DELO DUALBOND OB786** ⭐ | 改性环氧，UV+热双固化 | 收缩 1.6vol%，Tg=179°C，CTE=38ppm/K，**通过 NASA ASTM E595 低释气** | 专为激光器组装设计，4秒 UV 预固定，阴影区热固化，NASA 级低释气 |
| **LOCTITE STYCAST OS 5101** | 环氧，UV+热双固化 | Tg=137°C，CTE≈20ppm/K，收缩<1%，吸水率 0.8% | 专为 TO-Can 预固定设计，极低 CTE |
| **EPO-TEK 353ND** | 双组分环氧，纯热固化 | Tg≥90°C，使用温度 -55~225°C，通过 NASA 低释气 | 光纤行业"金标准"，800-1000nm 透过率>98%，但不支持 UV 预固定 |
| **EPO-TEK HYB-353ND** | 混合型，UV+热固化 | 同 353ND 体系，支持 UV 预固定 | 353ND 的 UV 预固定版本，预混冷冻针筒包装 |
| **3M Scotch-Weld 3581** | 改性环氧，UV+热双固化 | 收缩 0.9%，Tg=139°C，CTE=40 ppm/°C | ⚠️ 释气性未标注 NASA 认证，详见[第3章分析](#32-3m-scotch-weld-3581) |

> **推荐：DELO DUALBOND OB786**——双固化解决了 TO-Can 阴影区问题，NASA 级低释气保护激光器端面，高 Tg(179°C) 保证热稳定性。

### 2.2 接收镜片粘接

接收镜片将激光光斑成像到 CMOS 传感器上。镜片微小的角度偏移会被光学杠杆放大，导致光斑在传感器上的位置漂移——直接影响测量精度。

**核心要求：固化收缩率 <1%，光学透明 @650nm**

| 推荐产品 | 类型 | 关键参数 | 理由 |
|---------|------|---------|------|
| **Norland NOA 61** ⭐ | UV 固化，单组分 | 收缩率低，符合 **MIL-A-3920** 军标，折射率 1.56，粘度 300cps | 军工级光学胶，精密透镜胶合，玻璃-金属粘接 |
| **Norland NOA 63** | UV 固化，单组分 | 低收缩，低荧光，UV 透过性好 | 消色差透镜组、棱镜、厚截面固化 |
| **DELO DUALBOND OB6769** | 改性环氧，UV+热双固化 | 低收缩可预测，通过 NASA 低释气 | 专为 FAC/SAC 透镜主动对准设计 |
| **Dymax 9906-AA** | UV+热双固化 | 低收缩，高触变性 | 摄像头模组主动对准专用 |
| **3M Scotch-Weld 3581** | 改性环氧，UV+热双固化 | 收缩 0.9%，Tg=139°C | ⚠️ 颜色偏黄/琥珀色，650nm 透过率需验证 |

> **推荐：Norland NOA 61**——对于接收镜片（无阴影区问题），单组分 UV 胶工艺最简单，军标认证可靠性有保障，固化仅需 3-5 秒。

### 2.3 CMOS Sensor 板粘接

Hamamatsu S13131-1536 传感器封装尺寸 9.1×2.4×0.8mm，超薄封装对翘曲极为敏感。传感器像素面倾斜 1μm → 测量误差放大（取决于光学倍率）。

**核心要求：超低应力、CTE 匹配、低温固化**

| 推荐产品 | 类型 | 关键参数 | 理由 |
|---------|------|---------|------|
| **Zymet 超低应力芯片粘接胶** ⭐ | 环氧，热固化 | 曲率半径从 1000mm 改善至 100,000mm（对比传统胶） | 专为 CCD/CMOS 图像传感器设计，吸应力能力业界最优 |
| **Yongoo Y-Bond S751** | 环氧，热固化 | 通过 Tg、CTE、模量调谐控制翘曲 | 14 年图像传感器粘接研发经验 |
| **LOCTITE ABLESTIK ABP 8420** | 非导电芯片粘接胶 | 低应力，低温固化 | Henkel 摄像头模组产品线，供应链成熟 |
| **Henkel CCM 低温固化系列** | 环氧 | 固化温度 70-90°C，低释气 | 与 ABLESTIK 系列配套，完整 CCM 方案 |
| **3M 6011NS Black** | 环氧，纯热固化 | 60°C 低温固化，黑色防杂散光 | ⚠️ 关键参数缺失严重，详见[第3章分析](#31-3m-scotch-weld-6011-系列) |

> **推荐：Zymet 超低应力芯片粘接胶**——专为图像传感器翘曲问题设计，曲率半径提升 100 倍，对 S13131-1536 这种超薄传感器尤为重要。

## 4. 粘接工艺方法与参数

### 4.1 总体工艺流程

```
基材表面处理 → 精密点胶 → 主动对准 → UV 预固定 → 热固化 → 固化后检测
```

### 4.2 表面预处理

这是**最容易被忽视但最关键的步骤**：

| 步骤 | 方法 | 参数 | 目的 |
|------|------|------|------|
| 1. 溶剂清洗 | IPA（异丙醇）或无水乙醇擦拭 | 无尘布，单向擦拭 | 去除油污、指纹 |
| 2. 等离子清洗 | Ar/N₂ 等离子体 | 40kHz，200W，接触角 <5° | 激活表面能，大幅提升粘接力 |
| 3. 表面能验证 | 达因笔测试 | ≥48 达因/cm（金属）、≥40（玻璃） | 确认表面达到粘接要求 |

> ⚠️ **等离子清洗后必须在 30 分钟内完成点胶**，否则表面能衰减，效果大打折扣。

### 4.3 激光器 TO-Can 粘接工艺

```
对准（监测激光功率/光斑位置）
  ↓
UV 预固定 — 365nm LED, 150mW/cm², 4s（仅固定位置）
  ↓
热固化 — 130°C, 10min（阴影区完全固化）
  ↓
暗反应等待 — 静置 2-4h
  ↓
检测 — 光斑位置漂移验证
```

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 胶层厚度 | 50–100 μm | 过厚增加收缩量，过薄强度不足 |
| UV 预固定 | 365nm LED, 150mW/cm², 4s | 仅固定位置，不完全固化 |
| 热固化 | 130°C, 10min（OB786） | 阴影区完成交联 |
| 点胶量 | 按法兰面积计算，约 0.5–2μL | 避免溢胶到激光器出光面 |

**注意事项**：
- TO-Can 法兰盘背面是典型阴影区，**绝不能使用纯 UV 固化胶**
- 固化后需静置 2-4 小时让"暗反应"（dark reaction）完成，期间持续监测光斑位置
- 每日生产前需**标定该批次胶水的收缩率**，更新对准补偿偏置量（Fraunhofer IPT 推荐方法）

### 4.4 接收镜片粘接工艺

```
精密点胶（3-4 点对称分布）
  ↓
镜片就位
  ↓
主动对准（实时监测光斑在 CMOS 上的位置）
  ↓
微调至最佳位置
  ↓
渐变 UV 固化（关键！）
  ├─ 阶段 1：低功率 ~5 mW/cm², ~5s → 表皮固化
  └─ 阶段 2：高功率 ~1500 mW/cm², ≥20s → 深层固化
  ↓
固化后检测（30min 后复测光斑位置）
```

| 要点 | 方法 | 原因 |
|------|------|------|
| **对称点胶** | 3-4 点均布，非整圈连续涂布 | 不对称胶量 → 不对称收缩力 → 镜片倾斜 |
| **渐变 UV 引发** | 先低功率脉冲固化，再高功率全固化 | 让胶在凝胶前达到应力平衡状态 |
| **多灯头对称照射** | 3-4 个 UV 灯头对称布置 | 避免单侧先固化造成不对称收缩 |
| **胶层厚度控制** | 使用间隔珠（spacer beads），5–10μm | 精确控制胶层厚度，减小热膨胀差异 |

> ⚠️ **镜片粘接最重要的一条**：胶水在**凝胶点（gel point）**时产生的任何应力都会被永久锁定在固化胶层中。渐变固化就是让凝胶过程尽可能"从容"。

### 4.5 CMOS Sensor 板粘接工艺

```
PCB 基板预热（60°C）
  ↓
点胶（中央区域图案，非全覆盖）
  ↓
芯片贴装
  ↓
梯度升温固化
  ├─ 80°C, 30min
  ├─ 100°C, 30min
  └─ 120°C, 30min
  ↓
缓慢冷却（炉冷，≤2°C/min）
  ↓
翘曲检测（白光干涉仪）
```

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 点胶图案 | **仅中央区域**，非全覆盖 | 减小约束面积，允许差异膨胀 |
| 胶层厚度 | 25–50 μm | 薄胶层减少绝对热膨胀量 |
| 固化温度 | ≤100°C（优选 80°C） | 低温减少固化冷却后的温差 → 减小翘曲 |
| 冷却速率 | ≤2°C/min（炉冷） | 缓慢冷却让应力松弛 |
| PCB 基板选择 | 陶瓷基板（Al₂O₃/AlN, CTE 6-8ppm/°C）优于 FR4（CTE 14-17ppm/°C） | CTE 更接近硅(3ppm/°C) |

**减轻翘曲的补充措施**：
- 使用**陶瓷基板**（Al₂O₃ 或 AlN）替代 FR4——CTE 匹配度提升 3 倍，导热提升 50-100 倍
- 在 PCB 与传感器之间使用**弹性中间层**（如硅橡胶薄层）吸收 CTE 失配
- 中央点胶替代全区域涂布，允许边缘自由膨胀

## 5. 通用注意事项

### 5.1 胶水储存与处理

| 项目 | 要求 |
|------|------|
| 储存温度 | 单组分 UV 胶：室温避光；单组分环氧/双固化：-18°C ~ -20°C 冷冻储存 |
| 回温 | 冷冻胶使用前需在室温回温 1-2 小时，**严禁开盖回温**（防结露） |
| 气泡处理 | 高精度应用需**真空脱泡**（-0.1MPa, 5-10min）或离心脱泡 |
| 过期管理 | 每批次记录开封日期，定期标定收缩率变化趋势 |
| 先进先出 | 严格按照"先入先出"原则轮换库存 |

### 5.2 点胶精度控制

| 要求 | 推荐方案 |
|------|---------|
| 最小点胶量 | 纳升级：压电式喷射阀；微升级：螺杆计量阀 |
| 胶量一致性 | 在线称重闭环系统，实时检测胶量偏差并自动补偿 |
| 点胶位置精度 | ±25μm（机器视觉定位） |
| 防溢胶 | 触变性胶水 + 精确胶量控制，避免污染光学表面 |
| 胶线宽度控制 | 0.1 ±0.02 mm（螺杆阀点胶） |
| 点胶头-基板距离 | ~250 μm（保持恒定） |

### 5.3 固化工艺核心原则

```
❌ 错误做法：
   一次性高强度 UV 照射 → 瞬间固化 → 收缩应力锁定 → 对准偏移
  
✅ 正确做法：
   渐变 UV → 凝胶点缓慢到达 → 应力松弛 → 高功率完成固化 → 对准保持
```

**US Patent 8,486,214 分步固化法**（可将生产良率从 ~84% 提升至 ~90.7%）：

| 阶段 | UV 功率 | 时间 | 目的 |
|------|---------|------|------|
| 阶段 1：表皮固化 | ~5 mW/cm² | ~5s | 仅固化胶水外表面，组件仍可微调 ±30" |
| 阶段 2：深层固化 | ~1500 mW/cm² | ≥20s | ≥300 mJ/cm² 能量密度，完全固化 |

### 5.4 固化收缩补偿策略

| 策略 | 方法 | 适用场景 |
|------|------|---------|
| **偏置补偿** | 主动对准时刻意偏置，抵消预期收缩方向 | 所有精密光学装配 |
| **每日标定** | 每天测当批胶水收缩率，更新补偿值 | 批量生产（Fraunhofer IPT 推荐） |
| **最小胶层** | 设计最小粘接间隙，减少绝对收缩量 | 结构设计阶段 |
| **主动补偿** | 固化过程中运动系统实时补偿收缩位移 | 亚微米级精度需求（如 NanoGlue 系统） |
| **模型预测** | 基于胶水属性、粘接几何、固化参数建模预测 | 自动化产线 |

### 5.5 常见缺陷及对策

| 缺陷 | 影响 | 对策 |
|------|------|------|
| **气泡** | 光线散射、折射不均（Mura 效应）、强度下降 | 真空脱泡预处理、特殊阀体防混气 |
| **溢胶** | 污染镜片表面、遮挡光路 | 精确胶量控制、触变性胶水 |
| **阴影区固化不全** | 长期可靠性差、脱胶 | 选用双固化体系（UV+热）或阳离子暗固化胶 |
| **固化收缩应力** | 镜片变形、面形精度下降 | 选用低收缩/低模量胶水、渐变 UV 固化、控制胶层厚度 |
| **CTE 失配翘曲** | Sensor 像素面倾斜 → 测量误差 | 陶瓷基板、中央点胶、弹性中间层 |

## 6. 固化后验证标准

| 检测项目 | 方法 | 判定标准 |
|---------|------|---------|
| 光斑位置漂移 | 固化后 30min、2h、24h 分别测量 | 漂移 <2μm（CMOS 靶面） |
| 胶层固化程度 | 硬度测试 / DSC 残留反应热 | Tg 达到标称值，Shore D 达到标称值 90% 以上 |
| 镜片面形 | 干涉仪检测 | PV 变化 <λ/10 @ 650nm |
| Sensor 翘曲 | 白光干涉仪 / 激光轮廓仪 | 翘曲 <5μm（全幅面） |
| 粘接强度 | 剪切测试（抽检） | 达到 TDS 标称值 80% 以上 |
| 环境老化 | 85°C/85%RH, 1000h; -40°C~+85°C 温度循环 | 光斑位置漂移 <5μm，无脱胶/开裂 |
| 释气验证 | 高温烘烤后光学表面检测 | 无可见雾化/沉积 |

## 7. 综合推荐与行动建议

### 7.1 选型总结

| 粘接部位 | 首选胶水 | 备选方案 | 固化方式 | 核心优势 |
|---------|---------|---------|---------|---------|
| **激光器 TO-Can** | DELO DUALBOND OB786 | LOCTITE STYCAST OS5101 / EPO-TEK HYB-353ND / 3M 3581 | UV(4s) + 热(130°C/10min) | 双固化解决阴影区，NASA 低释气 |
| **接收镜片** | Norland NOA 61 | DELO DUALBOND OB6769 / 3M 3581 | UV(3-5s) | 军标认证，工艺简单，低收缩 |
| **CMOS Sensor 板** | Zymet 超低应力系列 | Yongoo Y-Bond S751 / LOCTITE ABP 8420 / 3M 6011NS | 热固化(<100°C) | 100倍曲率改善，专为图像传感器设计 |

### 7.2 3M 胶水定位

```text
┌─────────────────────────────────────────────────────────┐
│ 场景 A：追求最高精度和最低风险                            │
│ → TO-Can + 镜片：DELO OB786                             │
│ → Sensor 板：Zymet 超低应力系列                          │
│ → 胶水成本较高，但数据完整，风险可控                      │
├─────────────────────────────────────────────────────────┤
│ 场景 B：使用 3M 胶水（供应链便利或成本考虑）              │
│ → TO-Can + 镜片：3M 3581（需补齐释气性和透过率数据）     │
│ → Sensor 板：3M 6011NS Black（需补齐大量缺失数据）       │
│ → 成本可能更低，但需更多内部验证工作                      │
└─────────────────────────────────────────────────────────┘
```

### 7.3 向 3M 索取的关键缺失数据

**在获得以下数据前，不应做出最终选型决定：**

**针对 6011 系列（影响 CMOS Sensor 粘接决策）**：
- Tg（玻璃化转变温度）
- CTE（Tg 以下和 Tg 以上分别提供）
- 体积收缩率（%）
- 弹性模量（拉伸模量和弯曲模量）
- 释气性（是否通过 ASTM E595？TML%、CVCM%？）
- 离子含量（Cl⁻, Na⁺, K⁺ 各多少 ppm？）

**针对 3581（影响 TO-Can 和镜片粘接决策）**：
- 释气性（是否通过 ASTM E595？TML%、CVCM%？）
- 650nm 光学透过率（1mm 胶层厚度）
- 最大 UV 固化深度（mm）
- 折射率（固化后 @ 650nm）

### 7.4 内部验证测试建议

即使数据补齐，建议进行以下验证：

| 测试项目 | 方法 | 判定标准 |
|---------|------|---------|
| 3581 收缩致光斑漂移 | 点胶固化前后测量光斑在 CMOS 上位置变化 | <2μm |
| 3581 阴影区固化验证 | TO-Can 法兰背面胶层硬度测试 | Shore D >80% 标称值 |
| 6011NS 固化致 Sensor 翘曲 | 白光干涉仪测固化前后 sensor 表面形貌 | 翘曲 <5μm |
| 胶水 650nm 透过率 | 分光光度计，1mm 胶层 | >95% @ 650nm |

### 7.5 对 DF009 项目的特别建议

1. **650nm 波长兼容性验证**：虽然推荐胶水在可见光波段透过率通常良好，但建议实际测试胶水在 650nm 的折射率和透过率，确保与光学设计匹配。

2. **胶水收缩率标定装置**：建议搭建一套简易的收缩率标定装置（点胶到玻片 → UV 固化 → 激光位移传感器测量胶层厚度变化），每日生产前标定，这对保持 <30μm 重复精度至关重要。

3. **陶瓷基板值得投资**：对于 S13131-1536 这种超薄传感器（0.8mm），FR4 基板的 CTE 失配导致的翘曲风险很高。AlN 陶瓷基板虽然成本较高，但 CTE 匹配和散热性能远超 FR4。

4. **DOE 工艺参数优化**：建议通过 DOE（实验设计）优化以下参数组合——UV 功率、预固化时间、胶层厚度、热固化温度曲线，找到对准漂移最小的参数窗口。

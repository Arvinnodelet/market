# 激光位移传感器（三角法测量系统

## 项目概况

这是一个激光位移传感器项目，设计目标是外观尺寸尽可能小，便于集成到机器内使用。
根据提供的信息设计激光位移传感器方案，包含光学系统设计与分析、信号处理方案、机械结构设计、校准方案

## 产品性能需求

| 参数名称 | 用途 |
| ---- | --- |
| 测量范围 | 50mm±15mm |
| 分辨率 | 0.01mm |
| 重复精度 | ＜30um |
| 直线性 | ±0.1%F.S (全量程) |

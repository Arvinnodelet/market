## 1. 系统概述

### 1.1 设计目标

本方案设计一款基于激光三角法测量原理的位移传感器，核心指标如下：

| 参数 | 指标 | 备注 |
|------|------|------|
| 测量范围 | 50mm ±15mm（35–65mm） | 以传感器前端面为基准 |
| 分辨率 | 0.01mm | 输出数据的最小可分辨位移 |
| 重复精度 | ＜30μm | 同一条件下多次测量的一致性 |
| 直线性 | ±0.1% F.S. | 全量程 ±30μm |
| 光源波长 | 650nm | 可见红光，便于对准调试 |
| 设计目标 | 外观尺寸尽可能小 | 便于集成至设备内部 |

### 1.2 系统组成

```
                          ┌──────────┐
                          │  激光器   │  650nm, 5mW
                          │  驱动    │
                          └────┬─────┘
                               │
                    ┌──────────▼──────────┐
                    │   激光二极管        │
                    │   + 准直镜         │
                    │   + 聚焦镜         │
                    └──────────┬──────────┘
                               │ 投射光束
                               ▼
                    ╔══════════════════╗
                    ║    目标表面      ║  ← 35–65mm 范围
                    ╚══════════════════╝
                               │ 漫反射光
                               ▼
┌──────────┐    ┌──────────┴──────────┐    ┌──────────────┐
│  输出    │◄───│  MCU / 信号处理     │◄───│  CMOS 传感器 │
│ (RS485/  │    │                    │    │  S13131-1536 │
│  Analog) │    └─────────────────────┘    │  + 成像透镜  │
└──────────┘                               └──────────────┘
```

**工作原理**：激光二极管经准直聚焦后，在目标表面形成微小光斑。漫反射光经成像透镜汇聚于 CMOS 线阵传感器。当目标沿激光方向移动时，光斑在传感器上的像点位置随之移动。通过亚像素质心算法精确解算像点位置，经标定曲线将像素坐标映射为实际位移值。

### 1.3 三角法测量原理

```
         激光器
            │
            │  (垂直于基准面)
            │
            ▼
    ────────●────────────  基准面 (距离 = 50mm)
           /│\
          / │ \
         /  │  \  目标位移 = ±15mm
    ────●───┼───●───────  测量范围边界
       /    │    \
      /     │     \
     /      │ 角度=25°\
    ────────┼──────────
            │         \
            ▼          \
       成像透镜          \
       (焦距=16mm)       \
            \             \
             \             \
              ▼             \
         CMOS 传感器         \
         (Scheimpflug 倾斜)   \
                               \
                              目标表面
```

当目标从基准面（50mm）移动 Δz 时，像点在 CMOS 上的位移由下式给出（激光垂直于基准面）：

```
                    焦距 × sin(三角角度) × 目标位移
 像点位移 = ──────────────────────────────────────────────
            基准物距 × cos(三角角度) + 目标位移 × cos²(三角角度)
```

其中 **基准物距 = 基准工作距离 / cos(三角角度)**，即沿成像光轴方向从透镜到目标光斑的距离。

## 2. 光学系统设计与分析

### 2.1 三角法几何参数设计

#### 2.1.1 核心参数选择

| 参数 | 符号 | 数值 | 选择依据 |
|------|------|------|----------|
| 三角测量角度 | — | 25° | 平衡灵敏度与结构紧凑性；角度过大会增大传感器倾斜角 |
| 成像透镜焦距 | f | 16mm | 标准焦距，像差校正良好，尺寸紧凑 |
| 基准工作距离 | — | 50mm | 中心量程，兼顾防护窗口设计 |
| 基线距离 | — | 23.32mm | = 50 × tan(25°)，决定激光与成像光轴的间距 |

#### 2.1.2 几何关系推导

**（一）基准面处（目标位移 Δz = 0，即靶面在 50mm 处）**

```
 基准物距 = 基准工作距离 ÷ cos(25°) = 50 ÷ 0.90631 = 55.17 mm

 基准像距 = 1 ÷ (1÷焦距 − 1÷基准物距)
          = 1 ÷ (1/16 − 1/55.17)
          = 22.54 mm

 横向放大率 = 基准像距 ÷ 基准物距 = 22.54 ÷ 55.17 = 0.4086
```

**（二）像点位移方程**

将参数代入通用的像点位移公式：

```
 像点位移 [mm] = ────────────────────────────────
                  50.00 + 0.8214 × 目标位移 [mm]
```

上式分子中的 6.7619 = 16 × sin(25°)，分母中的 50.00 与 0.8214 则来自基准物距和三角角度的三角函数组合。该方程完整描述了目标从 35mm 到 65mm 之间任意位置时对应 CMOS 上的像点偏移量。

**（三）全量程像点位置**

| 目标位移 [mm] | 像点位移 [mm] | 偏离中心像素数 | 说明 |
|--------------|--------------|---------------|------|
| −15 | **−2.692** | −489 | 近端（目标距传感器 35mm） |
| −10 | −1.615 | −294 | |
| −5 | −0.736 | −134 | |
| 0 | 0.000 | 0 | 基准面（目标距传感器 50mm） |
| +5 | +0.625 | +114 | |
| +10 | +1.162 | +211 | |
| +15 | **+1.627** | +296 | 远端（目标距传感器 65mm） |

- 全量程像点移动总量：1.627 − (−2.692) = **4.319 mm**
- 占用像素数：4.319 ÷ 0.0055 = **785 像素**（占传感器总长 51%，留有充足余量）

#### 2.1.3 灵敏度分析

灵敏度 = 像点位移对目标位移的变化率，即像点位移公式的导数：

```
                            338.10
 灵敏度 [mm/mm] = ──────────────────────────────
                  (50.00 + 0.8214 × 目标位移)²
```

上式分子 338.10 = 16 × sin(25°) × 55.17 × cos(25°)。

| 位置 | 灵敏度 [mm/mm] | 像素分辨率 [pix/mm] | 原始精度 [mm/pix] |
|------|---------------|---------------------|-------------------|
| 近端 (位移=−15mm) | 0.2382 | 43.31 | 0.0231 |
| 中心 (位移=0mm) | 0.1352 | 24.59 | 0.0407 |
| 远端 (位移=+15mm) | 0.0871 | 15.83 | 0.0632 |

**含义说明**：
- 灵敏度 0.1352 mm/mm = 目标每移动 1mm，像点在传感器上移动 0.1352mm
- 像素分辨率 24.59 pix/mm = 目标每移动 1mm，像点横跨 24.59 个像素
- 原始精度 0.0407 mm/pix = 一个像素对应 0.0407mm 的目标位移

灵敏度从近端到远端变化约 **2.74 倍**，这是三角法固有的几何非线性，需通过标定进行修正。

#### 2.1.4 分辨率可行性验证

**最差情况（远端，目标位移 = +15mm，即目标在 65mm 处）：**
- 原始分辨率：0.0632 mm/像素（一个像素对应的位移变化）
- 目标分辨率：0.01 mm
- 需要的亚像素细分倍数：0.0632 ÷ 0.01 = **6.3 倍**
- 采用灰度质心法（CoG），在 SNR ≥ 100 时可达 **1/20 ~ 1/50 像素** 的细分精度
- **结论：分辨率裕量充足（≥3×）** ✅

### 2.2 Scheimpflug 条件

#### 2.2.1 原理

在三角法测量中，激光光斑在目标表面沿激光束方向移动，其轨迹构成一个倾斜的物平面。为保证全量程内光斑在传感器上清晰成像，必须满足 **Scheimpflug 条件**：

> 物平面（激光束轴线）、透镜主平面、像平面（传感器感光面）三者必须交汇于同一直线。

#### 2.2.2 传感器倾斜角计算

```
                    物平面 (激光束)
                    │
                    │  90° − 25° = 65°
                    │
                    ●───────────────
                   /│              /
                  / │             /
                 /  │            /
                /   │           /
    ──────────●────●──────────●──────────  三线交于一点
             /     │ 透镜平面  /
            /      │         /
           /       │        /
          /        │       /
         /         │      /
    ────●──────────●─────●───
        \         /      /
         \       /      /
          \     / 倾斜角 φ
           \   /      /
            \ /      /
             ●──────●────────
             传感器
             (倾斜 φ)
```

传感器倾斜角计算公式（近轴近似）：

```
 tan(倾斜角) = 放大率 × cot(三角角度)
             = 放大率 ÷ tan(三角角度)
```

代入数值：

```
 tan(倾斜角) = 0.4086 × cot(25°) = 0.4086 × 2.1445 = 0.8763

 倾斜角 = arctan(0.8763) = 41.2°
```

#### 2.2.3 景深校核

即使满足 Scheimpflug 条件，实际光学系统仍受限于有限孔径带来的景深。成像透镜 f/2.8 时：

```
 入瞳直径 = 焦距 ÷ 2.8 = 5.71 mm

 像方数值孔径 ≈ 入瞳直径 ÷ (2 × 基准像距) = 5.71 ÷ 45.08 = 0.127

 像方焦深 = 波长 ÷ (像方数值孔径)² = 0.65μm ÷ 0.0161 ≈ 40 μm

 物方焦深 = 像方焦深 ÷ 放大率² = 40 ÷ 0.167 ≈ 240 μm (±120 μm)
```

物方焦深 ±120μm 远小于 30mm 量程——这正是 Scheimpflug 条件是**必须满足**而非可选的原因。满足 Scheimpflug 后，理论上全量程焦点重合，实际像差限制下仍可保证光斑 RMS 半径在 1–2 像素以内。

### 2.3 激光光路设计

#### 2.3.1 激光器参数回顾

| 参数 | 值 |
|------|-----|
| 型号 | HGLD-650TO5.6-JP-5mW |
| 波长 | 650nm |
| 出光功率 | 5mW（额定），7mW（最大）|
| 发散角（FWHM）| 快轴 36°，慢轴 7° |
| 封装 | TO5.6 (Φ5.6mm)，内置 PD |

#### 2.3.2 准直与光束整形

激光二极管输出为椭圆形发散光束，需经准直与整形：

```
LD ──→ [非球面准直镜] ──→ [变形棱镜对] ──→ [聚焦镜] ──→ 目标表面光斑
       焦距=4.0mm         3× 扩束(慢轴)     焦距=40mm     φ50~80μm
       数值孔径≥0.5                         消色差透镜
```

**（1）准直镜选型：**
- 非球面透镜，焦距 = 4.0mm，数值孔径 ≥ 0.5
- 快轴光束直径（准直后）= 2 × 4.0 × tan(18°) = 2.60 mm
- 慢轴光束直径（准直后）= 2 × 4.0 × tan(3.5°) = 0.49 mm

**（2）光束圆化：**
- 采用变形棱镜对（Anamorphic Prism Pair），慢轴方向 3× 扩束
- 圆化后光束尺寸：约 Φ2.6mm × Φ1.5mm（近圆形）

**（3）聚焦镜：**
- 消色差双胶合透镜，焦距 = 40mm
- 衍射极限光斑直径（1/e²）：

```
              4 × 波长 × 焦距
 光斑直径 = ──────────────── × 光束质量因子
               π × 光束直径
```

- 快轴：光斑直径 = (4 × 0.650μm × 40) ÷ (π × 2.60) × 1.2 ≈ **15 μm**
- 慢轴：光斑直径 = (4 × 0.650μm × 40) ÷ (π × 1.5) × 1.2 ≈ **26 μm**
- 考虑装配误差与残余像差，实际光斑直径：**φ50–80μm**

**（4）瑞利长度（焦深）：**
- 对 φ50μm 光斑：

```
               π × 光斑直径²     π × 50²
 瑞利长度 = ─────────────── = ────────── = 3.0 mm
               4 × 波长         4 × 0.65
```

激光光斑在靶面的离焦不作为限制因素——测量基于光斑质心而非边缘清晰度。即使在量程两端光斑略有扩大（~100μm），质心算法仍可稳健工作。

#### 2.3.3 激光器驱动

- 恒功率控制（APC）：利用内置 PD 反馈，稳定出光功率
- 驱动电流：约 17mA（典型值）
- 调制功能：可选脉冲调制以抑制环境光干扰（与 CMOS 帧同步触发）

### 2.4 成像光路设计

#### 2.4.1 成像透镜选型

| 参数 | 值 | 依据 |
|------|-----|------|
| 焦距 | 16mm | 匹配传感器尺寸与量程 |
| F 数 | f/2.8 | 兼顾集光能力与像差 |
| 镀膜 | 可见光增透（R<1% @650nm）| 减少杂散光 |
| 镜片结构 | 4–5片双高斯或改进型 | 控制畸变<0.5% |

#### 2.4.2 窄带滤光片

在成像透镜前加装 650nm 窄带滤光片以抑制环境光：

| 参数 | 值 |
|------|-----|
| 中心波长 (CWL) | 650nm |
| 半高宽 (FWHM) | 10–20nm |
| 峰值透过率 | >90% |
| 截止深度 | OD4 (0.01%) @ 400–1000nm（除通带） |

#### 2.4.3 光功率预算

| 环节 | 功率/效率 | 累计 |
|------|----------|------|
| 激光器出射 | 5 mW | 5 mW |
| 光学系统透过率 | ~85% | 4.25 mW |
| 目标漫反射率（典型）| 30–50% | 1.3–2.1 mW 反射 |
| 成像透镜收集立体角 | (入瞳半径÷物距)² ≈ 0.0025 | — |
| 到达传感器总功率 | — | ~3–5 μW |
| 滤光片透过率 | >90% | ~3–4.5 μW |
| 单像素接收功率 | 光斑覆盖~4–6像素 | ~0.6–1.1 μW/pix |

**SNR 评估：**

CMOS S13131-1536 在 650nm 峰值灵敏度工况下：
- 灵敏度：280 V/(lx·s)
- 1 μW @ 650nm 落在单像素（5.5×63.5μm²）≈ 约 200 lx（基于光度转换）
- 积分时间 100μs，信号电压 ≈ 5.6 mV
- 读出噪声 0.4mV rms
- 单帧 SNR = 5.6 ÷ 0.4 = **14 倍**
- 16帧平均后 SNR = 14 × √16 = **56 倍** → 质心细分精度可达 1/50 像素

**结论：5mW 激光功率完全满足 SNR 要求。** 在低反射率目标（<10%）时可通过增大积分时间补偿。

### 2.5 杂散光抑制

| 措施 | 说明 |
|------|------|
| 窄带滤光片 | 成像光路标配，OD4 宽带截止 |
| 光学窗口倾斜 | 防护窗口倾斜 5–10° 安装，防止反射光进入成像光路 |
| 消光纹/光阑 | 激光出光口与成像窗口之间的隔板，阻断直接串扰 |
| 内壁处理 | 壳体内部黑色阳极氧化 + 消光条纹（螺纹或锯齿槽） |
| 遮光罩 | 成像镜头前端遮光罩，减小视场外杂光 |

## 3. 信号处理方案

### 3.1 传感器驱动与时序

#### 3.1.1 S13131-1536 关键参数回顾

| 参数 | 值 |
|------|-----|
| 像素数 | 1536 |
| 像元尺寸 | 5.5μm × 63.5μm |
| 最大数据速率 | 2 MHz |
| 饱和输出 | 1.4V |
| 读出噪声 | 0.4 mV rms |
| 暗输出 | 1.5 mV (积分时间=10ms) |

#### 3.1.2 时序设计

```
CLK  ─┐  ┌┐  ┌┐  ┌┐  ...  ┌┐  (2MHz, 50% 占空比)
       └──┘└──┘└──┘       └┘

ST   ──────┐              ┌──────  (帧起始脉冲)
           └──────────────┘

Video ────┬──┬──┬──┬── ... ──┬───
          │p1│p2│p3│         │p1536
          └──┴──┴──┘         └───

TRIG ──────┐                       (积分时间控制)
           └──────────────────┘
           |<── 积分时间 ──>|
```

- **时钟频率**：2 MHz
- **单帧读出时间**：1536 × 0.5μs = **768 μs**
- **最大帧率**：约 **1300 fps**（连续模式）
- **积分时间**：10–500 μs 可调（由外部触发或电子快门控制）

### 3.2 信号处理流程

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ 1. 暗场   │   │ 2. 背景  │   │ 3. 峰值  │   │ 4. ROI   │   │ 5. 质心  │   │ 6. 坐标  │
│   扣除    │──▶│   扣除   │──▶│   检测   │──▶│   提取   │──▶│   计算   │──▶│   映射   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
```

#### 第 1 步：暗场扣除

在无光条件下采集暗场参考帧（取 100 帧平均，记为 **暗场基准**），每次测量时，对每个像素 i：

```
 暗场校正后信号[i] = 原始信号[i] − 暗场基准[i]
```

此步骤消除暗电流和固定模式噪声（FPN）。

#### 第 2 步：背景扣除

在激光关闭时采集环境光背景帧（记为 **背景基准**），或通过激光调制实现同步解调：

```
 有效信号[i] = 暗场校正后信号[i] − 背景基准[i]
```

配合窄带滤光片，此步骤可基本消除 DC 环境光和 50/60Hz 闪烁干扰。

#### 第 3 步：峰值检测

对有效信号进行逐像素扫描：
- 设定阈值 = k × 噪声标准差（典型 k = 5–8）
- 检测超阈值连续区域
- 选择面积最大的区域作为有效光斑信号

#### 第 4 步：ROI 提取

以峰值像素为中心，提取宽度为 32–64 像素的感兴趣区域（ROI），减少后续计算量。

#### 第 5 步：亚像素质心计算

采用 **灰度重心法（Center of Gravity, CoG）**：

```
          ∑ [ 像素位置i × (有效信号[i] − 阈值) ]
质心位置 = ──────────────────────────────────────
          ∑ [ 有效信号[i] − 阈值                ]
```

（求和范围：ROI 内所有像素）

其中阈值的引入用于抑制背景噪声对质心估计的偏置。

**增强方案——高斯拟合法**（精度要求更高时使用）：

```
有效信号[i] = 幅度 × exp[ −(像素位置i − 质心位置)² ÷ (2 × 宽度²) ] + 基线
```

通过 Levenberg-Marquardt 或最小二乘迭代求解质心位置。理论精度优于 CoG 法的约 1.5–2 倍，但计算量较大。

**推荐初始方案**：使用带阈值的 CoG 法，浮点运算精度（32-bit float），预期可达 **1/20–1/30 像素**的质心细分精度。

#### 第 6 步：坐标映射

将质心像素坐标（浮点数）代入标定多项式（详见第 5 章），输出实际位移值（mm）。

### 3.3 数字滤波

| 滤波器类型 | 截止频率 / 参数 | 作用 |
|-----------|----------------|------|
| 滑动平均 | 窗口长度 8–16 | 降低随机噪声，延迟最小 |
| 低通 FIR | −3dB @ 50–100 Hz | 抑制机械振动高频分量 |
| 中值滤波 | 窗口长度 3–5 | 剔除偶发性异常值（斑点干扰） |

滤波器级联顺序：中值 → FIR 低通 → 滑动平均

### 3.4 重复精度分析

重复精度的主要误差源：

| 误差源 | 影响量（估计） | 性质 |
|--------|---------------|------|
| 光子散粒噪声 | <1 μm | 随机 |
| CMOS 读出噪声 | 1–2 μm | 随机 |
| 激光光斑散斑 | 3–8 μm | 随机（可通过平均抑制） |
| 温度漂移 | 2–5 μm/°C | 系统（可通过温度补偿修正）|
| 量化噪声 | <0.1 μm | 随机（浮点质心已消除） |

**RSS 综合（排除温漂）**：

```
综合误差 = √(1² + 2² + 5² + 0.1²) ≈ 5.5 μm
```

结论：在 16 帧平均条件下，重复精度可稳定 **<10μm**，满足 <30μm 的设计指标要求。温漂需通过第 5.4 节所述温度补偿予以控制。

### 3.5 处理器选型

| | 方案 A: STM32H743 | 方案 B: FPGA (ICE40/GW1N) |
|------|------|------|
| ADC 方案 | 内置 12-bit ADC / 外挂 14-bit ADC | 外挂 14–16 bit ADC |
| 处理能力 | 480MHz Cortex-M7, DSP 指令 | 并行流水线，任意吞吐 |
| 质心计算 | <5μs (硬件浮点) | 实时流水线 |
| 帧率 | 受限于 ADC 采样率 | >10,000 fps |
| 开发复杂度 | 低（C 语言，HAL 库） | 中–高（Verilog/VHDL） |
| 芯片成本 | ~$8 | ~$5 + ADC |
| 适用性 | ✅ 推荐，完全满足 1300fps | 仅高帧率或特殊需求时必要 |

**推荐方案 A（STM32H743 或同等 MCU）**：对 1300 fps 的 CMOS 数据流，每帧 768μs，在此期间完成 ADC 采样 + 质心计算绰绰有余。

## 4. 机械结构设计

### 4.1 总体布局

```
              ┌─────────────────────────────┐
              │         上壳体 (铝)          │
              │                             │
   激光器 ───┐│                      ┌──────┤
   TO5.6     ││                      │CMOS  │
   准直镜    ││                      │PCB   │
   棱镜对    ││    ┌──────────┐      │      │
   聚焦镜    ││    │ 光学隔板  │      │成像镜│
             ││    │ (消光纹)  │      │      │
   ──────────┘│    └──────────┘      └──────┤
   出光口     │                      接收口 │
   ──────────┐│    ┌──────────┐      ┌──────┤
   防护窗口 ─┘│    │  测量区域 │      │防护窗│──┘
              │    │  35-65mm │      │口    │
              └────┴──────────┴──────┴──────┘
              ◄──────── 约 50mm ──────────►

                侧视截面示意图（三角布局）
```

**关键几何约束：**
- 激光臂与成像臂夹角：25°
- 基线距离（光轴间距）：23.32mm
- 传感器倾斜角：41.2°（满足 Scheimpflug）
- 预估外形尺寸：**~55 × 35 × 22 mm**（长×宽×高，不含电缆）

### 4.2 关键机械件

#### 4.2.1 激光模块安装座

```
       ┌──────────────────┐
       │   调节环 (俯仰)    │
       │  ┌──────────────┐ │
       │  │  LD 安装座   │ │
       │  │  (TO5.6 压圈) │ │
       │  │  准直镜镜筒  │ │
       │  │  棱镜对座    │ │
       │  │  聚焦镜镜筒  │ │
       │  └──────────────┘ │
       └──────────────────┘
              │
         三点弹簧-螺钉调节
        (俯仰/偏摆 ±2°)
```

- 激光器 TO-5.6 封装通过压圈固定，确保散热接触
- 准直镜与聚焦镜分别安装于螺纹镜筒，可轴向调节
- 整体安装座通过三点式弹性调节机构与壳体连接，提供俯仰/偏摆 ±2° 的调校范围

#### 4.2.2 成像模块安装座

- 成像透镜装入 M12×0.5 或 M16×0.5 螺纹镜筒，配锁紧环
- CMOS 传感器焊接于小型 PCB，PCB 以 41.2° 倾斜角固定于壳体
- PCB 安装面加工倾斜槽，保证 Scheimpflug 角度精度 ±0.5°

#### 4.2.3 防护窗口

- 激光出射窗口与成像接收窗口均采用 AR 镀膜光学玻璃（BK7 或石英）
- 窗口与光轴倾斜 5–10° 安装，避免反射光串扰
- 窗口以 O 形圈 + 压圈密封

### 4.3 材料选择

| 零件 | 材料 | 理由 |
|------|------|------|
| 壳体（上/下） | 6061-T6 铝合金 | 导热好、重量轻、易加工、黑色阳极氧化 |
| 镜筒、压圈 | 6061-T6 铝合金 | 同上 |
| 关键隔圈 | 因瓦合金 (Invar) | 热膨胀系数极低（~1.2 ppm/°C），稳定光路长度 |
| 防护窗口 | BK7 或石英玻璃 | 光学级，双面 AR 镀膜 |
| 密封圈 | 氟橡胶 (FKM) | 耐候、耐油、弹性保持好 |
| PCB 固定座 | 玻纤增强 PEEK 或 FR-4 | 绝缘、尺寸稳定 |

### 4.4 热管理

**热源分析：**
- 激光二极管：正向电压约 2.1V，工作电流约 17mA

```
  电功耗 = 2.1V × 17mA ≈ 36 mW
  光输出 ≈ 5 mW
  热耗散 ≈ 31 mW
```
- MCU + CMOS 传感器：<100mW（估算）

**散热路径：** LD → TO-5.6 底座 → 安装座 → 铝合金壳体 → 环境

- 壳体表面积约 40 cm²，自然对流 + 辐射散热能力约 0.5–1.0W
- 总热耗约 130mW → **温升 <5°C**，无需强制冷却
- 内置 NTC 热敏电阻（贴于壳体内部靠近激光器处），用于温度补偿

### 4.5 装配公差分析

对测量精度的灵敏度分析：

| 公差项 | 名义值 | 公差 | 对测量误差的影响（最差） |
|--------|--------|------|------------------------|
| 三角角度 | 25° | ±0.1° | ~12 μm @ 50mm |
| 透镜焦距 | 16mm | ±0.16mm (1%) | ~6 μm |
| 传感器倾斜角 | 41.2° | ±0.5° | 离焦增大，质心精度下降 ~3μm |
| 透镜–传感器距离 | 22.54mm | ±0.05mm | ~4 μm |
| 激光指向偏差 | 0° | ±0.05° | ~8 μm |

**RSS 综合（制造公差）**：

```
综合误差 = √(12² + 6² + 3² + 4² + 8²) ≈ 16 μm
```

→ 装配公差带来的系统误差可通过 **标定** 予以补偿，残差 <5μm。

### 5.2 标定流程

```
      ┌──────────┐
      │ 1. 安装  │  传感器与滑台对正，激光垂直于靶面
      └────┬─────┘
           ▼
      ┌──────────┐
      │ 2. 参考  │  采集暗场、亮场参考、环境光背景
      └────┬─────┘
           ▼
      ┌──────────┐
      │ 3. 扫描  │  滑台以 0.1mm 步进遍历 35–65mm (301个点)
      └────┬─────┘  每个点采集 100 帧，记录质心位置
           ▼
      ┌──────────┐
      │ 4. 拟合  │  多项式回归：位移 = f(质心位置)，3–5 阶
      └────┬─────┘
           ▼
      ┌──────────┐
      │ 5. 验证  │  计算拟合残差，确认 ±30μm 合规
      └────┬─────┘
           ▼
      ┌──────────┐
      │ 6. 写入  │  多项式系数写入传感器 Flash/EEPROM
      └──────────┘
```

**详细说明：**

1. **安装对正（Alignment）**：将传感器固定于夹具，靶面安装于滑台。调节传感器姿态，使激光束垂直于靶面（可用自准直仪或通过观察反射光斑辅助判断）。靶面位于 50mm 处时，确保 CMOS 上光斑位于像素阵列中心附近（像素 700–836 之间）。

2. **参考采集**：
   - 暗场基准：遮挡激光与所有光源，100 帧平均
   - 背景基准：仅关激光，100 帧平均

3. **扫描采集**：
   - 滑台从 35mm 步进至 65mm，步距 0.1mm（共 301 个采样点）
   - 每个点采集 100 帧原始数据，扣除暗场与背景后计算质心位置
   - 记录 100 帧质心的**平均值**与**标准差**
   - 对于要求 ±0.01mm 分辨率的应用，步距可加密至 0.05mm

4. **多项式拟合**：

   推荐使用 **5 阶多项式** 模型：

   ```
   实际位移 = a₀ + a₁×(质心位置) + a₂×(质心位置)² + a₃×(质心位置)³
                    + a₄×(质心位置)⁴ + a₅×(质心位置)⁵
   ```

   或者分段拟合（将 30mm 量程等分为 3–5 段，每段独立 3 阶拟合），在保持拟合精度的同时避免高阶振荡。

### 5.3 非线性校正模型评估

基于 2.1 节推导的理论像点位移关系，模拟标定数据并评估拟合残差：

- 3 阶多项式拟合残差：< ±15μm ✅（已满足 0.1% F.S.）
- 5 阶多项式拟合残差：< ±5μm ✅✅（充裕）
- 分段 3 阶（5 段）拟合残差：< ±3μm ✅✅✅

**推荐量产方案**：5 阶单段多项式，系数少（6 个 float），适合 MCU 快速计算。

### 5.4 温度补偿

**补偿策略：**

测量传感器在 3 个温度点（如 10°C, 20°C, 30°C）的标定曲线，建立温度相关修正模型。

**简化方案——线性温漂补偿：**

```
 补偿后位移 = 原始测量值 + 温漂系数 × (当前温度 − 基准温度)
```

其中：
- **温漂系数** [mm/°C]：通过实验测定（在不同温度下测量标准位移，计算偏差率）
- **基准温度** = 20°C

**增强方案——二维查表 + 线性插值：**

对于要求更高精度的应用，分别在 3 个温度点获取完整标定曲线，运行时根据当前温度对相邻两条标定曲线进行线性插值：

```
                          (标定值@T₂ − 标定值@T₁)
 补偿后位移 = 标定值@T₁ + ─────────────────────── × (当前温度 − T₁)
                              (T₂ − T₁)
```

**目标**：0–40°C 工作温度范围内，温度引起的附加误差 <10μm。

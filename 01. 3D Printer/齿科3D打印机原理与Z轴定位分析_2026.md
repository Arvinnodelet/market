## 1. 齿科 3D 打印机技术原理

### 1.1 光固化技术路线

齿科 3D 打印的主流技术是 **桶式光聚合 (Vat Photopolymerization)**，根据光源和成像方式分为三种：

```
桶式光聚合 (Vat Photopolymerization)
├── SLA  (Stereolithography)          — 激光逐点扫描固化
├── DLP  (Digital Light Processing)   — 投影仪面曝光固化  ← S200 EvoDent 采用
└── LCD  (Liquid Crystal Display)     — 液晶掩膜面曝光固化
```

**DLP 工作原理**：

```
                    ┌─────────────────┐
                    │   DLP 投影光机    │  ← 405nm UV LED 光源 + DMD 芯片
                    │   (4K 分辨率)     │
                    └────────┬────────┘
                             │ 紫外光 (405nm)
                             ▼
              ┌──────────────────────────┐
              │      光学窗口（玻璃）      │
              │    ┌──────────────────┐  │
              │    │   离型膜 (FEP)    │  │  ← 透光、低表面能
              │    └──────────────────┘  │
              │    ═══════════════════════│  ← 液态光敏树脂
              │         ▲  Z 轴升降       │
              │    ┌────┴───────────┐    │
              │    │   成型平台       │    │  ← 逐层抬升，模型倒挂成型
              │    │   (Build Plate) │    │
              │    └────────────────┘    │
              └──────────────────────────┘
```

> 💡 **关键概念**：DLP 是"下投影 (Bottom-Up)"方式——光机在树脂槽下方向上投影，成型平台倒挂浸入树脂液中，每层曝光固化后平台向上抬升一层高度，已固化层与离型膜剥离，液态树脂回流填充，下一层曝光固化。如此逐层累积形成三维物体。

### 1.2 DLP 用于齿科的独特优势

| 维度 | DLP 优势 | 齿科关联 |
|------|---------|---------|
| **面曝光** | 整层同时固化，打印速度与模型数量无关 | 一版可同时打印 6-12 个半口牙模，效率极高 |
| **像素精度** | 4K DMD 芯片 → 50μm/pix (S200) | 满足种植导板、全口义齿的 ±50μm 临床精度要求 |
| **材料兼容性** | 405nm 波长覆盖主流齿科树脂 | 模型树脂、导板树脂、临时冠桥树脂、人工牙龈等 |
| **表面质量** | 像素级固化，层纹可控（支持抗锯齿） | 修复模型和义齿基托需光滑表面 |
| **幅面** | 192×108mm（S200）属齿科大幅面 | 单版容纳多个半口模型，适配技工所批量生产 |

### 1.3 临床精度要求

| 齿科应用 | 可接受偏差 | S200 标称精度 |
|---------|-----------|-------------|
| 研究模型 / 记存模型 | < ±200~500 μm | ±50 μm ✅ |
| 修复体工作模型 | < ±100 μm | ±50 μm ✅ |
| 种植导板 | < ±250 μm | ±50 μm ✅ |
| 全口义齿 | < ±200 μm | ±50 μm ✅ |

## 3. Z 轴定位实现方式 — 深度分析

Z 轴是 DLP 3D 打印机中**对精度影响最大的单一机械子系统**。每一层固化后，Z 轴需要完成"抬升剥离 → 回落复位 → 定位到下一层高度"的运动循环。层厚典型值为 50 μm（S200），Z 轴定位误差必须远小于层厚——工业级设备要求 **≤ ±3 μm**。

### 3.1 机械传动链

#### 3.1.1 典型工业级 Z 轴结构

```
         ┌──────────────────────┐
         │     驱动电机          │  ← 步进电机 / 伺服电机
         │  (Motor + Encoder)   │
         └──────────┬───────────┘
                    │ 联轴器 (Coupling)
                    ▼
         ┌──────────────────────┐
         │    滚珠丝杠           │  ← 将旋转运动 → 直线运动
         │  (Ball Screw)        │     导程 4~10mm，C3 精度级以上
         │  丝杠螺母             │
         └──────────┬───────────┘
                    │ 连接板 (Mounting Plate)
                    ▼
         ┌──────────────────────┐
         │   成型平台支架         │
         │  (Build Platform)    │
         └──────────────────────┘
                    ▲
                    │ 导向
         ┌──────────┴───────────┐
         │  双直线导轨 + 双滑块   │  ← 保证垂直度与刚性
         │  (Dual Linear Rails) │     HIWIN / THK 等品牌
         └──────────────────────┘
```

#### 3.1.2 核心传动件：滚珠丝杠 vs 滑动丝杠

| 对比维度 | 滚珠丝杠 (Ball Screw) | 滑动丝杠 (Lead Screw) |
|---------|---------------------|---------------------|
| 传动效率 | **90%–99%** | 25%–50% |
| 摩擦类型 | 滚动摩擦 | 滑动摩擦 |
| 反向间隙 (Backlash) | 可预紧消除 | 固有间隙，难消除 |
| 定位精度 | **≤ 3 μm** (C3 级) | ~10–30 μm |
| 磨损寿命 | 长（滚动体均匀承载） | 短（滑动磨损） |
| 成本 | 高（数百–数千元） | 低（数十元） |
| **3D 打印实证** | 厚度偏差 −0.08 mm, Ra 2.68 μm | 厚度偏差 −0.37 mm, Ra 24 μm |

> ⚠️ **关键发现**：学术实证表明，滚珠丝杠 3D 打印零件的厚度偏差 (−0.08mm) 仅为滑动丝杠 (−0.37mm) 的 **1/4.6**，表面粗糙度 Ra 也优一个数量级。这就是工业级设备（S200/Cute300）坚持用滚珠丝杠的原因。

#### 3.1.3 导轨系统

**双导轨 + 双滑块** 是工业级 Z 轴的标配：

- **双导轨**：左右对称布置，消除悬臂力矩，保证平台在升降过程中不产生俯仰/偏摆
- **双滑块**：每根导轨配两个滑块，增加承载跨距，进一步抑制偏摆
- **品牌选型**：国内工业级设备常用 **HIWIN（上银）**、**TBI** 等台湾品牌；高端设备用 **THK**（日本）、**IKO**（日本）
- **预压等级**：中预压 (Z1/Z2) 以消除间隙，提升刚性

#### 3.1.4 丝杠预紧与消隙

滚珠丝杠即使 C3 级也存在微米级轴向间隙。工业级 Z 轴通过以下方式消除：

1. **双螺母预紧**：两个螺母之间加垫片/弹簧，产生预压力，使滚珠始终与滚道双面接触
2. **过尺寸滚珠**：选择略大于滚道公称尺寸的滚珠，实现负间隙配合
3. **螺母旋转式预紧**：通过差动螺纹实现精密预紧力调节

### 3.2 驱动与闭环控制

#### 3.2.1 电机选型：步进 vs 伺服

```
工业级 DLP Z 轴电机方案决策树：

需求：层厚 50 μm，定位精度 ≤ 3 μm
│
├── 方案 A：开环步进电机
│   ├── 微步细分：1/64 → 理论分辨率 ~0.3 μm (4mm 导程)
│   ├── 问题：微步距角精度差，扭矩不足时丢步不报错
│   └── 结论：❌ 不能满足 ±3 μm 定位精度要求
│
├── 方案 B：闭环步进电机（步进 + 编码器）
│   ├── 电机尾部集成编码器 (1000–4000 P/R)
│   ├── 驱动器实时比较指令位置与实际位置
│   ├── 丢步自动补偿，到位信号输出
│   ├── 定位精度：~3–5 μm ← 接近 S200 指标
│   └── 结论：✅ 中端工业设备主流方案，性价比高
│
└── 方案 C：交流伺服电机
    ├── 增量式/绝对式编码器 (17–23 bit)
    ├── 三环控制：电流环 → 速度环 → 位置环
    ├── 定位精度：≤ 1 μm
    ├── 典型品牌：松下 MINAS A6, 安川 Σ-7, 三菱 MR-J4
    └── 结论：✅ 高端工业设备首选，成本最高
```

> 💡 **S200/Cute300 推断**：设备重量 122kg、定位精度 ≤3μm、同级别设备 ShapeSolid 明确采用"松下伺服电机 + HIWIN 导轨 + TBI 丝杆"。S200 大概率采用**闭环步进电机或交流伺服电机**。联泰科技 Cute300 产品页明确标注"高精密双导轨滚珠丝杆"但未公开电机类型——这在工业设备行业属于正常的技术保密范畴。

#### 3.2.2 位置反馈层级

Z 轴定位的闭环控制有三种反馈层级：

```
层级 1：半闭环 (Semi-Closed Loop)
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ 控制器    │────▶│ 驱动器    │────▶│ 电机     │──▶ 丝杠 → 平台
  └──────────┘     └──────────┘     └────┬─────┘
                                         │
                                    ┌────▼─────┐
                                    │ 编码器    │  ← 测电机轴转角
                                    │ (Encoder) │     反馈到驱动器
                                    └──────────┘
  优点：成本适中，抑制丢步
  局限：无法补偿丝杠热膨胀、磨损、联轴器弹性变形

层级 2：全闭环 (Full Closed Loop) — 光栅尺
  ┌──────────┐     ┌──────────┐     ┌──────────┐
  │ 控制器    │────▶│ 驱动器    │────▶│ 电机     │──▶ 丝杠 → 平台
  └──────────┘     └──────────┘     └──────────┘          │
       ▲                                                   │
       └───────────── 光栅尺读数头 ◀────────────────────────┘
                   (Renishaw / Heidenhain)
  优点：直接测量平台位移，补偿所有中间环节误差
  精度：±1 μm 级（如 Renishaw TONiC 系列）
  成本：高（光栅尺 + 读数头 ~数千元）

层级 3：双闭环 (Dual Loop)
  电机编码器 (速度环) + 光栅尺 (位置环)
  优点：兼顾动态响应与绝对定位精度
  应用：最高端工业设备、半导体设备
```

> 💡 **S200 推断**：以 ≤3 μm 的 Z 轴精度和齿科设备的成本约束（售价通常在 ¥15–30 万区间），S200 最可能采用**层级 1 半闭环方案（伺服/闭环步进 + 电机编码器）**，通过精密丝杠和导轨保证机械精度。若宣称 3 μm 精度是全闭环光栅尺方案，通常会作为核心卖点公开（如同级别竞品 ShapeSolid 明确宣传"闭环控制"）。

#### 3.2.3 运动控制算法

Z 轴在每个打印层需执行以下运动序列：

```
                  抬升高度
                     ▲
    剥离高度 (~5mm)  │     ┌─────────┐
                     │     │ 等待树脂 │  ← 树脂回流填充
                     │     │ 回流填充  │
                     │     └─────────┘
    层厚 (50μm)      │          ┌──┐
                     │          │▼▼│  ← 下降到下一层位置
    ─────────────────┼──────────┴──┴──────▶ 时间
                     │  曝光固化
                     │
                     ├──── 抬升阶段 (Lift)
                     │     速度：20–60 mm/min (慢速剥离)
                     │     行程：3–6 mm (确保完全剥离)
                     │
                     ├──── 回落阶段 (Retract)
                     │     速度：50–100 mm/min
                     │     需精确停到"距底板 1 层厚"的位置
                     │
                     └──── 定位容差
                           ±3 μm 内确认到位 → 触发曝光
```

**关键控制参数**：

| 参数 | 典型值 | 对 Z 轴精度的意义 |
|------|-------|-----------------|
| 抬升速度 | 20–60 mm/min | 太快→剥离力冲击→平台抖动→Z 轴误差 |
| 抬升距离 | 3–6 mm | 太短→剥离不完全→下一层固化失败 |
| 回落速度 | 50–100 mm/min | 太快→树脂液面波动→首层误差 |
| 静止等待 | 0.5–2 s | 树脂充分回流+液面平稳→一致层厚 |
| 到位确认 | 编码器反馈 ±3 μm 内 | 确保实际位置 = 指令位置后再曝光 |

### 3.3 影响 Z 轴精度的非机械因素

Z 轴定位不仅仅是机械精度问题，以下因素同样关键：

#### 3.3.1 剥离力 (Peeling Force) 导致的动态误差

```
        成型平台
           │
    ┌──────▼──────┐
    │  已固化层    │  ← 与离型膜之间存在真空吸附力
    │  ════════════│
    │  离型膜 FEP  │  ← 弹性变形，剥离时产生"拔河效应"
    └──────┬──────┘
           │
        光机投影
```

- 每层固化后，已固化层与离型膜之间形成真空吸附 + 化学粘接力
- Z 轴抬升时剥离力可达 **数牛顿**，导致平台、丝杠、联轴器产生弹性微变形
- 剥离瞬间力突然释放 → 平台微振 → Z 轴定位偏差
- **大截面模型**（如全口义齿基托）剥离力远大于小截面（单颗牙冠）

**行业对策**：
- 模型倾斜 15–30° 摆放，减少每层截面积
- 使用 **ACF 膜**（低剥离力氟素膜）替代传统 FEP
- 抬升速度分段：初始慢速剥离 → 快速抬升
- 优化支撑结构，分散剥离力

#### 3.3.2 树脂收缩

- 光敏树脂聚合时体积收缩 **6–10%**
- 收缩在 Z 方向产生内应力，导致"层间翘曲"
- 不均匀收缩造成 Z 轴方向的**累积误差**
- **全牙弓模型**（跨度大）收缩影响尤为严重

#### 3.3.3 树脂温度与黏度

- 树脂温度影响黏度和流动性
- 低温 (如 < 20°C)：树脂粘稠 → 回流慢 → 层厚不均
- 高温 (如 > 30°C)：树脂过稀 → 可能发生不需要的暗反应
- S200 推荐工作温度 22–26°C，这是平衡黏度与反应速率的最佳区间

#### 3.3.4 离型膜状态

- 膜磨损/雾化 → 剥离力不均匀 → Z 轴每次抬升行为不一致
- 膜松弛 → 固化层与膜之间的间隙不稳定 → 层厚波动
- **诊断信号**：打印件出现等间距横向条纹 → 优先排查离型膜和 Z 轴螺杆

### 3.4 工业级 vs 消费级 Z 轴方案对比

| 维度 | 消费级 (如 Anycubic/ELEGOO) | 工业级 (如 S200 EvoDent) |
|------|---------------------------|------------------------|

## 5. Z 轴精度诊断与验证方法

### 5.1 打印测试件诊断

来自工业实践的标准诊断方法：

```
测试件：10 × 10 × 80 mm 直立方柱

观察结果 → 诊断：
├── 等间距横向条纹 (周期性)
│   ├── 间距 = 丝杠导程 → Z 轴螺杆偏心/弯曲
│   ├── 间距 ≠ 丝杠导程 → 联轴器松动/不同心
│   └── 条纹在特定高度集中 → 该段导轨/丝杠脏污
│
├── 随机横向条纹 (非周期性)
│   ├── 离型膜雾化/划痕 → 更换 FEP/ACF 膜
│   ├── 树脂温度波动 → 检查温控
│   └── 抬升速度过快 → 降低至 20–40 mm/min
│
├── 整体高度偏差 (系统性)
│   ├── 偏低 → 曝光过度 (光功率过高 / 曝光时间过长)
│   ├── 偏高 → 曝光不足 / 丝杠回程间隙未补偿
│   └── 层厚不一致 → 检查 Z 轴归零传感器的重复性
│
└── 顶面/底面不平
    ├── 平台本身不平 → 机加工校准
    └── 丝杠与导轨不平行 → 装配校准 (打表)
```

## 6. 总结

### 6.1 齿科 DLP 3D 打印机 Z 轴定位的核心命题

Z 轴在 DLP 打印机中承担的是**纳米级重复定位**任务：每一层必须在 50 μm 层厚的基础上，以 ≤ 3 μm 的重复性回到精确位置。这不是一个简单的"电机转多少圈"的问题，而是一个涉及**机械传动链、闭环控制策略、动态剥离力管理、树脂流变学和环境温控**的多物理场系统问题。

### 6.2 S200 EvoDent 的 Z 轴方案总结

| 层次 | 方案（基于公开信息+行业推断） |
|------|---------------------------|
| **传动** | 高精密滚珠丝杠 (C3 级以上) + 双直线导轨 |
| **驱动** | 闭环步进电机 / 交流伺服电机 |
| **反馈** | 半闭环（电机编码器） |
| **消隙** | 双螺母预紧 + 导轨预压 |
| **精度** | Z 轴定位 ≤ ±3 μm |
| **控制** | DSCON 软件闭环位置确认 + 光源功率自动补偿 |

### 6.3 关键洞察

1. **滚珠丝杠是硬门槛**：消费级滑动丝杠 vs 工业级滚珠丝杠造成 Z 轴精度 10 倍差距，这是工业级齿科设备不可妥协的选择。

2. **重量即刚性**：S200 的 122 kg 并非"笨重"，而是机械稳定性的保障——大质量基座吸收振动、抑制热变形、保证导轨长寿命。

3. **Z 轴精度 ≠ 打印精度**：Z 轴定位 ≤ 3 μm 是机械精度，实际打印件 Z 向精度还受树脂收缩 (6–10%)、剥离力弹性变形、后固化翘曲等因素影响——最终零件精度约为 ±50 μm，这是合理的。

4. **闭环的价值在于"确认到位"，而非"驱动分辨率"**：1/64 微步的开环步进理论上也有 0.3 μm 分辨率，但丢步时系统完全不知道。闭环的价值在于：**曝光之前，系统确认平台确实在正确位置**——这对逐层累加 2000+ 层（100mm / 0.05mm = 2000 层）的打印过程至关重要。

5. **光栅尺全闭环是超配**：对于 50 μm 层厚的 DLP 工艺，3 μm 半闭环精度已足够。光栅尺全闭环（±1 μm）更适用于纳米压印、晶圆级光学等更高精度场景。

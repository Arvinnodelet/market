### 名字由来

"ELEGOO" 由 "electronic"（电子）与 "googol"（10¹⁰⁰，象征无限可能）组合而成。中文名"智能派"直接对应公司定位——智能硬件派系。"爱乐酷"为面向中文消费市场的音译品牌。

### 创始背景

洪英盛与陈波为暨南大学市场营销专业同学，均出身中国邮政系统，后辞职创业。二人先做跨境电商，在项目中发现了海外市场对中国电子元器件的旺盛需求，于是从华强北采购电阻、传感器、开发板等组件，打包成 STEM 教育套件销售。据 Fabbaloo 对联合创始人 Kevin Wang 的专访，该业务一度获得约 300% 毛利率，ELEGOO 在 2018 年成为 Amazon 上销量第一的 Arduino 套件品牌。2018–2019 年前后 STEM 市场饱和，公司切入 3D 打印赛道，由此进入高速增长期。


## 三、业务与产品版图

截至 2026 年 9 月，智能派以**光固化（树脂 MSLA）为基本盘、FDM 为增长极**，双技术路线并行：

```
FDM（熔融沉积）                            光固化（树脂 MSLA）
─────────────────────────────────────────────────────────────
旗舰封闭 CoreXY（Centauri 系列）             旗舰（Saturn 4 Ultra 16K）
├── Centauri          (256³) $199          └── 10" 16K LCD / Tilt Release
├── Centauri Carbon   (256³) $299          └── 211.7×118.4×220 mm / $519.99
└── Centauri Carbon 2 (256³) $449          入门/桌面（Mars 系列）
    └── CANVAS 四色 (Combo)                └── Mars 5 Ultra  7" 9K / 153×78×165
经典入门（Neptune 4 系列）[在售，边缘化]
├── Neptune 4 / 4 Pro / 4 Plus / 4 Max     大尺寸（Jupiter 系列）
└── 开放式 Bedslinger + Klipper            └── Jupiter SE  12.8" / 大尺寸
工业级（OrangeStorm Giga）
└── 800×800×1000 mm [在售]
```

| 产品线 | 定位 | 价格区间 (USD) | 技术 | 核心用户群 |
|---|---|---|---|---|
| **Centauri** | FDM 旗舰/次旗舰 | $199–$449+ | 封闭式 CoreXY + 可选 CANVAS 多色 | 家庭、进阶玩家、工作室 |
| **Neptune 4** | FDM 经典入门 | ~$200–$400 | 开放式 Bedslinger + Klipper | 价格敏感用户、DIY 玩家 |
| **OrangeStorm Giga** | FDM 工业大尺寸 | $1,500+ | 大尺寸 Cartesian | 打印农场、大型件用户 |
| **Saturn** | 光固化旗舰 | ~$500 | MSLA 16K + Tilt Release + 恒温料槽 | 手办、牙科、批量小件 |
| **Mars** | 光固化入门 | ~$300 | MSLA 9K + Tilt Release + AI 摄像头 | 微缩模型、新手 |
| **Jupiter** | 光固化大尺寸 | ~$500–$900 | MSLA 6K 大平台 | 大型树脂件、批量生产 |

**产品组合健康度评估**：

- FDM 侧已用 Centauri 三代（$199/$299/$449）覆盖入门到中端，但 $500 以上的高端位（对应拓竹 P2S/X2D、创想 K2）仍空缺；
- 光固化侧 Mars/Saturn/Jupiter 覆盖小/中/大三档，是公司最强、最完整的品类；
- Neptune 系列 2023 年发布后未再更新，处于"在售但边缘化"状态（部分区域渠道仍在销售，官方商城已以 Centauri 为主推）；OrangeStorm Giga 定位工业大尺寸，与消费级主线关联弱；
- 多色系统 2026 年 2 月才落地（CANVAS），落后拓竹 AMS、创想 CFS、纵维 ACE 各约 1–2 年。

## 四、产品线详解

### 4.1 Centauri 系列 — FDM 旗舰（封闭式 CoreXY）

Centauri 是智能派 FDM 战略转型的核心平台：首次放弃开放式 Bedslinger 路线，转向封闭式 CoreXY + 全自动校准，直接对标拓竹 P 系列与创想 K 系列。

#### Centauri Carbon（2025 年 2 月，$299.99 首发价）

| 参数 | 详情 |
|---|---|
| **打印尺寸** | 256 × 256 × 256 mm |
| **最高速度** | 500 mm/s（推荐约 250 mm/s） |
| **最高加速度** | 20,000 mm/s² |
| **最高喷嘴温度** | 320°C（硬化钢喷嘴 + 60W 陶瓷加热器） |
| **热床温度** | 110°C（1000W AC 加热，220V 条件下） |
| **热床** | 双面柔性磁吸钢板（光滑 PLA 面 + 纹理 PEI 面） |
| **结构** | 一体化压铸铝合金框架 + SPCC 侧板 + 钢化玻璃顶/侧板，整机免组装 |
| **自动调平** | 4 个压力传感器 + 自研算法，一键首层校准，自动 Z 轴补偿 |
| **固件** | ELEGOO OS（8GB ROM，OTA 升级） |
| **算法** | 振动补偿（Input Shaping）+ 压力提前（Pressure Advance） |
| **摄像头** | 内置 720P（实时监控 + 延时摄影） |
| **显示屏** | 4.3 英寸电容触摸屏 |
| **连接** | Wi-Fi + USB |
| **过滤** | 内置活性炭过滤 |
| **材料** | PLA/PETG/TPU/ABS/ASA/碳纤维增强/尼龙/PC |
| **噪音** | 评测实测最高约 55 dB（静音模式更低） |
| **重量** | 17.5 kg；外形约 398×404×490 mm |
| **切片软件** | ElegooSlicer（基于开源 Orca Slicer） |

首发直接以 $299.99 定价（英国 £299.99、欧盟 €329.99），2 月 17 日预售、2 月 20 日零售，未走众筹。3D Printing Industry、Overclock3D 等评测普遍评价为"开箱打印质量出色、框架坚固、同价位性能突出"；主要批评集中在高噪音（最高 55 dB）与仓内照明偏弱。

#### Centauri（2025 年 8–9 月，$199）

| 参数 | 详情 |
|---|---|
| **与 Carbon 版差异** | 无硬化钢喷嘴（标准喷嘴）、无内置摄像头、无侧板/腔体（开放式） |
| **共享平台** | 256³、500 mm/s、20,000 mm/s²、CoreXY、32 mm³/s 体积流量、压铸铝框架、全自动校准、振动补偿 + 压力提前 |

$199 将封闭式设计理念（保留压铸框架与自动校准，砍掉腔体）下探到"冲动消费"价格带。Fabbaloo 评价其"重新定义预算级 3D 打印"，直接冲击同价位开放式 Bedslinger 机型。

#### Centauri Carbon 2（2026 年 2 月，$449；Combo 含 CANVAS）

| 参数 | 详情 |
|---|---|
| **打印尺寸** | 256 × 256 × 256 mm |
| **最高速度** | 500 mm/s（推荐 250 mm/s）；20,000 mm/s² |
| **运动系统** | CoreXY + 双 4260 步进电机 + 低摩擦金属直线导轨 |
| **最高喷嘴温度** | **350°C**（硬化钢，较一代 +30°C） |
| **热床** | 110°C 双面弹簧钢板（纹理 PEI + PLA 专用面） |
| **腔体** | 全封闭 + 隔热顶盖 + 智能自动调节风栅 + HEPA + 活性炭过滤 |
| **调平/校准** | 121 点自动调平 + 自动 Z-offset + 主动振动补偿 + 压力提前校准 + 堵头检测 |
| **传感器** | 31 个智能传感器 |
| **显示屏** | 5 英寸电容触摸屏（11 种语言） |
| **噪音** | ≤45 dB（静音模式） |
| **多色** | 可选 CANVAS 四色系统（RFID 识别、自动换色、耗材耗尽自动切换备用料盘） |
| **重量** | 17.5 kg（净重） |
| **联名** | ELEGOO × EMOJI 白色/银色特别版（仅外观差异，附 17 色 RFID 标签 PLA） |

PCMag 评测结论：四色打印可靠（40 小时四色打印无人值守完成）、公差表现优秀（0.05 mm 塞尺通过）；不足之处为单喷嘴多色的典型 purge 废料量大、预估打印时间偏乐观、料盘裸露无湿度检测。CNET 评价其为"第一台带多色系统的 Centauri"。

### 4.2 Neptune 系列 — FDM 经典入门（开放式 Bedslinger）

Neptune 是智能派 2022 年切入 FDM 的功臣系列，以 Neptune 4 Pro 为例：

| 参数 | Neptune 4 Pro（2023 年） |
|---|---|
| **打印尺寸** | 225 × 225 × 265 mm |
| **最高速度** | 500 mm/s（推荐 250 mm/s） |
| **喷嘴温度** | 300°C |
| **热床** | 250W 分段式智能热床（100W + 150W 双区），110°C |
| **挤出** | 双齿轮直驱，5.2:1 减速比（较 Neptune 3 Pro 轻 25%） |
| **调平** | 121 点自动调平 + 手动辅助调平 |
| **固件** | **预装 Klipper**（ARM 64 位 1.5GHz 四核，8GB 内存），支持 Input Shaping / Pressure Advance |
| **散热** | 2× 4015 滚珠侧吹 + 4× 4020 滚珠鼓风，静音驱动下 <50 dB |
| **Z 轴** | 双电机 + 丝杆 |
| **价格** | 约 $359–$480（随渠道波动） |

Neptune 4 系列（4 / 4 Pro / 4 Plus / 4 Max，最大 320×320×385 mm）目前与 Centauri 并存销售，定位为低成本、开放式、可深度定制（Klipper 调参）的入门选择。但从产品节奏看，2023 年后未再更新，资源明显转向 Centauri 平台——Neptune 处于"维护期"，预计逐步退出或仅保留入门型号。

### 4.3 光固化产品线 — Saturn / Mars / Jupiter（MSLA）

#### Saturn 4 Ultra 16K（2025 年 1 月，$519.99）

| 参数 | 详情 |
|---|---|
| **LCD 屏幕** | 10 英寸 16K 黑白单色 LCD（15,120 × 6,230 px） |
| **XY 分辨率** | 14 × 19 µm；Z 轴精度 0.02 mm |
| **打印尺寸** | 211.68 × 118.37 × 220 mm |
| **最高速度** | 150 mm/h（Tilt Release 倾斜剥离） |
| **剥离技术** | Tilt Release 料槽倾斜剥离（业界首创于 S4U 12K，2024） |
| **恒温料槽** | 智能恒温加热，维持树脂 30°C |
| **智能传感器** | 残渣检测、树脂余量提醒、调平状态检测 |
| **AI 摄像头** | 实时监控 + 失败检测 + 延时摄影 |

### 5.2 Tilt Release 倾斜剥离深度分析

Tilt Release 是智能派最具原创性的核心技术，2024 年随 Saturn 4 Ultra 首次落地，后下放至 Mars 5 Ultra 与 16K 升级版，构成树脂产品线的共性平台技术。

#### 5.2.1 工作原理

传统 MSLA 打印每层固化后，构建平台整体垂直抬升，将成型件从离型膜（FEP/ACF）上剥离。剥离力在脱离瞬间集中释放，产生三个问题：剥离力峰值高（需更强支撑、更大抬升行程）、剥离冲击引发层间微裂纹、剥离耗时长。

Tilt Release 将"平台抬升"改为"料槽倾斜"：料槽绕前缘枢轴旋转一个角度，离型膜与成型件之间形成逐边推进的分离前沿，剥离由"整面瞬时脱离"变为"线状渐进脱离"：

```
传统垂直剥离（Mars/Saturn 3 世代）          Tilt Release（S4U / M5U）

  平台抬升                                料槽绕前缘倾斜
  ┌────────┐                             ┌────────┐
  │ 成型件  │                             │ 成型件  │ ← 平台保持
  │ ██████ │  ↑ Z                        │ ██████ │
  └────┬───┘  │                           └────┬───┘
  ┌────▼───┐  │  整面剥离                  ┌───▼──┐   料槽下倾
  │ 离型膜  │  │  力峰值集中于瞬间          │离型膜│   ∕
  └────────┘  ↓                            └──────┘  ∕ 分离前沿
                                                     逐边推进
  剥离力曲线：                                 剥离力曲线：
  F                                       F
  │   ▂▂▂▂▂▂▂▂ 尖峰                          │  ▂▂▂▂▂ 平台期
  │  ╱        ╲                              │ ╱       ╲
  │ ╱          ╲                             │╱         ╲
  └─────────────→ t                         └─────────────→ t
```

渐进剥离将瞬时峰值力摊平为持续时间更长的低幅值力，带来三重收益：

1. **速度**：剥离行程缩短、等待时间减少，整机速度提升至 150 mm/h（同世代垂直剥离机型通常 60–100 mm/h）；
2. **成功率**：剥离力峰值下降 → 支撑需求降低、细支撑断裂减少、大截面件脱膜风险下降；
3. **自动化基础**：剥离力更可控 → 可配合自动调平与残渣检测实现无人值守连续打印。

#### 5.2.2 硬件实现

| 组件 | 说明 |
|---|---|
| **料槽枢轴** | 料槽前端铰接于机架，绕前缘旋转 |
| **驱动机构** | 电机/丝杆驱动料槽后缘升降，实现倾斜角控制（具体角度未公开） |
| **料槽快拆** | 倾斜机构要求料槽可快速锁定/释放（较传统机型更复杂的接口） |
| **位置反馈** | 料槽位置检测，配合残渣检测传感器（S4U 16K 起） |
| **Z 轴简化空间** | 平台只需小幅抬升即可开始剥离，Z 轴行程利用更高效 |

**结构代价**：倾斜机构使料槽组件重量与复杂度上升，且料槽每次打印前需可靠复位对齐；树脂在倾斜过程中向一侧流动，液位波动比垂直剥离更大，需要液位控制或加大余量。

#### 5.2.3 竞品方案对比

| 维度 | ELEGOO Tilt Release | 传统垂直抬升（各厂通用） | 纵维 Wave Release NFEP | 黑格力控剥离 |
|---|---|---|---|---|
| **机制** | 料槽倾斜渐进剥离 | 平台垂直抬升整面剥离 | 膜面微结构降剥离力 | 传感器闭环控制剥离过程 |
| **剥离力峰值** | 显著降低 | 高（基准） | 降幅约 60%（厂商口径） | 主动控制 |
| **硬件成本** | 中（倾斜机构） | 低 | 低（膜材更换） | 高（传感器 + 闭环） |
| **适配机型** | S4U / S4U 16K / M5U | 绝大多数消费机 | Photon 系列 | Reflex 系列 |
| **开放程度** | 硬件技术，不锁定 | — | 膜材耗材锁定 | 软硬件全锁定 |

> 工程判断：Tilt Release 与 Wave Release NFEP 分别从"运动机构"与"界面材料"两个方向解决同一问题，且**不互斥**——理论上可叠加。智能派选择机构路线，换取了膜材兼容自由（用户可继续使用第三方 FEP/ACF），这是与纵维立方路线（膜材成为耗材收入）的商业模式差异。

#### 5.2.4 优势与局限

**优势**：
1. 速度与成功率双提升，构成 150 mm/h 高速树脂打印的物理基础；
2. 不改变膜材生态，兼容第三方离型膜，社区自由度保持；
3. 平台级技术：一代开发、全系列下放（S4U → S4U 16K → Mars 5 Ultra），研发摊销效率高。

**局限**：
1. 倾斜运动增加料槽机械复杂度与潜在故障点（枢轴磨损、复位精度漂移）；
2. 树脂液位随倾斜波动，液位管理要求提高；
3. 分离前沿的力分布依赖膜面张力均匀性，长期使用膜面松弛后效果衰减（缺乏膜面状态反馈）；
4. 该技术已随时间扩散（2024 年首创，2026 年竞争对手跟进风险），先发窗口有限。

| **多材料能力** | PLA/PETG/TPU/ABS/ASA/PC/PA/CF 线材 | 同等级 | 同等级 | 同等级 |
| **首发价格** | Combo 较单机溢价约 $150–200 | Combo 溢价约 $200+ | 类似 | 类似 |

**定位判断**：CANVAS 的技术独特点仅在"备用料盘自动接管"（打长件中途耗材耗尽时的容错），其余为跟进功能。其战略意义在于**补齐 $449 价位段的多色能力**，使 CC2 Combo 成为同类多色封闭 CoreXY 中价格最低者之一——PCMag 评价其"为预算用户打开多色之门"，同时坦承该方案在换色废料上并无本质改进（单喷嘴 purge 方案的共性）。

### 5.5 光固化光学路线：16K + 被动均光

Saturn 4 Ultra 16K 的 10 英寸 16K 单色 LCD（15,120×6,230 px、14×19 µm）参数处于消费级第一梯队。光学上采用 COB 光源 + Fresnel 透镜的**被动均光**方案（与纵维 LightTurbo 同类），整场均匀性 ≥90% 量级；相比黑格 OptiZone 的主动分区补偿，被动方案无法修正区域性差异与长期老化漂移（本项目黑格报告已做详细对比）。智能派的差异化在于其自述"借鉴手机屏幕技术改良曝光屏，成本压低三分之一"——将华强北手机产业链的 LCD 供应链能力迁移到树脂机曝光屏，是其参数竞赛中的成本后盾。

### 5.6 子系统技术定位总览

| 子系统 | ELEGOO 定位 | 评估依据 |
|---|---|---|
| **运动系统（FDM）** | 行业主流 | CoreXY 标准方案 + 金属导轨（CC2）；无 PMSM 伺服（拓竹独有） |
| **挤出/热端** | 行业主流 | 硬化钢喷嘴 350°C（CC2）+ 陶瓷加热器；无快拆 |
| **运动系统（树脂 Z 轴）** | 行业主流 | 丝杆 Z 轴，0.02 mm；弱于纵维 P1 的滚珠丝杠+双导轨 |
| **传感器** | 行业中上（FDM）/ 行业领先（树脂） | 4 压力传感 + 31 传感器（CC2）；树脂线残渣/液位/调平检测 + AI 摄像头领先同级 |
| **剥离技术（树脂）** | **行业首创/领先** | Tilt Release 平台级创新 |
| **光学（树脂）** | 参数领先、方案常规 | 16K 参数第一梯队；被动均光 |
| **固件** | 行业标准 | Klipper 内核扩展，开源红利 |
| **切片软件** | 跟随 | ElegooSlicer（OrcaSlicer 衍生）、SatelLite 新发布 |
| **云/App/社区** | **显著落后** | 无成型模型社区，App 生态弱（管理层公开承认） |

### 5.7 工程权衡总结

1. **成本工程 > 单项技术领先**：与拓竹的"全栈自研"不同，智能派的每一项选择（压铸框架、压力传感、Klipper/OrcaSlicer 开源复用、手机屏供应链）都指向"以最小自研投入获得最大性价比"，自研集中在剥离技术与供应链工艺上；
2. **树脂创新 > FDM 创新**：唯一真正原创（Tilt Release）在树脂线；FDM 侧 2025–2026 均为快速跟进（CoreXY、多色），创新密度低于纵维（ACE GEN2 内置 4 通道）与拓竹；
3. **硬件速度 > 软件深度**：三代 Centauri 每半年迭代一次，硬件节奏领先；但软件生态（模型社区、App、云端）始终是缺口，且管理层明确将其列为下一阶段投入重点。

## 十、战略判断

### 核心优势

1. **光固化全球第一**：Mars/Saturn 双系列十年积累的品类心智 + 渠道（Amazon Bestseller 惯性）+ 150 国覆盖；
2. **成本工程体系**：压铸框架、2 分钟装配、供应链联合研发（曝光屏降本 1/3）、$199/$299 定价能力——这是比任何单项技术更难复制的组织能力；
3. **平台化产品策略**：Tilt Release 一代研发全系下放、Centauri 三代共用平台，研发效率高于同体量对手；
4. **资本与背书**：大疆战略投资 + 美团/高瓴等 B+ 轮，弹药充足且品牌势能上升；
5. **开放生态口碑**：开源切片/Klipper 兼容路线在 Maker 社区形成差异化好感。

### 结构性弱点

1. **软件生态断层**：无模型社区、无 App、无云平台——在"打印机 = 硬件 + 生态"的 2026 年格局下，这是最深的护城河缺口，管理层已公开承认；
2. **FDM 品牌溢价低**：Centauri 的爆量依赖绝对低价，$500 以上无产品，品牌向上通道未打开；
3. **创新密度不均**：树脂线原创（Tilt Release）后缺乏持续创新（16K 属参数竞赛），FDM 侧 2025–2026 均为跟进动作；
4. **财务透明度低**：利润率、耗材收入占比未公开，估值与商业模式质量难以外部验证；
5. **海外面临合规风险敞口**：>90% 海外收入集中于北美/欧洲，关税与贸易政策波动直接影响（与全行业共担）。

### 技术位置

树脂线：剥离技术原创 + 参数第一梯队，综合技术位置**领先**；FDM 线：架构主流、成本领先、传感中上、多色跟进，综合**中上**；软件栈：**落后**。整体技术定位为"硬件强、软件弱、成本优"。

### 制造位置

自建产线 + 月产 10 万台 + 两分钟节拍 + 150 万台年产能规划，制造体系在四小龙中**属第一梯队**；DFM 驱动的压铸一体框架证明其设计-制造一体化能力。风险点：快速扩产期（新基地）的品控一致性待验证。

### 竞争位置

**全球消费级 3D 打印第二营收体量 + 树脂第一 + FDM 最具威胁的性价比挑战者**。相对拓竹：规模与生态差距大，但价格带错位使其在 $200–$450 区间有真实杀伤力；相对纵维：综合实力占优但创新叙事略逊；相对创想：增长动能与资本热度占优。

### 战略角色与方向

智能派的路线清晰可辨：**以树脂基本盘反哺 FDM 扩张，以成本工程撕开封闭 CoreXY 市场，以大疆资源补强产品与质量体系，2026–2028 全力补软件生态**。公开目标（2026 年 ¥35–40 亿、三年 ¥50 亿）意味着未来两年仍需 ~30% CAGR——这要求 Centauri 持续放量且多色版（CANVAS）达到主流水平，同时树脂线守住份额。IPO 是大概率方向（未证实）。

```
          若补课失败则停留在"硬件性价比品牌"天花板）
```

### 公司定位

黑格科技是国内极少数具备光固化 3D 打印"光学、硬件、软件、材料"**全栈自研能力**的企业。公司以齿科（数字牙科）为基本盘完成技术积累与规模化盈利，2023 年起以 UltraCraft Reflex 系列切入消费级/专业桌面市场，被行业媒体称为对消费级光固化市场的"降维打击"——将工业级光引擎、精密 Z 轴与力控算法下放至万元以下价格段。

## 四、各系列产品详解

### Reflex 系列 — 消费/专业桌面光固化（LCD）

Reflex 系列是黑格从齿科 To B 切入消费市场的产品线，核心卖点为"**注塑级表面质量**"——以工业级光引擎、C5 精密 Z 轴和力控剥离算法，在消费价位实现接近注塑件的表面效果与 0.05 mm 级打印公差。四代机型构成从"入门体验"到"生产级"的完整阶梯。

#### UltraCraft Reflex

| 参数 | 详情 |
|---|---|
| **构建体积** | 192 × 121 × 220 mm |
| **成型技术** | LCD 光固化（下投影） |
| **光源** | 385 nm 光引擎（工业树脂、透明件不发黄的波长选择） |
| **XY 分辨率** | 33 μm |
| **打印精度** | ±16 μm |
| **层厚** | 50 μm（固定） |
| **打印速度** | 约 27 mm/h（Z 向） |
| **Z 轴** | C5 级工业模组，重复定位误差 96% 在 1 μm 内 |
| **显示屏** | 7" 触摸屏 |
| **连接** | USB / Wi-Fi / 以太网 |
| **整机功率** | 350 W |
| **重量** | 25 kg |
| **耗材体系** | 封闭体系：1L RFID/NFC 树脂料盒自动加注（原厂树脂锁定） |
| **智能功能** | AI 剥离力管理（逐层分析调整剥离力）、浮动平台自动调平（矫正 0.15° 倾斜，消除最大 240 μm 间隙）、残渣检测（最小 0.2 mm）、树脂自动加注、树脂加热（10°C→22°C 约 20 分钟） |
| **参考价格** | 中国 ¥9,999；美国约 $2,000–2,500（渠道促销曾低至 $1,998） |

> ⚠️ 初代 Reflex 采用**封闭树脂生态**：仅可使用黑格 RFID/NFC 原厂树脂料盒，第三方树脂无法通过识别。评测机构普遍肯定其打印精度（"master of its craft"），但指出封闭生态推高了单件打印成本。
> 💡 Reflex 的 25 kg 重量在消费级光固化机中罕见——这与"重量即刚性"的工业设计哲学一致：压铸底座 + 精密 Z 轴模组的刚性直接决定层纹表现。

#### UltraCraft Reflex RS

2024 年 9 月发布，定位"降维打击"——将 Reflex 的核心技术下放至千元级价位，同时开放 405 nm 第三方树脂。

| 参数 | 详情 |
|---|---|
| **构建体积** | 222.3 × 122.5 × 230 mm（比 Reflex 大，机身更紧凑） |
| **成型技术** | LCD 光固化，10.3" 8K 单色液晶 |
| **光源** | 405 nm **开放平台**（兼容第三方树脂） |
| **XY 分辨率** | 29.7 μm |
| **打印精度** | ±15–16 μm（公差控制在 0.05 mm 内） |
| **层厚** | 30–100 μm |
| **层速** | 平均 4.5 s/层（DMA 3.0 动态运动算法，较 Reflex 提升 33%） |
| **光学校准** | 屏幕划分 **60 个分区**独立校准，光强差异 ≤ 3% |
| **Z 轴** | C5 级模组（96% 重复定位误差在 1 μm 内）+ 自适应 Z 轴补偿，宣称"无层纹" |
| **力控** | 力传感器每秒 80 次实时采样，动态运动算法逐层调节剥离速度 |
| **显示屏** | 5" 触摸屏 |
| **整机功率** | 180 W（外置电源） |
| **重量** | 20 kg |
| **设置时间** | 15 分钟（配合 Blueprint 一键预处理） |
| **参考价格** | 中国首发 ¥5,599；美国 $699–999（单机）；含加热脉冲树脂槽 $898；含 PRM $1,388；含 Cure $1,448；全套 Combo 约 $2,107 |

> ⚠️ RS 相较初代 Reflex 的降本点：机身塑料件占比更高、外置电源、无倾斜倒树脂平台、实心（无孔）构建板易残留树脂、无内置树脂加热器（需另购加热树脂槽）。评测者评价其为"一台被难用固件拖累的好机器"——构建板锁止逻辑（打印后只能升高一次）、控制面板层级混乱、文件命名默认 32 位数字串是主要抱怨点。

#### UltraCraft Reflex 2

2025 年 10 月 27 日发布，与 2 Pro 组成 Reflex 2 系列，官方发布主题为"从 1 到 N，开启 3D 打印量产时代"——产品定位从"专业桌面"转向"稳定量产"，核心升级为 **161 分区 OptiZone 光引擎**与 Z 轴/温控/传感器的全面换代。

| 参数 | 详情 |
|---|---|
| **构建体积** | 230 × 144 × 230 mm |
| **光引擎** | **161 分区 OptiZone**：161 颗可独立 PWM 控制 Mini-LED，光均匀性 ≥ 94%，减少漏光、表面更平滑 |
| **液晶屏** | 10.7" Amber Screen Pro 琥珀屏：抗压能力提升 100 倍、抗 UV 寿命 6000+ 小时、官方 1 年保修 |
| **层厚** | 20–100 μm（支持 20 μm 低层厚） |
| **打印精度** | ≤ 0.05 mm（AI 驱动 86,000+ 点逐区光学校准） |
| **Z 轴** | C5 级模组 + **闭环 FOC 电机**（25,600 微步/转），80 kg 负载下精准定位；压铸一体机身底座 |
| **树脂液位** | 超声波液位检测（±0.5 mm），自动触发树脂加注 |
| **残渣检测** | 0.01 N 力传感器，可检出最小 0.15 mm 残渣，异常自动停机 |
| **调平** | 浮动构建平台自动调平（0.15° 偏差矫正） |
| **温控** | 智能温控：树脂 10°C→22°C 约 6 分钟，±1°C 保持 |
| **剥离** | AI 逐层剥离力管理 |
| **材料** | 支持 PAE20（弹性体）、PAT10（透明/韧性）、PAH270（高刚度耐热，270°C）、齿科牙龈树脂等 |
| **参考价格** | 中国 ¥12,999（首销优惠 ¥10,399）；美国 $1,799；英国 £1,566（经销商促销 £1,260） |

#### UltraCraft Reflex 2 Pro

2025 年 10 月 27 日发布的旗舰（Reflex 2 系列），面向小批量生产与工程树脂用户。

| 参数 | 详情 |

#### 2.1 OptiZone 分区光引擎技术详解

OptiZone 是黑格消费级产品线最核心的光学创新，直指 LCD 光固化打印**最根本的物理问题——光场均匀性**。树脂固化是"剂量依赖"过程：曝光剂量 = 光强 × 时间，任何光强不均匀都会直接转化为**零件各区域的固化深度差异**，进而造成尺寸偏差、翘曲和层纹。传统 LCD 打印机的光路缺陷恰恰集中在这一环。

##### LCD 光固化的光路与均匀性难题

```
传统 LCD 光固化光路（侧视）：

    ┌──────────────────────────┐
    │   UV LED 阵列（面光源）     │  ← 边缘衰减 + 热点分布
    │   ● ● ● ● ● ● ● ● ● ●    │     灯珠排布导致明暗交替
    └────────────┬─────────────┘
                 │
    ┌────────────▼─────────────┐
    │   菲涅尔/漫反射均光层       │  ← 一次性光学均光，静态补偿
    └────────────┬─────────────┘
                 │
    ┌────────────▼─────────────┐
    │   单色 LCD（掩膜成像）      │  ← 每个像素是"快门"
    └────────────┬─────────────┘
                 │
    ┌────────────▼─────────────┐
    │   离型膜（FEP/ACF）        │
    │   ═════════════════════    │
    │   液态光敏树脂              │
    │   ┌──────────────────┐    │
    │   │  已固化层（零件）   │    │  ← 光强不均 → 固化深度不均
    │   └──────────────────┘    │
    └──────────────────────────┘

问题根源：
- LED 灯珠离散排布 → 光场存在"网格状"明暗纹理
- 大面幅边缘光衰 → 中心与四角剂量差异可达 10%+
- 均光层只能"静态整形"，无法逐区修正
- 传统方案只能在整机层验收一个"平均均匀性"指标
```

**行业的传统应对**（Elegoo COB + 菲涅尔透镜、Anycubic LighTurbo 3.0）均属"被动均光"：改进光源排布与透镜整形，使整场均匀性达到 ≥90% 的水平，但**无法对不同区域做差异化补偿**，出厂后随时间老化产生的漂移也无法修正。

##### OptiZone 的解决方案：把面光源变成"像素化光源"


#### 2.2 C5 Z 轴与力控剥离闭环详解

黑格将齿科工业设备的机械精度体系整体下放至消费级产品线，其核心是 **C5 级精密 Z 轴 + 力传感器闭环 + DMA 动态运动算法**的三位一体方案——解决光固化打印的第二个根本问题：**Z 轴定位误差与剥离力冲击导致的层纹**。

##### 层纹的物理根源

光固化打印的层纹（layer lines）来自两个相互叠加的误差源：

```
层纹成因 1：Z 轴重复定位误差
    每一层固化前，平台需精确停在"离型膜上方 1 个层厚"的位置。
    丝杠回程间隙、螺距误差、弹性变形 → 每次停位不同 → 层厚波动 → 可见环纹

层纹成因 2：剥离力动态冲击
    已固化层与离型膜分离瞬间，剥离力突释 → 平台/Z 轴弹性回弹微振
     → 下一次归位位置偏移 → 周期性环纹（大截面层尤其明显）
```

**Z 轴定位精度必须远小于层厚**（典型层厚 30–100 μm，Z 轴重复定位需在个位数 μm），这正是黑格坚持使用滚珠丝杠而非消费级滑动丝杠的原因：

| 对比维度 | 消费级滑动丝杠（T 型） | 黑格 C5 级滚珠丝杠模组 |
|---------|---------------------|---------------------|
| 传动效率 | 25%–50% | 90%–99% |
| 反向间隙 | 固有间隙，难消除 | 可预紧消除 |
| 定位精度 | ~10–30 μm | C5 级：300 mm 行程累积误差 ≤ 18 μm，重复定位 96% 在 1 μm 内 |
| 磨损寿命 | 短（滑动摩擦） | 长（滚动体均匀承载） |
| 成本 | 数十元 | 数百至上千元 |
| 装配要求 | 低 | 高（预紧力、导轨平行度） |

##### Reflex 2 的 Z 轴闭环架构

```
Reflex 2 / 2 Pro Z 轴系统（推断架构，基于官方披露）：

┌────────────────────────────────────────────┐
│              Z 轴运动控制链                  │
│                                            │
│  DMA 3.0 运动控制器                          │
│    │  ← 逐层剥离力数据（力传感器 80 Hz）       │
│    │  ← 自适应运动曲线（抬升/回落/停位）       │
│    ▼                                       │
│  FOC 闭环电机驱动（25,600 微步/转）           │
│    │  ← 磁场定向控制（矢量控制）              │
│    │  ← 编码器位置/转矩反馈闭环               │
│    ▼                                       │
│  C5 级滚珠丝杠（预紧消隙）                    │
│    ▼                                       │
│  构建平台（浮动式，0.15° 自动调平）            │
│                                            │
│  结构支撑：压铸一体机身底座                    │
│    · 80 kg 负载下保持定位精度                 │
│    · 一体成型减少装配误差累积                 │
└────────────────────────────────────────────┘
```

**三个关键设计选择**：

1. **FOC 闭环电机而非开环步进**：消费级打印机普遍使用开环步进——丢步不报错、低速爬行有扭矩脉动。FOC（Field-Oriented Control）矢量控制将电机作为伺服系统运行：位置、速度、转矩三环反馈，25,600 微步/转的分辨率意味着理论单步位移远小于 1 μm（以 5 mm 导程计约 0.2 μm/微步）。**闭环的价值不在分辨率而在"确认到位"**——曝光前系统确认平台确实停在目标位置，这对每层都依赖精确定位的打印过程至关重要。

2. **力传感器驱动的 DMA 3.0 动态运动算法**：力传感器以 80 Hz 实时采样剥离力，DMA 算法据此**逐层调节抬升/回落速度曲线**：

```
              剥离力曲线（单层分离过程）
   力 ▲
     │      ╱╲ ← 峰值剥离力（膜-件分离瞬间）
     │     ╱  ╲
     │    ╱    ╲__
     │   ╱         ╲_____ ← 完全分离后趋稳
     │  ╱
     └─╱──────────────────────▶ 时间
       ┌────┐  ┌──────────────┐
       │ 抬升│  │ 分离 → 回落   │
       └────┘  └──────────────┘

DMA 3.0 策略：
- 分离阶段减速：峰值剥离力显著降低
- 分离完成瞬间提速：快速越过"空行程"
- 停位阶段低速蠕动：精确定位下一层
→ 综合效果：Reflex RS 平均层速 4.5 s（初代 Reflex 12 s 的 1/3 以下）
```

   力控闭环的意义：剥离力是**随零件截面、树脂黏度、膜老化实时变化的量**，固定速度曲线无法在全工况下最优——要么在易剥离时浪费时间，要么在大截面时力冲击超限。实时力反馈让运动曲线"贴着剥离力上限走"，这是"无层纹"宣称的算法基础。

3. **浮动构建平台自动调平**：平台与 Z 轴连接处采用浮动结构，抵膜时自动贴合离型膜平面，矫正最大 0.15° 的安装倾斜（消除最大 240 μm 的间隙）——将"机械装配精度"转化为"自动对位"，降低产线装配要求的同时保证首层一致性。

#### 2.3 Pulsing Release Module 脉冲剥离详解

PRM（脉冲剥离模块）是黑格独有的机械创新，针对光固化打印的第三个根本问题：**剥离力与零件精细结构之间的矛盾**。

##### 剥离力的物理本质

每层固化后，已固化层通过范德华力 + 真空吸附粘附在离型膜上。分离所需拉力与**当前层截面积**成正比——截面越大，剥离力越大。这带来一个恶性循环：

```
            剥离力过大时的失效链

  大截面层 / 细支撑结构
        │
        ▼
  峰值剥离力超过支撑/细部结构强度
        │
    ┌───┴───┐
    ▼       ▼
  细支撑断裂   薄壁/悬垂变形
   → 打印失败   → 层纹、精度损失

  传统缓解手段（各有代价）：
  · 增加支撑数量/接触面积 → 后处理变难、表面疤痕多
  · 降低抬升速度 → 打印时间大幅增加
  · 倾斜剥离机构 → 大面幅机器仍有峰值力问题
  · 模型摆向优化 → 增加用户工作量，牺牲部分表面质量
```

##### PRM 的解决思路：把"一次撕离"变成"多次小步撕离"

```
无 PRM：持续拉力撕离
 力 ▲
   │        ╱╲ ← 单次峰值剥离力高
   │       ╱  ╲
   │      ╱    ╲____
   │     ╱          ╲___
   └────╱──────────────────▶ 位移
        └──┘  └──┘
       Z 抬升  分离完成

有 PRM：脉冲式分离
 力 ▲
   │  ╱╲ ╱╲ ╱╲ ← 脉冲振动，峰值力降低 ~50%
   │ ╱  ╲╱  ╲╱  ╲
   │ ╱            ╲___
   └╱─────────────────────▶ 位移
    └──┘└──┘└──┘└──┘
    每个脉冲局部撕离一段界面
    裂纹以脉冲节律扩展，避免"整面同时撕离"
```

**物理机制**：材料界面的粘附失效本质是**裂纹扩展**过程。连续拉力要求裂纹在整层界面同步启动，需要克服总粘附力的峰值；脉冲式加载让裂纹在每一拍中仅局部扩展一段，峰值力显著降低。类似"撕胶带时一鼓作气 vs 一拉一停"——后者峰值力更小，但注意：**脉冲频率与幅值必须匹配树脂的黏弹性响应**，这正是黑格对 PRM 与自研树脂做联合优化的原因。

> - **NFC/RFID**：初代 Reflex 的 1L 料盒带 RFID/NFC 识别（封闭体系核心）；RS 为开放平台，不设耗材锁定；Reflex 2/2 Pro 官方未明确是否延续料盒识别（🟡，材料工艺参数通过 Blueprint 云端预设实现）
> - **FOC 编码器**：Reflex 2/2 Pro 官方确认 FOC 闭环电机（25,600 微步/转）；初代/RS 仅确认"C5 模组 96% 重复定位 1 μm 内"，电机类型未公开，推断为高细分闭环方案（🟡）
> - **浮动平台调平**：全系标配，0.15° 倾斜矫正能力为官方通用参数
> - **分区光引擎**：RS 60 分区、Reflex 2 161 分区、Reflex 2 Pro 1032 分区；初代 Reflex 未披露分区校准

### 3. 齿科工业级制造的"降维打击"

黑格消费级产品线的全部技术差异化，最终可归结为一句话：**把齿科工业设备的工程体系，整体降本下放至消费级价位**。

| 齿科工业需求 | 沉淀的技术 | 下放至消费级 |
|---|---|---|
| ±50 μm 级临床精度 | C5 级 Z 轴模组、分级滚珠丝杠 | Reflex 全系 |
| 修复体表面质量（免抛光） | 光场均匀性控制、剥离力管理 | OptiZone + DMA 3.0 |
| 技工所批量一致性（95% 批次一致） | AI 光学校准、工艺参数芯片化 | 86,000+ 点校准、树脂预设 |
| 无人值守量产（16h） | HiVE 自动加液/铲件、云端监控 | 超声液位、自动加注、残渣检测 |
| III 类医疗器械材料 | 树脂配方与工艺耦合能力 | UltraPrint 全系 + 开放 405 nm |

这条路径的不可复制性在于**逆向顺序**：多数消费级厂商是先做消费机再向上做工业机，黑格是先拥有工业级全套能力（光学、材料、软件、产能）再向下做消费机——其消费机的 BOM 里有工业级部件（C5 丝杠、FOC 电机、定制光学件），而售价锚定的是消费级市场。

### 竞争策略分析

黑格在消费级市场采取的是**"从专业向下"策略**，与拓竹在 FDM 市场的"从上打下"同构但路径不同：

1. **基本盘锚定**：齿科业务规模化盈利（技工端市占率 60%+）为消费级产品线提供现金流与试错空间——消费级打价格战无生存压力
2. **技术降维**：把齿科工业设备的光引擎、Z 轴、力控系统整体下放，在 $699–4,000 价格带形成"参数不占优、效果占优"的差异化（RS 的 29.7 μm 分辨率低于 Saturn 4 Ultra 16K 的 14×19 μm，但光均匀性、Z 轴精度、力控剥离的综合效果被评测认为更好）
3. **避开红海**：不参与 $200–500 价格带血拼，占据"专业桌面"空档——上有 Formlabs（$4,499+），下有 Elegoo/Anycubic，Reflex 卡位 $699–4,000
4. **生态锁入**：初代 Reflex 的封闭树脂体系（RFID 料盒）验证了"设备+耗材"剃刀模式后，RS 转向开放平台换取市占率，Reflex 2/2 Pro 回归"原厂树脂工艺耦合"路线——阶梯式生态策略
5. **第二曲线**：2026 Q3 桌面全彩光固化产品线对标万元至数十万元级设备，目标是把"全彩"从工业级（Stratasys PolyJet 级别）拉入桌面市场

### 关于封闭生态的提醒

> ⚠️ **树脂-机型-模块三者必须匹配**：初代 Reflex 仅吃原厂 RFID 料盒；RS 虽开放但无法正确固化 PAH10/PAU20 等 385 nm 工业树脂；PRM 与 PAWW 水洗树脂不兼容、与 PAC10 铸造树脂强制绑定。选购前先确认目标树脂属于哪条生态线，避免"买了机器用不了料"。
> 💡 **软件锁定是更深的锁定**：Blueprint 是唯一切片软件，树脂曝光参数不可手工修改（RS 第三方树脂依赖云端策略）。偏好 CHITUBOX/Lychee 自由调参的玩家会感到受限——这正是 Reflex 与 Elegoo/Anycubic 生态的本质分野。

## 未来展望

1. **全彩桌面化（2026 Q3）**：桌面级全彩光固化产品线是对当前全彩 3D 打印市场（工业级主导）的价格重构，若将工业级全彩（PolyJet 级别）能力下放至万元档，将开辟全新品类——也是 C 轮融资的核心叙事
2. **消费线架构闭环化**：初代/RS 的"高细分步进"向 Reflex 2 的 FOC 闭环演进，预计下一代将全系 FOC 化；力控采样率（80 Hz）与分区数量（1032）仍有提升空间
3. **材料体系扩张**：RE70 弹性体、PAH270 耐热 270°C 树脂显示材料线正从"建模"走向"功能件"，与 FDM 在工程件市场形成错位竞争
4. **软件去云化**：离线模式已上线但功能不全，云端依赖（后处理参数、树脂策略）是评测中最大的体验短板，料将随消费级销量增长倒逼本地化
5. **海外深化**：北美齿科出口第一 + 欧洲增速 100% 的基础上，消费级渠道（经销商网络 APPLY3D/OpenELAB 等）正在扩张
6. **齿科基本盘自动化**：A3D + Resin Station、HiVE 的 24/7 无人产线模式若在技工所普及，将把行业竞争从"卖设备"推向"卖产能"
7. **风险提示**：消费级光固化市场竞争加剧（Elegoo/Anycubic 的高分辨率参数竞赛 + Formlabs 下探），黑格"效果占优、参数不占优"的差异化依赖口碑传播；封闭软件生态可能成为规模扩张的天花板

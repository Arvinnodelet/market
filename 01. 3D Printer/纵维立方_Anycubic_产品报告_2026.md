### 名字由来

"纵维立方"——"纵维"意为纵深的维度，"立方"代表 3D 打印的三维空间构建。英文 Anycubic 传达品牌的包容性和 3D 属性。

### 业务版图

纵维立方是"深圳 3D 打印四大天王"中唯一**横跨 FDM 和光固化（树脂）两大技术路线**的公司：

```
纵维立方（Anycubic Group）
├── FDM 打印设备（Kobra 系列）
├── 光固化打印设备（Photon 系列）
├── 多色供料系统（ACE Pro / ACE 2 Pro）
├── 耗材与配件（FDM 线材 + 光固化树脂）
├── 软件平台（Anycubic Slicer Next、Photon Workshop）
├── 社区平台（Makeronline）
└── 行业解决方案（教育、医疗、鞋业）
```

### 8.2 ACE GEN2 内置 4 通道打印头深度分析 🔍

ACE GEN2（Anycubic Color Engine Generation 2）是纵维立方在 Kobra X 上首发的内置多色打印头系统。它将 4 个独立耗材通道集成到打印头内部，彻底取消了外部供料盒（ACE Pro / AMS / CFS）作为多色打印的必要条件。这是 2025 年 FDM 消费级市场最具原创性的供料架构创新。

#### 8.2.1 工作原理

传统多色方案（AMS/CFS/ACE Pro）采用**远端换色**架构：外部供料盒通过 PTFE 管将耗材推送至打印头，换色时需回抽旧料 → 推送新料 → 冲洗混合段。这带来三个固有问题：

1. **长熔体路径**（~120 mm PTFE 管 + 热端内部）：回抽/推送产生大量废料
2. **外部供料盒成本**：增加 $100–$200 硬件成本
3. **桌面空间占用**：额外设备 + 电源 + 线缆管理

ACE GEN2 采用**近端并联通道**架构——4 条耗材在打印头内部汇聚，每条通道由独立电机驱动，在距喷嘴仅 30 mm 处完成换色切换：

```
传统远端换色（AMS / CFS / ACE Pro）：          ACE GEN2 近端并联（Kobra X）：

┌──────────────────────┐                      ┌──────────────────────────┐
│     外部供料盒         │                      │       打印头总成           │
│  ┌────┐┌────┐┌────┐┌────┐│                  │                          │
│  │ F1 ││ F2 ││ F3 ││ F4 ││                  │  ┌───┐┌───┐┌───┐┌───┐   │
│  └──┬─┘└──┬─┘└──┬─┘└──┬─┘│                  │  │M1 ││M2 ││M3 ││M4 │   │ ← 4× 独立送料电机
│     │     │     │     │   │                  │  └──┬─┘└──┬─┘└──┬─┘└──┬─┘   │
│     └─────┴──┬──┴─────┘   │                  │     │     │     │      │    │
│              │ 4-in-1 Hub  │                  │     ├─────┴──┬──┴──────┤    │
│              │             │                  │     │4-in-1 汇聚块     │    │
└──────────────┼─────────────┘                  │     └───────┬─────────┘    │
               │                                │             │              │
          PTFE 管                                │      熔体路径 30 mm        │
          ~120 mm                                │             │              │
               │                                │      单喷嘴出口            │
      ┌────────▼────────┐                       └──────────────────────────┘
      │   打印头（单喷嘴） │
      │   熔体路径 ~60 mm │                          换色：F1 → F2
      └─────────────────┘                    F1 回抽 5mm → F2 推进 5mm → 冲洗
                                              废料体积 ∝ 30 mm 路径长度
换色：F1 → F2
F1 回抽 ~120mm → F2 推进 ~120mm → 冲洗
废料体积 ∝ 120 mm 路径长度
```

**关键物理原理**：换色废料量与熔体路径长度成正比。将路径从 ~120 mm 缩短至 ~30 mm，理论上可减少约 75% 废料。纵维立方宣称实际减少达 81.25%，额外收益来自独立通道避免了远端管的死体积。

#### 8.2.2 硬件实现

| 组件 | 规格 | 说明 |
|---|---|---|
| **驱动电机** | 4× 独立无刷直流电机 | 每通道独立控制，可同时预加载下一颜色 |
| **汇聚块** | 4-in-1 合并流道 | 4 通道在距喷嘴 30 mm 处汇聚为单出口 |
| **熔体路径长度** | ~30 mm（从汇聚点到喷嘴出口） | 相比传统 ~120 mm 减少 75% |
| **喷嘴** | 0.4 mm 硬化钢（标配） | 耐磨，兼容 PLA/PETG/TPU |
| **散热设计** | 独立通道散热片 + 主动风扇 | 防止相邻通道热传导导致提前软化 |
| **通道隔离** | 物理隔板分离 4 通道 | 防止交叉污染，确保纯色切换 |
| **送料检测** | 4× 独立断料传感器 | 每个通道独立监测耗材状态 |

**热管理挑战**：4 个通道在打印头内紧密排列，相邻通道的热传导可能导致非活动通道的耗材提前软化（热 creep 风险）。纵维立方的解决方案是独立散热片 + 主动风扇 + 物理隔板三重隔离——但这增加了打印头重量和复杂度。

#### 8.2.3 子系统评分

对 ACE GEN2 涉及的子系统做量化评估（1–5 量表）：

| 子系统 | 评分 | 依据 |
|---|---|---|
| **挤出系统（Extrusion）** | **4/5** | 4× 独立无刷电机直驱，每通道独立控制；非 FOC/PMSM 闭环（无堵转检测）；优于传统 Bowden 方案，弱于拓竹 PMSM 伺服 |
| **热端系统（Hotend）** | **4/5** | 30 mm 极短熔体路径，换色速度和效率行业领先；300°C 温度上限（够用但非顶尖）；硬化钢喷嘴标配；无快拆功能 |
| **传感器系统（Sensors）** | **3/5** | 4× 独立断料检测（基础）；无涡流/压力传感器；依赖 LeviQ 3.0 做调平；无打印中流量闭环反馈 |
| **电子系统（Electronics）** | **3/5** | 需驱动 4 通道 + 打印机本体，I/O 需求高；具体 MCU 未公开；无 NPU/AI 加速 |
| **整体技术评分** | **3.5/5** | 架构创新度 5/5，但执行层面依赖成熟组件（无刷电机、硬化钢喷嘴），非全栈自研 |

#### 8.2.4 与竞品方案对比

#### 8.2.5 优势与局限

**优势**：
1. **成本革命**：$259 即可 4 色打印，将多色入门门槛从 $450+ 降至 $250 档位
2. **换色速度**：30 mm 熔体路径使每层换色时间减少 30–50%，多色打印总时间显著缩短
3. **废料削减**：81.25% 冲洗废料减少——对多色打印用户而言，意味着每卷耗材中更多材料变成产品而非废料
4. **桌面空间**：无外部供料盒，适合空间有限的家庭/教育场景
5. **无 PTFE 管损耗**：短路径无长管磨损，维护成本低

**局限**：
1. **无封闭腔室**：开放式结构限制材料选择（不支持 ABS/ASA/PC）
2. **打印头重量**：4 电机 + 4 通道 + 散热系统使打印头质量增加，限制极限加速度
3. **热管理边界**：高环境温度下多通道热 creep 风险需要持续优化
4. **4 色以上需外部扩展**：第 5–19 色仍需外接 ACE 2 Pro（回归传统远端方案）
5. **不可维修性未知**：内置 4 通道汇聚块堵塞后的清理难度待社区验证

#### 8.2.6 未来演进方向

- **封闭式 Kobra X 后继机**：增加腔室加热 → 支持 ABS/ASA，扩大适用范围
- **FOC 伺服电机替换**：4 通道换用闭环伺服 → 增加堵转/流量检测
- **快拆喷嘴**：缩短维护时间，匹配多材料切换场景
- **6–8 通道版本**：进一步增加内置颜色数，减少对外部供料盒的依赖

### 8.3 Photon P1 双料槽光固化深度分析 🔍

Photon P1 是全球首款消费级双材料 MSLA 光固化 3D 打印机（2025 年 12 月 Kickstarter 发布）。它通过双独立料槽 + 单屏的设计，实现了刚性/弹性双材料在同一台机器上的一次性打印，开创了"鞋业 3D 打印"这一全新增量市场。

#### 8.3.1 工作原理

传统 MSLA 光固化打印机只有单个料槽——每层曝光后，构建平台抬升 → 剥离膜分离 → 树脂回流 → 下一层曝光。打印多材料对象需要手动中途换料槽（暂停 → 清洗 → 换树脂 → 继续），极易引入层间附着问题和污染。

Photon P1 的双料槽系统核心机制如下：

```
┌──────────────────────────────────────────────────┐
│                   Photon P1                       │
│                                                    │
│   ┌──────────────────┐  ┌──────────────────┐      │
│   │   料槽 A          │  │   料槽 B          │      │
│   │   刚性树脂         │  │   弹性树脂         │      │
│   │   (350 ml)        │  │   (350 ml)        │      │
│   │                   │  │                   │      │
│   │  ┌─────────────┐  │  │  ┌─────────────┐  │      │
│   │  │ Wave Release │  │  │  │ Wave Release │  │      │
│   │  │ NFEP 膜      │  │  │  │ NFEP 膜      │  │      │
│   │  └──────┬───────┘  │  │  └──────┬───────┘  │      │
│   └─────────┼──────────┘  └─────────┼──────────┘      │
│             │                       │                  │
│             └───────────┬───────────┘                  │
│                         │                              │
│             ┌───────────▼───────────┐                  │
│             │   10.1" 14K 黑白 LCD   │                  │
│             │   11520 × 5120 px      │                  │
│             │   XY 16.8×24.8 µm      │                  │
│             └───────────────────────┘                  │
│                         │                              │
│             ┌───────────▼───────────┐                  │
│             │   LightTurbo 4.0      │                  │
│             │   COB + Fresnel 透镜   │                  │
│             │   ≥92% 均匀度          │                  │
│             └───────────────────────┘                  │
└──────────────────────────────────────────────────┘

双材料打印流程：
  第 1–N 层：料槽 A → LCD 曝光 A 区域 → 构建平台抬升
  第 N+1–M 层：平台平移至料槽 B → LCD 曝光 B 区域 → 构建平台抬升
  循环往复 → 单对象内刚性+弹性区域一次性完成
```

**关键技术挑战**：

1. **料槽切换精度**：构建平台在两个料槽之间平移后，XY 对齐误差必须 < 50 µm，否则层间错位肉眼可见
2. **树脂交叉污染**：构建平台从料槽 A 携带残留树脂进入料槽 B，可能导致颜色/材料污染
3. **参数独立性**：两种材料（刚性 vs 弹性）需要截然不同的曝光时间、抬升速度、剥离策略

**纵维立方的解决方案**：

| 挑战 | 解决方案 | 技术手段 |
|---|---|---|
| **XY 对齐** | 工业滚珠丝杠 Z 轴 + 双线性导轨 | 重复定位精度 ±0.01 mm |
| **交叉污染** | 双料槽物理隔离 + 清洗策略 | 每槽独立刮刀 + 可编程中间清洗层 |
| **参数独立性** | Photon Workshop 4.0 双料槽独立参数 | 每个料槽独立曝光时间/抬升速度/剥离高度 |
| **剥离力** | Wave Release NFEP 膜 | 剥离力降低 60%，支持 8,000 cps 高粘度树脂 |
| **树脂流动性** | 动态恒温料槽（20–40°C） | 加热降低粘度，确保高粘度工程树脂正常回流 |

#### 8.3.2 硬件实现

| 组件 | 规格 | 说明 |
|---|---|---|
| **LCD 屏幕** | 10.1" 14K 黑白 LCD，11520×5120 px | 单屏覆盖两个料槽区域 |

### 8.4 LeviQ 3.0 自动调平系统深度分析 🔍

LeviQ 3.0 是纵维立方在 Kobra S1 和 Kobra X 上搭载的第三代自动调平系统。它基于**应变片（Strain Gauge）多点网格扫描**，实现喷嘴-热床间隙的全自动校准。与拓竹的涡流传感器方案和 Prusa 的 Load Cell 方案形成三条不同的技术路线。

#### 8.4.1 工作原理

LeviQ 3.0 采用**喷嘴物理接触 + 应变片测量**方案：

```
┌─────────────────────────────────────────────┐
│              工具头剖面                        │
│                                              │
│   ┌──────────────────────────┐               │
│   │     应变片（Strain Gauge） │               │
│   │     安装于热端支架          │               │
│   │     测量微应变 → 力信号     │               │
│   └────────────┬─────────────┘               │
│                │                              │
│   ┌────────────▼─────────────┐               │
│   │     热端 + 喷嘴            │               │
│   └────────────┬─────────────┘               │
│                │                              │
│                ▼  喷嘴触碰热床                  │
│   ╔══════════════════════════╗               │
│   ║        PEI 热床           ║               │
│   ╚══════════════════════════╝               │
└─────────────────────────────────────────────┘

调平流程：
  1. 喷嘴加热至清洁温度（~150°C），挤出残余耗材
  2. 工具头移至第 1 个网格点 (X₁, Y₁)
  3. Z 轴缓降 → 喷嘴接触热床 → 应变片检测到力突变 → 记录 Z₁
  4. 工具头移至 (X₂, Y₂) → 重复步骤 3
  5. ...循环 49 点 → 生成热床 3D 高度网格
  6. 固件计算补偿矩阵 → 打印时 Z 轴实时微调跟随网格
```

**应变片检测原理**：

| 步骤 | 物理过程 | 电信号 |
|---|---|---|
| 1. 喷嘴下降 | 未接触热床 → 应变片无变形 | 基准电压 V₀ |
| 2. 喷嘴触床 | 热端支架产生微弯曲 → 应变片拉伸 | 电压变化 ΔV |
| 3. 过阈值判定 | ΔV > 预设阈值 → 确认接触 | 记录当前 Z 坐标 |
| 4. 喷嘴回退 | 脱离接触 → 应变片恢复 | 电压回到 V₀ |

LeviQ 3.0 的关键改进是 **49 点高密度网格**（上一代 LeviQ 2.0 为 25 点），重复精度从 <0.05 mm 提升至 <0.02 mm。密度的增加使它能更准确地捕捉热床的局部变形（如边缘翘曲、中心凹陷）。

#### 8.4.2 硬件实现

| 组件 | 规格 | 说明 |
|---|---|---|
| **传感器类型** | 应变片（金属箔式） | 低成本、紧凑、成熟技术 |
| **安装位置** | 热端支架（散热片上方） | 测量喷嘴接触热床时支架的微变形 |
| **网格密度** | 7×7 = 49 点 | Kobra S1 / X 标配 |
| **重复精度** | <0.02 mm | 纵维立方官方标称 |
| **Z-offset 校正** | 手动微调 ±0.05 mm 步进 | 自动调平后用户可选精调 |
| **执行时间** | ~3–5 分钟 | 49 点全扫描（含喷嘴加热时间） |

#### 8.4.3 传感器评分

按传感器评估框架评估：

| 评估维度 | 评分 | 依据 |
|---|---|---|
| **精度（Accuracy）** | **3/5** | 重复精度 <0.02 mm（良好，但弱于涡流和 Load Cell） |
| **可靠性（Reliability）** | **3/5** | 应变片受温度和安装条件影响（对安装条件敏感 + 温度效应）；无自检能力 |
| **成本（Cost）** | **5/5** | 应变片成本极低（<$1），远低于涡流传感器和 Load Cell |
| **制造复杂度** | **4/5** | 应变片贴装需要精确的位置和胶水固化；但整体装配比 Load Cell 简单 |
| **多功能性** | **1/5** | **仅做热床调平**——无法做流量补偿/裹头检测/Z-offset 自动校准 |
| **综合传感器评分** | **3.2/5** | 成本领先，功能单一——在"一传感器多功能"趋势下处于劣势 |

#### 8.4.4 三条技术路线对比

| 维度 | LeviQ 3.0（纵维立方） | 涡流传感器（拓竹） | Load Cell（Prusa） |
|---|---|---|---|
| **传感器类型** | 应变片 | 涡流线圈 | 称重传感器 |
| **工作原理** | 喷嘴触床 → 支架微变形 → 应变片测力 | 线圈阻抗变化测散热片微位移 | 喷嘴触床 → 测力传感器直接读数 |
| **非接触式** | ❌ 必须物理接触 | ✅ 非接触（通过磁场） | ❌ 必须物理接触 |
| **调平速度** | ~3–5 分钟（49 点） | ~2–3 分钟（多点） | ~2–3 分钟 |
| **重复精度** | <0.02 mm | <0.01 mm（更优） | <0.01 mm（更优） |
| **额外功能** | ❌ 仅调平 | ✅ 流量补偿 + 裹头检测 + Z 归零 + 在位检测 | ✅ Z-offset 自动校准 |
| **传感器融合** | AI 摄像头（炒面检测，独立系统） | 涡流 + AI 摄像头 + NPU 深度集成 | Load Cell + 加速度计 |
| **热床材料限制** | ✅ 无限制（接触式） | ⚠️ 需要导电目标（金属热床/贴片） | ✅ 无限制（接触式） |
| **喷嘴清洁度要求** | 高（残留耗材影响接触判断） | 无要求（非接触） | 高（残留耗材影响接触判断） |
| **BOM 成本** | **极低（<$1）** | 中等（$3–$8） | 中等（$5–$10） |
| **代表机型** | Kobra S1 / Kobra X | A1 / A2L / P2S / H2D / H2S / X2D | Prusa MK4 / XL / Core One |

```
技术路线选择逻辑：

低成本导向                    精度导向                   多功能导向
    │                            │                           │
    ▼                            ▼                           ▼
  应变片（LeviQ 3.0）          Load Cell（Prusa）         涡流传感器（拓竹）
    │                            │                           │
    ├─ BOM <$1                  ├─ 精度 0.01 mm            ├─ 1 传感器 = 4 项功能
    ├─ 仅做调平                 ├─ 自动 Z-offset           ├─ 硬件+固件深度融合
    ├─ 制造简单                 ├─ 开源生态友好             ├─ 闭源生态锁定
    └─ 入门机最优解              └─ 维修友好                 └─ 竞品难以复制
```

> 💡 LeviQ 3.0 的技术选择体现了纵维立方的工程优先级：**以最低 BOM 成本实现"足够好"的自动调平**，将功能创新的资源投入到 ACE GEN2 和 Photon P1 等差异化技术上。在 $259–$549 价位段，这是一个理性的工程权衡。

#### 8.4.5 优势与局限

**优势**：
1. **极低 BOM 成本**：应变片 <$1，是三种主流方案中最便宜的
2. **热床材料无限制**：接触式方案不限热床材质（PEI/玻璃/PC 均可），拓竹涡流需要金属热床
3. **简单可靠**：成熟技术，无复杂信号处理需求
4. **49 点密度**：相比入门机常见的 16–25 点，网格密度领先同价位

**局限**：
1. **功能单一**：仅做调平——流量补偿、裹头检测、Z-offset 自动化均缺失
2. **物理接触**：必须喷嘴触床 → 对喷嘴清洁度要求高（残留耗材误判）→ 需预加热清洁步骤
3. **温度漂移**：应变片的输出随温度变化（温度效应是应变片的固有限制），高温腔室环境可能影响精度
4. **无自检能力**：无法检测自身是否失效——如果应变片胶水老化脱落，用户只能通过打印失败发现
5. **无可升级性**：应变片的物理原理决定了它不能通过固件 OTA 增加新功能（不像涡流/摄像头可通过软件解锁新能力）

#### 8.4.6 未来演进方向

- **应变片 + MEMS 加速度计融合**：增加振动监测能力（类似 Klipper 的 ADXL345）
- **压力传感升级**：考虑增加低成本压力传感器用于流量补偿
- **Load Cell 迁移**：中高端机型可能向 Prusa Load Cell 方案迁移（获取 Z-offset 自动校准能力）
- **AI 增强**：利用摄像头数据辅助调平验证（检测首层一致性→反馈调平质量）

## 四、各系列产品详解

### 4.1 P 系列 — CO₂ 激光切割旗舰

P 系列是 xTool 的技术制高点，定位小型商业/工业级 CO₂ 激光切割市场。

#### P3 — 旗舰 80W CO₂ 激光切割机 🆕

| 规格项 | 参数 | 评价 |

##### MOPA 技术 — F2 Ultra 的核心差异化

MOPA（Master Oscillator Power Amplifier，主振功放）是脉冲光纤激光器的一种架构，相比传统 Q-switched 光纤激光器，其核心优势是**脉冲宽度和频率可独立调节**：

```
传统 Q-switched 光纤 (F1 Ultra 20W IR)      MOPA 光纤 (F2 Ultra 60W)
──────────────────────────────────────      ──────────────────────────
脉冲宽度      固定（~100ns）                   2–500ns 连续可调
频率范围      窄（~20–80kHz）                  宽（1–4,000kHz）
峰值功率      中等                             极高（短脉冲 + 高能量）
彩色打标      有限（金/棕/黑）                  100+ 色（蓝/绿/紫/红/黄/白）
铝黑标        不可靠                            稳定黑色 ✅
3D 浮雕       浅层                              深层（逐层去除）
```

**MOPA 彩色打标原理**：

```
［MOPA 脉冲 → 金属表面局部加热 → 受控氧化层生长 → 薄膜干涉呈色］

脉冲能量 ↑ + 脉宽 ↑ → 表面温度 ↑ → 厚氧化层 → 蓝色/紫色
脉冲能量 ↓ + 脉宽 ↓ → 表面温度 ↓ → 薄氧化层 → 金色/棕色
特定参数组合 → 特定氧化层厚度 → 特定颜色

不锈钢可产生颜色范围：
██ 黑  ██ 深灰  ██ 银白  ██ 金  ██ 棕  ██ 紫  ██ 蓝  ██ 青  ██ 绿  ██ 红  ██ 黄  ██ 白
```

> 💡 **关键区别**：F1 Ultra 的 20W Q-switched IR 光纤也可以在不锈钢上产生有限颜色（金/棕/紫），但黑色和绿色/红色需要 MOPA 的独立脉宽控制。铝黑标（bare aluminum black marking）是 MOPA 的独占能力——短脉冲+高频率使激光穿透铝表面透明氧化层，直接在铝基体上形成黑色标记，对比度极高。

**紫外激光的"冷加工"原理**：

```
红外/可见光激光 (CO₂/二极管/IR 光纤)     紫外激光 (355nm)
────────────────────────────────────     ────────────────────
热效应 → 材料吸收光能 → 升温 → 熔化/气化    光化学效应 → 光子能量 > 分子键能
                                            → 直接打断化学键 → 材料以原子/分子形式脱离
产生热影响区 (HAZ)、碳化、熔渣             几乎零热影响区、无碳化
切面粗糙，边缘变色                          切面光滑如抛光，边缘无变色
```

这使得 F2 Ultra UV 在以下场景有不可替代的优势：
- **玻璃/水晶内雕**：355nm 紫外光可透过透明材料表面，在内部焦点处发生非线性吸收，形成微爆点——实现 3D 立体图案

#### F2 Ultra 的 MOPA 升级 — 从 Q-switched 到主振功放

F2 Ultra 对 F1 Ultra 的核心升级不在振镜光路（两者架构相同），而在**光纤激光器的脉冲控制方式**：

```
F1 Ultra (20W IR)                    F2 Ultra (60W MOPA)
══════════════════                    ════════════════════

泵浦源 (LD)                           种子激光器 (Master Oscillator)
    │                                      │
    ▼                                      ▼
增益光纤                               前置放大器 (Pre-Amplifier)
    │                                      │
    ▼                                      ▼
Q-switch (声光调制器)                   功率放大器 (Power Amplifier)
→ 固定脉宽 ~100ns                      → 脉宽 2–500ns 可调
→ 频率 20–80kHz                        → 频率 1–4,000kHz 可调
    │                                      │
    ▼                                      ▼
输出 20W                               输出 60W

核心区别：
Q-switched: 泵浦→储能→瞬间释放         MOPA: 种子信号→逐级放大
→ 脉宽由腔长和Q开关决定（不可调）       → 脉宽由种子源电调制决定（可调）
→ 峰值功率固定                          → 峰值功率可独立于频率调节
```

**MOPA 可调参数对加工效果的影响**：

| 参数调节 | 加工效果变化 |
|---|---|
| **脉宽 ↓ + 频率 ↑** | 低热输入 → 浅标记/退火标记（不锈钢上的黑/灰/白） |
| **脉宽 ↑ + 频率 ↓** | 高热输入 → 深雕刻/3D 浮雕 |
| **脉宽中 + 频率中** | 受控氧化层生长 → 彩色打标（100+ 色） |
| **极短脉宽 (2–10ns)** | 高峰值功率 → 铝黑标/材料去除率高 |

> 💡 **为什么 MOPA 能做铝黑标而 Q-switched 不行**：铝表面天然存在一层 ~4nm 的透明氧化层（Al₂O₃）。Q-switched 的长脉冲（~100ns）将大部分能量沉积在氧化层表面→氧化层增厚→形成白色标记。MOPA 的短脉冲（2–10ns）+ 高频率将能量穿透氧化层直接作用于铝基体→产生受控微坑→光在微坑内多次反射→呈现黑色。这是物理光学效应，非化学染色。

**F2 Ultra 在振镜系统中的功率密度优势**：

| 参数 | F1 Ultra IR | F2 Ultra MOPA | 倍数 |
|---|---|---|---|
| 光斑面积 | ~0.0009 mm² | ~0.0009 mm² | 相同 |
| 峰值功率（估算） | ~200W | ~6,000W（最短脉宽时） | **30×** |
| 平均功率密度 | ~2,200 kW/cm² | ~6,700 kW/cm² | **3×** |
| 金属切割能力 | 0.3–0.4mm | 2mm | **5–6×** |

MOPA 的高峰值功率使其可以在极短脉冲内达到金属气化阈值（通常需 >10⁷ W/cm²），而平均功率的 3× 提升则直接转化为更深的单次去除量。两者叠加 → F2 Ultra 的金属切割/深雕能力是 F1 Ultra 的 5–6 倍。

##### 立体视觉深度感知 — F2 Ultra 的核心升级

F2 Ultra 不依赖 ToF LiDAR 或结构光，而是使用**被动立体视觉（Passive Stereo Vision）**——两个 48MP 相机以 ~60mm 基线间距排列，通过左右视图的视差（disparity）计算深度：

```
立体视觉三角测量原理：

        左相机 (广角)              右相机 (微距)
            │                         │
            │ ←──── 基线 B ~60mm ────→│
            │                         │
            │      ╲                 ╱ │
            │        ╲             ╱   │
            │          ╲         ╱     │
            │            ╲     ╱       │
            │              ╲ ╱         │
            │               ✖ ← 工件表面 P
            │                         │
            └─────────────────────────┘

  视差 d = x_left - x_right（同一特征点在左右图中的像素差）
  深度 Z = f × B / d
  
  其中：f = 相机焦距（像素），B = 基线，d = 视差（像素）
```

##### Curve-measure — 3D 曲面建模与雕刻 🆕

##### Curve-measure 详细技术参数

**测量密度（Rows × Columns）详解**：

测量密度是 Curve-measure 的核心用户可控参数，直接影响模型精度和作业总时间：

```
测量密度与精度的关系（以 100×100mm 加工区域为例）：

  密度      行列数    采样点数    采样间距    测量时间(估)   适用场景
  ────────  ────────  ────────   ────────    ───────────   ──────────────
  低密度    5×5       25         20 mm       ~15–30s       大曲率渐变（杯身）
  中密度    10×10     100        10 mm       ~1–2 min      通用曲面
  高密度    20×20     400        5 mm        ~3–5 min      小物件精细曲面
  超高密度  30×30     900        3.3 mm      ~5–10 min     极致精度/复杂曲率

  XCS 推荐值：根据所选区域大小自动计算，通常是 10×10 或更密
  上限：XCS 不硬限制，但实际受限于测量时间 + Z 轴定位时间
```

| 参数 | 说明 | 工程意义 |
|---|---|---|
| **Rows（行数）** | Y 轴方向的采样线数 | 控制曲面在 Y 方向的分辨率 |
| **Columns（列数）** | X 轴方向的采样线数 | 控制曲面在 X 方向的分辨率 |
| **采样间距** | = 区域宽度/列数、区域高度/行数 | 间距 > 曲面特征尺寸 → 细节丢失 |
| **总采样点数** | = Rows × Columns | 点数 ↑ → 测量时间线性增长 |
| **单点测量时间** | ~0.5–2s（含 Z 轴移动 + 立体视觉采集 + 计算） | 取决于 Z 轴行程和纹理质量 |
| **测量总时间** | ≈ 点数 × 单点时间 + Z 轴往复时间 | 高密度时 Z 轴往复成为主要时间消耗 |

**Smoothness（平滑度）与 Tension（张力）参数详解**：

XCS 在生成 3D 模型后提供两个后处理滑块，用于调整曲面拟合质量。这两个参数作用于**数学曲面拟合算法**（推测为薄板样条 Thin-Plate Spline 或类似方法），而非改变物理测量数据：

```
Smoothness 和 Tension 的数学直觉：

原始测量点 (xᵢ, yᵢ, zᵢ)
        │
        ▼
  曲面拟合算法 ─── Smoothness ──→ 控制拟合曲面的"刚度"
        │                        ├─ 高平滑 = 曲面像"钢板"——忽略局部高频波动
        │                        └─ 低平滑 = 曲面像"橡胶膜"——紧贴每个采样点
        │
        └────── Tension ──────→ 控制拟合曲面的"边界行为"
                                 ├─ 高张力 = 曲面在采样点间线性插值（防过冲）
                                 └─ 低张力 = 曲面在采样点间自由弯曲（自然过渡）
```

| 参数 | 作用 | 推荐设置 | 过度使用的风险 |
|---|---|---|---|
| **Smoothness** | 滤除测量噪声（高频波动） | 中等 → 偏高（多数场景） | 过高 → 曲面过于扁平 → 丢失真实曲面特征 → 雕刻深度不准 |
| **Smoothness** 低值 | 保留原始测量细节 | 极精细曲面 / 纹理表面 | 过低 → 测量噪声被当作曲面特征 → 雕刻表面粗糙不平 |
| **Tension** | 控制采样点间的插值行为 | 中等（多数场景） | 过高 → 采样点间线性过渡 → 曲面出现"折痕" |
| **Tension** 低值 | 允许采样点间平滑弯曲 | 光滑曲面（杯身、球面） | 过低 → 边界处过度拟合 → 边缘出现非物理的"翘曲" |

> 💡 **实际操作建议**（来自 xTool 官方教程和社区实践）：
> - **默认值起步**：先用 XCS 默认的 Smoothness/Tension 生成模型，检查 3D 预览
> - **曲面出现"台阶感"** → 提高 Smoothness（测量噪声过大）
> - **曲面过于扁平，丢失杯身弧度** → 降低 Smoothness + 提高测量密度重新扫描
> - **边缘翘起/下沉** → 提高 Tension
> - **采样点间出现折线** → 降低 Tension
> - **根本性精度不足** → 返回 Phase 2 提高 Rows/Columns 重新测量，而非过度依赖后处理

##### Curve-measure 技术边界条件

**支持的曲面几何**：

| 条件 | 限值 | 原因 | 典型通过 | 典型不通过 |
|---|---|---|---|---|
| **曲面类型** | 平滑渐变曲面 | 阶梯/尖锐拐角 → 高度跳变 → Z 轴无法瞬时跟踪 | 杯子外壁、手机壳背板、勺子凹面、球冠 | 阶梯状结构、锯齿边、尖刺 |
| **切线角** | **≤ 45°**（相对水平面，任意点） | 超过 45° → F-Theta 透镜边缘光斑变形严重 + 立体视觉视差过大 | 浅碗、弧形标牌、曲面手机壳 | 球体赤道附近、陡峭瓶肩、垂直杯壁 |
| **最高-最低高度差** | **≤ 100 mm** | F2 Ultra Z 轴有效行程 150mm，减去安全余量 | 马克杯（~80mm 直径）、保温杯身 | 深碗、大型花瓶 |
| **曲面连续性** | 无突变高度、无尖角、无内凹（inward sloping） | 内凹 → 光路被遮挡 + 立体视觉盲区 | 凸面、平面、浅凹面 | 倒扣（undercut）、深凹槽、孔洞 |

**支持的材料特性**：

| 条件 | 要求 | 原理 | 典型通过 | 典型不通过 |
|---|---|---|---|---|
| **表面反射率** | **非高镜面反射** | 镜面反射 → 相机看到反射像（而非表面）→ 立体匹配失败 | 阳极氧化铝、喷漆金属、木材、亚克力、陶瓷 | 镜面抛光不锈钢、镀铬表面、镜面玻璃 |
| **表面纹理** | **需要一定可见纹理/图案** | 被动立体视觉依赖特征点匹配——纯色无纹理表面无法生成可靠视差图 | 木纹、拉丝金属、印刷图案、粗糙表面 | 纯白陶瓷、纯色光滑塑料、无纹理玻璃 |
| **材料颜色** | 避免极暗/极亮表面 | 极暗 → 特征对比度低；极亮 → 相机过曝 | 中等色调最佳 | 纯黑橡胶、纯白高光表面 |

##### Curve-measure 的工程限制与已知问题

| 限制/问题 | 详情 | 影响 | 缓解措施 |
|---|---|---|---|
| **2.5D 非真 3D** | Z 轴调整焦平面高度，但激光始终垂直于焦平面（非曲面法线） | 陡坡处光斑变为椭圆形 → 边缘雕刻模糊 | 限制曲面角 ≤ 45° |
| **测量-加工 分离** | "先测量→后加工"，非实时闭环反馈 | 加工中工件移动/热变形 → 曲面模型失效 | 确保工件固定牢固 |
| **测量时间成本** | 20×20 网格 = 400 点 = 3–5 分钟纯测量时间 | 不适合量产中频繁换件 | 同批次同型号工件复用同一模型 |
| **F-Theta 边缘退化** | 大扫描角（>30°）→ 光斑变大 + 焦深减小 | 曲面边缘雕刻质量下降 | 将关键图案放在曲面中心区域 |
| **无纹理表面盲区** | 立体视觉需要可见纹理特征 | 纯色/光滑表面测高不可靠 | 临时纹理化处理 |
| **软件学习曲线** | Smoothness/Tension 参数无精确指导值 | 新用户需反复试错找到最佳参数 | 从默认值起步，小步迭代 |

> ⚠️ **Curve-measure ≠ 任意 3D 自由曲面**：这不是 CNC 5 轴的"自由曲面加工"。F2 Ultra 的 Galvo F-Theta 透镜有一个焦平面，Z 轴调整的是整个焦平面的高度。严格来说，它做的是**高度随位置变化的 2.5D 加工**——Z 轴在 XY 每个位置可以有不同的高度，但激光始终垂直于焦平面（而非跟随曲面法线）。对于杯子、勺子、手机壳等中等曲率的物体实用，但对于球体或锐角曲面不适用。

#### 7.6.7 M1 Ultra — 接触式探针（精度优先于速度）

M1 Ultra 采用**物理探针触碰**测距，标称精度 ±0.1mm。相比 M1 初代的相机对焦方案（精度 ~1mm），探针方案将精度提升了 10 倍。

| 维度 | 评估 |

| **为什么不用 LiDAR** | $599 价位无法承载 LiDAR + 多相机系统 |
| **混合工艺需求** | 刀切模式需要精确的下压力控制，探针可以直接测量材料厚度和硬度 |
| **用户群体** | 手工创作者不需要"黑科技"，需要"每次都能切透卡片"的确定性 |

#### 7.6.7 F1 — 纯手动红蓝双点（最低成本）

无自动对焦，完全依赖用户手动调整红蓝光点重合。$599 价位将硬件成本投入到双光源（10W 二极管 + 2W IR）和振镜系统。

#### 7.6.11 跨领域技术对标：激光对焦 ↔ 3D 打印调平

这两个看似不相关的技术问题，本质上是**同一类传感器解决同一个几何问题**。下表给出 xTool 每种对焦方案在 3D 打印领域的等价物：

| xTool 方案 | ≈ 3D 打印等价方案 | 共同原理 | 适用精度层 |
|---|---|---|---|
| **O1 Pixel-Scan™**（线激光+CIS） | Bambu X1C 结构光 LiDAR [EOL] | 线激光三角测量 | ±0.01mm |
| **P3/P2S ToF LiDAR** | —（3D 打印不需要大范围快速粗测） | 红外脉冲飞行时间 | ±1mm |
| **S1/M1 Ultra 探针** | BLTouch / 3D Touch | 物理接触 → 开关触发 | ±0.1mm |
| **F2 Ultra 立体视觉** 🆕 | 双目视觉里程计（机器人 SLAM） | 被动立体视觉 → 三角测量 | ±0.2mm |
| **F1 Ultra 相机自动** | AI 视觉首层检测（Creality K2） | 图像识别 → 软件推断 | ±0.1mm（不可靠） |
| **F1 手动红蓝** | 手动调平旋钮（Ender 3 初代） | 人工感知 + 视觉对齐 | 依赖操作者 |

**核心洞察——为什么两个行业选择了不同的"最优解"？**

| 维度 | 激光雕刻 | 3D 打印 |
|---|---|---|
| **精度需求** | 中等（±0.1–2mm） | 高（±0.01–0.02mm） |
| **材料多样性** | 极高（木/亚克力/金属/皮革/玻璃…） | 中等（主要是金属热床+PEI） |
| **表面状态** | 任意（粗糙/光滑/透明/不透明） | 可控（平整、金属基底） |
| **测量速度要求** | 低（对焦只需 1 次） | 中（首层前网格扫描 25–100 点） |
| **首选方案** | **非接触光学**（ToF/相机） | **接触式或近场电磁**（荷重元/涡电流） |

3D 打印需要亚毫米精度——ToF LiDAR 的 ±1mm 根本不合格，所以行业走向了荷重元（直接测力）和涡电流（nm 级电磁场感知）。激光加工材料千变万化——透明亚克力对红外 LiDAR 可能"隐身"、黑色材料可能吸收信号、反射金属可能产生多路径干扰，这迫使激光雕刻机采用**多传感器融合**来覆盖所有材料。

#### 7.6.12 工程洞察

**"反相机"路线的勇气**：xTool 在 S1 和 M1 Ultra 上刻意避开相机对焦（而相机恰恰是 Glowforge 的核心卖点）。探针方案的绝对可靠性——任何材料、任何颜色、任何表面，零标定需求、零图像处理算力——在 Glowforge 的纯相机路线暴露出透明/反光材料测不准的短板后，反而成为了差异化优势。

**技术降级路径**：

```

  │
  ├── 降级到 ──→ P3 ACS™ (ToF LiDAR + 相机验证)    ← 多传感器融合（±0.5mm）
  │                 │
  │                 └── 降级到 ──→ P2S (ToF LiDAR + 双相机)
  │

  │                 │                           ← 被动立体视觉（±0.2mm）
  │                 │
  │                 ├── 降级到 ──→ F1 Ultra (单目 AI 推断)
  │                 │                                   ← 单相机（不可靠）
  │                 │
  │                 └── 降级到 ──→ F2 (50MP 相机自动) 🆕

xTool 没有"一个方案打天下"，而是在不同价位用不同方案实现"刚好够用"的对焦能力。这是一种**精益的产品管理策略**——不给 $599 的产品配立体视觉系统（成本不允许），也不给 $4,999 的产品配手动对焦（用户不接受）。F2 Ultra 的立体视觉方案位于技术树的"振镜分支"，与 P 系列的"ToF 分支"和 O 系列的"结构光分支"并列，各自由产品架构的物理约束（Galvo vs Gantry vs 喷墨）决定了对焦方案的选择。

**传感器融合的未来方向**：xTool 已经在 P3 和 O1 Omni 上实践了多传感器融合——P3 的 ToF LiDAR（快速粗测）+ 近距相机（视觉确认）+ 侧面相机（实时监控），O1 的线激光 + CIS + 激光测距三重冗余。F2 Ultra 的立体视觉 + 手动红蓝 fallback 也是一种简化版的"传感器融合"——光学测量 + 操作者视觉确认。这和 Bambu Lab X1C 曾尝试的"LiDAR 首层扫描 + AI 相机 spaghetti 检测"异曲同工——都是**用多种传感器交叉验证同一个物理量**。单一传感器总有盲区（立体视觉怕无纹理表面、ToF 精度不够、探针怕柔性材料、单目相机怕透明物体），只有多传感器融合+软件决策，才能为所有材料和场景提供可靠的自动对焦。

**F2 Ultra 立体视觉的行业意义**：在消费级激光雕刻领域，被动立体视觉是一个**非传统选择**。大多数竞品要么使用 ToF（如 xTool P 系列）、要么使用单目相机（如 Glowforge）、要么使用探针（如 S1）。xTool 在 F2 Ultra 上选择立体视觉，反映了两个工程判断：① 对于 Galvo 架构的短工作距离（<150mm），立体视觉的深度精度优于消费级 ToF；② 双相机在定位（视觉预览）+ 对焦（深度感知）上的一石二鸟降低了系统总成本。这一选择是否会被 F 系列后续产品延续，取决于用户在实际使用中纹理依赖和镜面反射问题的反馈程度。

##### CO₂ 镜头选型：S / M / L — 焦长-光斑-景深三角权衡

P3（以及多数 xTool CO₂ 机型）支持三种可更换聚焦镜头。镜头选择直接影响三个互相制约的变量：

```
                   焦长 (Focal Length)
                        ↑
                        │
                   ┌────┴────┐
                   │   L 镜  │ ← 长焦 (63.5mm) → 光斑最大、景深最大、切割最深
                   │  2.5"   │
                   ├─────────┤

                   │  2.0"   │
                   ├─────────┤
                   │   S 镜  │ ← 短焦 (38.1mm) → 光斑最小、景深最小、雕刻最细
                   │  1.5"   │
                   └─────────┘

                  光斑尺寸 ↑ = 细节能力 ↑

```

| 镜头 | 焦长 | 光斑 (P3) | 景深 (估算) | 最佳场景 | 不适场景 |
|---|---|---|---|---|---|
| **S** | 38.1 mm (1.5") | 0.14×0.16 mm | ~±0.5 mm | 精细雕刻、薄材、珠宝、印章、文字 | 厚材料切割（景深不足→切面锥度大） |
| **M** | 50.8 mm (2.0") | 0.15×0.18 mm | ~±1.0 mm | **通用**，木/皮/亚克力全能 | 极端精细 or 极端厚度 |
| **L** | 63.5 mm (2.5") | 0.18×0.20 mm | ~±1.8 mm | 厚材料切割（20mm+）、强调垂直切面 | 精细雕刻（光斑太大，细节糊） |

```
焦长 vs 光斑 vs 景深 的关系：

  光斑直径 d ∝ λ × f / D     （λ=波长，f=焦长，D=入射光束直径）
  景深 DOF ∝ λ / NA²        （NA=数值孔径，焦长越大 NA 越小）

  长焦 L → NA 小 → 景深大 → 厚材料切面平行 ✅
            → 光斑大 → 雕刻细节粗糙 ❌

  短焦 S → NA 大 → 景深小 → 厚材料切面锥度大 ❌
            → 光斑小 → 雕刻细节精细 ✅
```

> 💡 **行业对比**：工业级 CO₂ 通常提供 1.5"/2.0"/2.5"/4.0" 四种镜头，xTool 目前提供 3 种。4" 镜头（焦长 101.6mm）可实现更大的景深和更强的切割能力，但 xTool 的 Z 轴行程（P3 最大 220mm）可能限制了超长焦镜头的安装。

##### CO₂ 激光管的技术局限

| 局限 | 说明 | 影响 |
|---|---|---|
| **气体退化** | He 原子逐渐通过玻璃壁渗出，CO₂ 分子分解 | 功率随时间缓慢下降，6,000–10,000h 后需更换 |

| **水冷必需** | CO₂ 激光器电光转换效率仅 ~10–15% | 85% 输入电能转化为热量需冷却带走 |
| **脉冲特性** | DC 激励管在低功率时易出现脉冲→雕刻点不均匀 | 低功率（<10%）雕刻质量下降 |

##### F1 Ultra IR 脉冲光纤激光器的彩色打标原理

F1 Ultra 的 20W 脉冲光纤激光器是 xTool 产品线中**最高端的光源**。其脉冲特性（Q-switched 主动调 Q 或 MOPA 主振功放）允许对金属表面进行**受控氧化层生长**，从而产生颜色：

```
不锈钢彩色打标原理：

  ［IR 脉冲 → 金属表面局部加热 → 氧化层生长］

  脉冲能量 ↑ + 频率 ↓ → 表面温度 ↑ → 厚氧化层 → 蓝色/紫色
  脉冲能量 ↓ + 频率 ↑ → 表面温度 ↓ → 薄氧化层 → 金色/棕色
  特定参数组合 → 特定氧化层厚度 → 特定颜色（薄膜干涉）

  可产生的颜色范围：
  ██ 黑  ██ 深灰  ██ 银白  ██ 金  ██ 棕  ██ 紫  ██ 蓝  ██ 青
```

这是二极管 CW 激光和 CO₂ 激光完全无法实现的能力——脉冲光纤+精确参数控制是唯一能在消费级价格点实现金属彩色打标的技术路线。

##### 60W MOPA 脉冲光纤激光器 — F2 Ultra 核心光源 🆕

F2 Ultra 的 60W MOPA 光纤激光器是 xTool 当前产品线中**最强大的激光源**，代表从 Q-switched（F1 Ultra）到 MOPA（Master Oscillator Power Amplifier）的代际升级：

| 规格项 | 参数 | 对比 F1 Ultra 20W IR |

**MOPA vs Q-switched 工程架构对比**：

```
Q-switched (F1 Ultra 20W IR):       MOPA (F2 Ultra 60W):
──────────────​─────────────         ───────────​───────
泵浦 LD → 增益光纤 → Q开关           种子激光器 → 前置放大 → 功率放大
           (储能)   (瞬间释放)       (电调制)    (增益)     (增益)
              │                          │          │          │
              ▼                          ▼          ▼          ▼
        固定脉宽 ~100ns              脉宽 2–500ns 电控可调
        固定频率 20–80kHz            频率 1–4,000kHz 独立可调
        峰值功率不可调                峰值功率 + 脉宽 + 频率三参数独立控制
```

> 💡 **MOPA 的"杀手级应用"——铝黑标**：未经阳极氧化的裸铝在激光打标中极难呈现高对比度黑色。传统 Q-switched 光纤激光在铝表面只能产生灰/白色标记（激光能量被天然氧化铝层反射/吸收→氧化层增厚）。MOPA 的 2–10ns 超短脉冲 + 高频率组合可将能量穿透 ~4nm 透明氧化层→直接在铝基体上产生受控微坑→光在微坑内多次反射→呈现深黑色。这对工业条码/序列号/Logo 打标是刚需。

F2 Ultra UV 使用 **355nm 紫外 DPSS（Diode-Pumped Solid-State）激光器**，是 xTool 首款 UV 激光产品：

| 规格项 | 参数 |
|---|---|
| **激光类型** | DPSS 三倍频 Nd:YAG/YVO₄ |
| **波长** | 355±5 nm（紫外 UVA） |
| **输出功率** | 5W（平均） |
| **脉宽** | ~10–30 ns |
| **频率** | ~20–200 kHz |
| **光斑尺寸** | **0.02×0.02 mm**（<10μm） — 全产品线最细 |
| **加工原理** | **"冷加工"** — 光子能量 3.5eV > 多数材料分子键能（C–C 3.6eV），直接打断化学键 |

**紫外激光"冷加工" vs 红外/可见光"热加工"**：

```
红外/可见光激光 (CO₂/二极管/IR 光纤):     紫外激光 (355nm):
──────────────────────────────​───     ───────────​─────────
光子能量 < 分子键能                      光子能量 > 分子键能
    │                                        │
    ▼                                        ▼

    │                                        │
    ▼                                        ▼
热影响区 50–500μm                        热影响区 <5μm

> 💡 **355nm UV 激光的稀缺性**：消费级激光雕刻市场几乎全部为 455nm（蓝光二极管）和 10.6μm（CO₂）波长。355nm 紫外激光器在工业领域常见（晶圆划片、PCB 切割、玻璃标记），但在 $4,599 价位进入消费市场是行业首次。DPSS 紫外激光器的核心成本在非线性晶体（LBO/BBO 用于三倍频）和 808nm 泵浦 LD 寿命——这些供应链的成熟度决定了 F2 Ultra UV 能否大规模普及。

#### 7.7.5 振镜光学系统 (Galvo) — F 系列独有光路

F 系列（F1、F1 Ultra、F2 Ultra、F2 Ultra UV）与 xTool 其他所有产品使用完全不同的光束扫描方式——**振镜扫描**替代**龙门 XY 运动**。

##### F-Theta 透镜的工程约束

| 约束 | 说明 | 对 xTool 的影响 |
|---|---|---|
| **扫描面积 ∝ f** | F-Theta 焦距越长 → 扫描场越大 → 但光斑也越大 | F1/F1 Ultra 定在 220×220mm 以平衡面积+光斑 |
| **远心度** | 光束进入 F-Theta 后应垂直于工作面——实际在大角度时有偏差 | 扫描场边缘的光斑略大于中心 |
| **色差** | F1 Ultra 有双波长（455nm + 1064nm）——F-Theta 需在全波段消色差 | 两种波长的焦平面可能略有偏移，xTool 可能用软件补偿 |
| **场曲** | F-Theta 设计的平坦焦面是近似值——实际有残余场曲 | 边缘对焦精度可能略低于中心 |

##### 振镜 vs 龙门式 — 从激光头视角

```
              振镜 (Galvo)                 龙门 (Gantry)
              ─────────────                 ──────────────

激光头位置     固定（光束偏转）               物理移动（电机+皮带+导轨）
光路长度       变长（扫描角越大光路越长）      固定（只垂直方向）

Z 轴范围       有限（~10–20mm）               宽（P3 最大 220mm）

```

#### 7.7.7 光束质量综合分析

##### 波长-材料互作用深度对比

三种激光波长对同一材料的吸收率完全不同。这决定了"什么材料用什么激光"的根本物理限制：

```
材料                455nm 蓝光二极管    1,064nm IR 光纤     10.6μm CO₂
──────────────────────────────────────────────────────────────
透明亚克力 (Clear)   几乎透射 ❌          几乎透射 ❌          90%+ 吸收 ✅
深色亚克力            85%+ ✅             70%+ ✅             90%+ ✅
椴木/松木             85%+ ✅             75%+ ✅             90%+ ✅
不锈钢                30-35%              35-40% ✅           5-8% ❌
铝                    10-13%              15-20%              2-3% ❌
铜                    5-7%                3-5%                1-2% ❌
玻璃 (钠钙)           5% (透射)           5% (透射)           90%+ ✅
皮革                 80%+ ✅             75%+ ✅             85%+ ✅
纯棉布料              60-70%              50-60%              85%+ ✅
```

> 💡 **核心洞察**：没有任何一种激光波长能覆盖所有材料。这就是 xTool 在 F1 Ultra 中集成双光源（455nm+1064nm）和在 P3 中提供附加 IR 模块的根本原因——**多波长 = 多材料覆盖**。

##### 光斑尺寸与加工精度

| 光斑等级 | 代表模组 | 最小特征尺寸 (估算) | 适用精度场景 |
|---|---|---|---|
| **超精细** 0.03mm | F1 Ultra IR 光纤 | ~0.05mm | 珠宝打标、微文字、PCB 序列号 |
| **精细** 0.04–0.06mm | M1 Ultra 10W 二极管 | ~0.10mm | 印章、精细雕刻、照片雕刻 |
| **中等** 0.08–0.10mm | 20W/40W 二极管 | ~0.20mm | 标牌、切割、通用雕刻 |
| **粗** 0.14–0.20mm | CO₂ (P2S/P3) | ~0.30mm | 切割、大面积雕刻 |

##### 光束质量因子 M² 估算

M²（光束质量因子）描述实际光束偏离理想高斯光束（M²=1）的程度。M² 越大 → 光束质量越差 → 聚焦光斑越大 → 功率密度越低。

| 光源类型 | 估算 M² | 说明 |
|---|---|---|
| **单管二极管** (10W) | ~1.1–1.5 | 半导体发光区窄，快轴接近衍射极限 |
| **多管合束二极管** (20W/40W) | ~2–5 | 多管合束后光斑扩大，M² 恶化 |
| **CO₂ 激光管** (55W/80W) | ~1.2–1.5 | CO₂ 激光器以高光束质量著称 |
| **IR 光纤激光** (20W) | ~1.05–1.1 | 光纤激光器光束质量优异 |
| **MOPA 光纤激光** (60W) 🆕 | ~1.05–1.1 | 与 Q-switched 光纤同级，功率更高 |
| **UV DPSS 激光** (5W) 🆕 | ~1.1–1.3 | 三倍频过程轻微降低光束质量 |

> 💡 **为什么 F1 Ultra IR 的光斑可以达到 0.03mm**：光纤激光器的 M² ≈ 1.05，几乎就是理想高斯光束。这意味着它在给定的聚焦系统中可以达到最小的理论光斑。二极管模组受制于合束后的 M² 恶化，即使增加透镜 NA，也无法在同等功率下达到光纤激光的精细度。

##### 功率密度对比

光斑尺寸和功率的组合决定了**功率密度**（W/cm²），这是材料去除率的直接决定因素：

| 模组 | 功率 | 光斑面积 (估) | 功率密度 (kW/cm²) | 比较基准 |
|---|---|---|---|---|
| **20W IR 光纤** (F1 Ultra) | 20W | ~0.0009 mm² | **~2,200** | 基准 |
| **2W IR** (F1) | 2W | ~0.0009 mm² | ~220 | 1/10 |
| **10W 二极管** (M1 Ultra) | 10W | ~0.0024 mm² | ~420 | 1/5 |
| **20W 二极管** (F1 Ultra) | 20W | ~0.0080 mm² | ~250 | 1/9 |
| **40W 二极管** (S1) | 40W | ~0.0080 mm² | ~500 | 1/4 |
| **60W MOPA 光纤** (F2 Ultra) 🆕 | 60W | ~0.0009 mm² | **~6,700** | **3× 基准** |
| **5W UV 紫外** (F2 Ultra UV) 🆕 | 5W | ~0.0004 mm² | ~1,250 | ~0.6× |
| **80W CO₂** (P3, M 镜) | 80W | ~0.0270 mm² | ~300 | 1/7 |

> 💡 **关键发现**：F1 Ultra 的 20W IR 光纤激光器虽功率仅为 CO₂ 的 1/4，但功率密度是它的 **7 倍以上**。这就是为什么 20W 光纤可以雕刻不锈钢而 80W CO₂ 在金属上效率极低——功率密度，而非总功率，决定了材料与激光的交互。CO₂ 激光在金属表面大部分被反射，光纤 IR 波长（1,064nm）的金属吸收率也有优势。

##### 冷却系统对比

| 冷却方式 | 搭载产品 | 散热能力 | 优点 | 缺点 |
|---|---|---|---|---|
| **被动风冷** | F1, M1 Ultra (10W) | ~15–20W 废热 | 零维护、轻量、安静 | 仅适合低功率 |
| **主动风扇** | S1 (20W/40W), F1 Ultra, F2 Ultra | ~30–120W 废热 | 成本低、结构简单 | 噪声、灰尘积累 |
| **主动风扇（UV 模组）** | F2 Ultra UV | ~15W 废热 | UV 激光器电光效率较高 | 同 |
| **水冷（被动散热）** | P2S | ~400W 废热 | 可靠性高 | 长时间运行水温上升，功率漂移 |
| **变频压缩机制冷** | P3 | ~600W 废热 | **主动恒温**，功率稳定 | 成本高、重量大、有压缩机噪声 |

##### 未来技术方向推测

1. **WBC 光谱合束二极管**：当前的偏振+空间合束方案在 8 管（40W）时接近物理极限。下一代高功率二极管模组可能采用 **WBC（Wavelength Beam Combining）** 技术——使用略微不同波长的二极管经衍射光栅合束，在保持光斑不扩大的前提下实现 60–80W 输出。这将直接挑战入门级 CO₂ 的切割能力。

2. **RF 金属管 CO₂**：P 系列目前使用 DC 激励玻璃管，寿命和功率稳定性是软肋。RF 激励的金属-陶瓷 CO₂ 激光器（如 Coherent/大通激光的方案）寿命 >20,000h，功率稳定性更好，体积更小——但成本是玻璃管的 5–10 倍。如果 xTool 推出 P3 Pro 级产品，RF 金属管是自然的升级方向。

3. **MOPA 脉冲光纤**：✅ **已于 2025 年 7 月通过 F2 Ultra 实现。** 60W MOPA 支持 2–500ns 独立脉宽调节，实现 100+ 色金属打标和铝黑标。下一步方向：100W+ MOPA 或 532nm 绿光 MOPA（铜/贵金属吸收率更高）。

4. **紫外激光 (355nm)**：✅ **已于 2025 年 11 月通过 F2 Ultra UV 实现。** 5W UV DPSS 激光支持玻璃/水晶 3D 内雕和 1,500+ 种材料冷加工，与 O1 Omni 的 UV 喷墨打印形成"UV 双线"。下一步方向：更高功率 UV（10–15W）以实现 UV 切割能力。

| **Pixel-Scan™** | 线激光三角测量 + CIS | ±0.01mm | O1 Omni | UV 打印（喷头间隙 1–2mm，需微米级精度） | 成本最高、仅 O1 搭载 |
| **接触式探针** | 物理触碰 + 编码器 | ±0.01–0.1mm | S1、M1 Ultra | 所有材料（含透明/镜面）、曲面雕刻 | 逐点测量慢、会刮伤精致表面 |
| **ToF LiDAR** | 红外脉冲飞行时间 | ±0.5–1mm | P3、P2S | 大行程（64–220mm）、全材料、全自动 | 精度不足以做 UV 打印对焦 |
| **立体视觉（被动）** | 双相机视差 → 三角测量 | ~±0.2mm | F2 Ultra、F2 Ultra UV | Galvo 振镜短工作距离、曲面建模（Curve-measure） | 纹理依赖（纯色/镜面失效） |
| **单目 AI 相机** | 图像识别 → AI 推断 | ~±0.1mm（不可靠） | F1 Ultra、F2 | 不透明/非反光材料自动对焦 | 透明/反光/黑色材料不可用 |
| **纯手动红蓝双点** | 操作者视觉对齐 | 依赖操作者 | F1 [EOL]、F1/F2 Ultra（fallback） | 任何材料、零成本 | 速度慢、依赖经验 |

> 💡 **6 种技术不是技术路线混乱，而是"精准的产品管理"**：每个价位用"刚好够用"的方案。$599 的 F1 把钱投入双光源而非对焦系统；$6,999 的 P3 用 ToF LiDAR + 4 相机的多重冗余覆盖所有材料和场景；O1 Omni 因为 UV 喷墨的物理约束（喷头间隙 1–2mm）必须使用最高精度的 Pixel-Scan™。这与 Bambu Lab 的"X1C 用 LiDAR / P1P 用荷重元 / A1 Mini 用压力传感器"的分级策略异曲同工。

#### 7.8.6 传感器平台化复用分析

xTool 的传感器选型呈现出**跨产品线的平台化复用**特征——这是降低供应链复杂度和固件开发量的关键策略：

| 传感器模块 | 复用产品 | 复用方式 |
|---|---|---|
| **16MP 相机模组** | P3、P2S、M2、MetalFab | 相同的相机硬件模组，固件/标定参数按产品差异化 |
| **ToF LiDAR 模块** | P3、P2S | P3 为升级版（量程更大），但核心器件相同 |
| **接触式探针组件** | S1、M1 Ultra | 相同的机械探针+微动开关+编码器方案，S1 软件增加曲面多点测量 |
| **48MP 相机模组** | F2 Ultra、F2 Ultra UV | 相同的双相机立体视觉硬件，Curve-measure 为软件差异化 |
| **IR 火焰传感器** | 全部封闭式激光产品 | 标准化 8×IR 阵列（P3）/ 单 IR（其他）按安全等级配置数量 |
| **开盖互锁开关** | 全部 Class 1/Class 4 封闭产品 | 标准化微动开关模块 |
| **光电 endstop** | 全部龙门式产品（P/S/M 系列） | 标准化光电传感器模块 |
| **振镜位置编码器** | 全部 F 系列 | 来自振镜供应商（Sino-Galvo 等）集成方案，非 xTool 自研 |

> 💡 **最大的平台化杠杆在相机模组**：xTool 使用的 16MP/48MP 相机模组本质上是手机相机供应链的成熟产品——这意味着年采购量达到数十万颗时，单价极低（16MP 模组 ~$8-15、48MP 模组 ~$20-35）。相同硬件在不同产品上通过固件差异化实现不同功能（P3 用 16MP 做定位+监控、M2 用 16MP 做远距预览、MetalFab 用 16MP 做 AI 排版），这是典型的"硬件 commoditized + 软件价值化"策略。

#### 7.8.7 关键洞察

1. **传感器数量与价格呈正比，但非线性**：$599 F1（0 传感器）→ $1,499 F2（1 相机 + 火焰 + 互锁）→ $4,999 F2 Ultra（2 相机立体视觉 + 火焰 + 互锁 + 振镜编码器）→ $6,999 P3（4 相机 + LiDAR + 8 IR + CO₂ 灭火 + 水冷传感 + 互锁 + 急停）。传感器的数量和质量是 xTool 产品层级定价的重要工程支撑。

2. **非激光产品线的传感器策略迥异**：O1 Omni 的 Pixel-Scan™ 是 xTool 最复杂的单机传感器系统（线激光 + CIS + 激光测距三重冗余），因为 UV 喷墨打印对距离的敏感度远超激光加工。而 WonderPress 的传感器方案（NTC + 压力传感器）完全来自家电行业供应链，体现了 xTool 进入新品类时"借用成熟供应链"的策略。

3. **开放式→全封闭→Class 1 的安全进化**：xTool 2021 年起家于 D1 开放式架构（零安全传感器），2023 年 S1/P2S 转向全封闭（基础安全传感器），2025-2026 年 P3/M2/F2 Ultra UV 实现 Class 1 认证（完整安全传感器集群 + 工业级灭火）。这一进化路径反映了消费级激光工具从"DIY 爱好者玩具"向"家用电器"的品类升级——安全传感器是这一升级的工程基础。

4. **与 3D 打印行业的传感器趋同**：xTool 全系传感器配置与智能 3D 打印机呈现出明显的趋同趋势——AI 相机（spaghetti 检测 ↔ 火焰检测）、ToF/结构光测距（首层扫描 ↔ 自动对焦）、封闭+过滤（ABS  enclosure ↔ 激光安全罩）。两个行业正在向同一终点演进："按下按钮即可安全运行的桌面制造设备"。

### 10.2 关键观察

- **营收增速从 70% 降至 19%**：高速增长期接近尾声，正在进入"稳态增长"阶段
- **毛利率 56%**：高于传统制造（~30%），低于纯软件/SaaS（70%+），体现了"硬件+软件"混合模式
